# 실행 가이드

이 문서는 `ai_std_dev_llmragdev`의 Streamlit 사용자 정보 조회 프로그램 실행 방법을 정리한다.

## 1. 실행 대상

```text
F:\ai_std_dev\ai_std_dev_llmragdev\mainUserInfoStreamlitApp.py
```

## 2. 사전 준비

Anaconda 환경을 활성화한다.

```powershell
conda activate ai-std-dev7
```

프로젝트 폴더로 이동한다.

```powershell
cd F:\ai_std_dev\ai_std_dev_llmragdev
```

필요 패키지가 없으면 설치한다.

```powershell
pip install -r .\requirements.txt
```

## 3. 환경변수 확인

DB 접속 정보는 다음 파일에 있어야 한다.

```text
F:\ai_std_dev\.env
```

필수 값:

```text
DATABASE_URL=postgresql://...
```

앱은 이 값으로 PostgreSQL에 접속하고 `temp_users` 테이블을 조회한다.

## 4. 실행 명령

기본 실행:

```powershell
streamlit run .\mainUserInfoStreamlitApp.py
```

포트를 지정해서 실행:

```powershell
streamlit run .\mainUserInfoStreamlitApp.py --server.port 8501 --server.address 127.0.0.1
```

브라우저 접속:

```text
http://127.0.0.1:8501
```

## 5. 사용 방법

1. 왼쪽 sidebar의 `이름 또는 이메일` 입력창에 검색어를 입력한다.
2. `최대 조회 건수`를 선택한다.
3. `조회` 버튼을 누른다.
4. 본문 테이블에서 사용자 정보를 확인한다.
5. 필요하면 `CSV 다운로드` 버튼으로 결과를 저장한다.

검색어를 비워두면 전체 사용자를 조회한다.

## 6. 검증 명령

문법 검사:

```powershell
python -m py_compile `
  .\mainUserInfoStreamlitApp.py `
  .\userinfo\app\userInfoApp.py `
  .\userinfo\biz\userInfoBiz.py `
  .\userinfo\repository\userInfoRpo.py `
  .\userinfo\schemas\userInfoSch.py
```

DB 조회 확인:

```powershell
python -c "from userinfo.biz.userInfoBiz import UserInfoBizService; svc=UserInfoBizService(); print('count=', svc.get_summary(None).total_count); print('sample=', len(svc.search_users(None, 5)))"
```

정상 예시:

```text
count= 19
sample= 5
```

## 7. 자주 나는 오류

| 오류 | 원인 | 조치 |
|---|---|---|
| `streamlit` 명령을 찾을 수 없음 | Streamlit 미설치 또는 환경 미활성화 | `conda activate ai-std-dev7` 후 `pip install streamlit` |
| `DATABASE_URL` 오류 | `.env`에 DB URL 없음 | `F:\ai_std_dev\.env` 확인 |
| DB 접속 실패 | 네트워크, 계정, DB 서버 문제 | DB URL과 인터넷 연결 확인 |
| `ModuleNotFoundError` | 패키지 누락 | `pip install -r .\requirements.txt` |
| 빈 화면 또는 결과 없음 | 검색 조건에 맞는 데이터 없음 | 검색어를 비우고 다시 조회 |

## 8. 종료 방법

터미널에서 실행 중이면 `Ctrl + C`를 눌러 종료한다.

백그라운드로 실행한 경우 PowerShell에서 Streamlit 프로세스를 확인한다.

```powershell
Get-Process | Where-Object { $_.ProcessName -like "*streamlit*" -or $_.ProcessName -like "*python*" }
```

필요한 프로세스만 확인 후 종료한다.
