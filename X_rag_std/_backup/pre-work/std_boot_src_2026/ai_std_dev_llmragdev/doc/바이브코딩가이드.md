# 바이브코딩 가이드

이 문서는 `ai_std_dev_llmragdev` 프로젝트에서 "지금 프로그램 개발해줘"라고 요청할 때 사용할 안내서이다. 개발자는 이 문서를 읽고, 표준 문서와 현재 구현을 기준으로 바로 기능을 추가한다.

기준 표준 문서:

```text
F:\ai_std_dev\ai_std_dev_llmragdev\doc\ai_solution_development_standard.md
```

현재 대상 프로그램:

```text
F:\ai_std_dev\ai_std_dev_llmragdev\mainUserInfoStreamlitApp.py
```

## 1. 개발 요청 목표

Streamlit으로 사용자 정보를 조회하는 프로그램을 개발한다.

기본 기능:

- `temp_users` 테이블의 사용자 목록 조회
- 이름 또는 이메일 키워드 검색
- 최대 조회 건수 제한
- 조회 결과 테이블 표시
- CSV 다운로드
- DB 접속 실패 시 화면에 오류 표시

## 2. 개발 기준

개발자는 다음 계층 구조를 유지한다.

```text
ai_std_dev_llmragdev/
  mainUserInfoStreamlitApp.py
  userinfo/
    app/
      userInfoApp.py
    biz/
      userInfoBiz.py
    repository/
      userInfoRpo.py
    schemas/
      userInfoSch.py
```

계층별 역할:

| 계층 | 역할 |
|---|---|
| `mainUserInfoStreamlitApp.py` | Streamlit 앱 진입점 |
| `userinfo/app` | 화면 구성, 입력 위젯, 결과 표시 |
| `userinfo/biz` | 조회 조건 처리, 업무 흐름 제어 |
| `userinfo/repository` | DB 연결, SQLAlchemy 조회 |
| `userinfo/schemas` | 설정, 검색 조건, 조회 결과 모델 |

## 3. 구현 지시

개발할 때는 다음 순서로 진행한다.

1. `schemas`에서 입력/출력/설정 모델을 먼저 정의한다.
2. `repository`에서 DB 테이블 모델과 조회 로직을 작성한다.
3. `biz`에서 화면 요청을 repository 호출로 연결한다.
4. `app`에서 Streamlit UI를 작성한다.
5. `mainUserInfoStreamlitApp.py`에서 화면 렌더링 함수를 호출한다.
6. `requirements.txt`와 `README.md`에 실행에 필요한 정보를 적는다.
7. `python -m py_compile`로 문법을 확인한다.
8. 실제 DB 조회가 가능한지 짧은 명령으로 검증한다.
9. `streamlit run`으로 앱 실행을 확인한다.

## 4. DB 기준

DB 연결 정보는 코드에 직접 쓰지 않고 `.env`에서 읽는다.

```text
F:\ai_std_dev\.env
```

필수 환경변수:

```text
DATABASE_URL=postgresql://...
```

조회 테이블:

```text
temp_users
```

조회 컬럼:

| 컬럼 | 설명 |
|---|---|
| `id` | 사용자 ID |
| `name` | 사용자 이름 |
| `email` | 이메일 |
| `created_at` | 생성일시 |

## 5. Streamlit UI 기준

화면은 단순 조회 업무에 맞게 구성한다.

- 페이지 제목은 `사용자 정보 조회`로 한다.
- 검색 조건은 sidebar에 둔다.
- 본문 상단에는 조회 건수, 검색어, 표시 제한을 metric으로 보여준다.
- 조회 결과는 `st.dataframe`으로 표시한다.
- 결과가 없으면 `st.info()`로 안내한다.
- 예외가 발생하면 `st.error()`로 사용자에게 표시한다.
- CSV 다운로드 버튼을 제공한다.

## 6. 코딩 규칙

- DB 비밀번호, API Key 등 민감정보는 코드에 직접 쓰지 않는다.
- 로그나 화면 문구에는 깨지기 쉬운 이모지를 쓰지 않는다.
- DB session은 사용 후 반드시 닫는다.
- SQLAlchemy engine은 `pool_pre_ping=True`를 사용한다.
- Streamlit에서 서비스 객체는 `st.cache_resource`로 캐시한다.
- 화면 코드는 DB 세부 구현을 직접 알지 않게 한다.
