### 1. 영향도 분석 엔진 (500줄)

**파일**: `impact_analyzer.py`

```python
class ImpactAnalyzer:
    """정답 보정의 영향도 분석"""
    
    - analyze_correction_impact(): 개별 정답 영향도
    - _analyze_ontology_changes(): 온톨로지 변경점
    - _analyze_rag_changes(): RAG 변경점
    - _analyze_evaluation_changes(): 평가 기준 변경점
    - _calculate_impact_score(): 영향도 점수
    - _assess_risk_level(): 위험도 평가
    - _create_rollback_plan(): 롤백 계획

class ConsolidatedImpactAnalysis:
    """여러 정답 보정의 통합 영향도"""
    
    - analyze_all_corrections(): 통합 영향도 분석
    - _deduplicate_changes(): 중복 제거
    - _assess_overall_risk(): 전체 위험도
    - _prioritize_changes(): 우선순위 정렬
```

**주요 기능**:
- 정답 수정이 어떤 부분을 변경해야 하는지 자동 분석
- 온톨로지/RAG/평가 기준 변경점 식별
- 영향도 점수 및 위험도 자동 평가
- 롤백 계획 자동 생성
