### 4. 핵심 설계 결정

**org_id DDTT 계층 코드 체계**
```
01__  →  01부서 전체
0100  →  01부서 (팀 미배정)
0101  →  01부서 01팀
0102  →  01부서 02팀
```

**ChromaDB 부서 단위 필터링 문제 해결**  
ChromaDB/Qdrant는 prefix LIKE 지원 없음 → `dept_code` 파생 필드를 별도 저장하여 exact match로 부서 검색 구현.

**Index Swap 패턴 (조직 개편 대응)**  
1. 신규 컬렉션에 새 org_id 기준 야간 배치 재색인
2. routing.json collection_name 원자적 교체
3. 구 컬렉션 D+3 이후 안전 삭제
