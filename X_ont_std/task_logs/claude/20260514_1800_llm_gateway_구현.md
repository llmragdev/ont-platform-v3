# 작업 기록: LLM Gateway 구현 + src_claud v2 연동

- **작업일시**: 2026-05-14
- **요청자**: 사용자
- **배경**: 기존 qaRpo.py의 Gemini 임베딩 패턴 참조, 멀티테넌트 + LLM/RAG 분리 아키텍처
- **산출물**: `src_agents/llm_gateway/` (신규), `src_claud/v2/` 연동 파일 추가

## 생성된 파일

### llm_gateway/ (신규 서비스, 포트 8010)
```
llm_gateway/
├── app/
│   ├── main.py
│   ├── core/
│   │   ├── config.py       # GEMINI_API_KEY1~4 키 풀 설정
│   │   └── key_pool.py     # 라운드로빈 + 실패 격리
│   ├── api/
│   │   ├── embed.py        # POST /api/v1/embed (캐싱 포함)
│   │   ├── generate.py     # POST /api/v1/generate + /stream (SSE)
│   │   └── health.py       # GET /api/v1/health
│   ├── models/
│   │   └── schemas.py      # EmbedRequest/Response, GenerateRequest/Response
│   └── services/
│       ├── gemini_client.py # httpx 기반 Gemini REST API 호출
│       └── embed_cache.py   # TTL 인메모리 캐시
├── .env.example
├── requirements.txt
└── README.md
```

### src_claud v2 추가 파일
- `app/services/embedding/gemini_http_embedding.py` — Gateway 경유 임베딩
- `app/services/llm/gemini_http_llm.py` — Gateway 경유 LLM + 스트리밍
- `app/core/config.py` — `LLM_GATEWAY_URL` 설정 추가
- `app/services/providers.py` — `gemini_http` 프로바이더 분기 추가

## 운영 전환 방법
```
# 1. Gateway 실행
cd llm_gateway && uvicorn app.main:app --port 8010

# 2. src_claud v2 환경변수
EMBEDDING_PROVIDER=gemini_http
LLM_PROVIDER=gemini_http
LLM_GATEWAY_URL=http://localhost:8010
```

## 기술 결정 사항
- Gemini SDK 대신 httpx + REST API 직접 호출 → 전역 상태 없음, 스레드 안전
- 임베딩 캐시: SHA256(model::text) 키, TTL 1시간, 최대 10,000건
- 키 실패 임계: 3회 연속 실패 시 다음 키로 전환
- 기존 .env의 GEMINI_API_KEY1~4 구조 그대로 사용
