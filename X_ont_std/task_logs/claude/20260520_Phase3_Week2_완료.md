## 🔍 기술 세부사항

### FastAPI 통합 테스트 전략
```python
from fastapi.testclient import TestClient
from app.main import app

client = TestClient(app)
response = client.post("/api/workflow/execute", json=body, headers=headers)
```

### 권한 헤더 (X-* 기반)
```python
headers = {
    "X-User-Id": "user@nipa.go.kr",
    "X-Company-Id": "demo-co",
    "X-Project-Id": "proj-01",
    "X-Role": "FinanceManager"
}
```

### Pydantic 모델 통합
- Request 모델: WorkflowExecuteRequest (자동 검증)
- Response 모델: ActionResponse (FastAPI 문서 자동 생성)
- Query 매개변수: Query() 사용 (description 지원)

### HTTP 상태 코드
```
200 ✅ 액션 실행 성공
400 ❌ 필드 누락 또는 비즈니스 로직 오류
403 🚫 권한 부족
404 🔍 엔티티 또는 액션 미찾음
422 ⚠️  Pydantic 검증 오류
```
