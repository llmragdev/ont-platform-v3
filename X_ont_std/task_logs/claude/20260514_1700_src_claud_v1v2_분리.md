## v2 — 프로덕션 업그레이드 내역

`v1/` → `v2/` 복사 후 아래 업그레이드:

| 항목 | 변경 사항 |
|------|----------|
| `services/providers.py` (신규) | embedding/LLM/chunker 팩토리 중앙화 (DRY) |
| `services/document_service.py` | `_run_pipeline` → `await asyncio.to_thread(...)` 비동기화 |
| `services/rag_service.py` | 로컬 팩토리 제거, `providers` 임포트 사용 |
| `services/embedding/claude_embedding.py` | `voyageai.Client` 실제 Voyage-3 임베딩 구현 |
| `services/llm/claude_llm.py` | `anthropic.Anthropic` 실제 Claude API 구현 (스트리밍 포함) |
| `services/llm/base.py` | `async def → def`, `AsyncGenerator → AsyncIterator` 시그니처 수정 |
| `services/llm/mock_llm.py` | `AsyncIterator` 타입 일치 |
| `models/db_models.py` | `ca_org_mgnt`, `ca_user`, `wc_project_rag_doc`에 ForeignKey 추가 |
| `tests/conftest.py` | `scope="session"` 제거 → 함수 스코프 (테스트마다 독립 DB) |
| `requirements.txt` | `voyageai>=0.2.0` 추가 |
| `v2_Development_Plan.md` (신규) | 변경 내역 + 향후 과제 문서화 |
