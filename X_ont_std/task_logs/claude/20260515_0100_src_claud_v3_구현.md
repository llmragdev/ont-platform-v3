# src_claud/v3 구현

**작업 일시**: 2026-05-15

## 작업 개요

RAG 표준 설계 v1.3을 기준으로 v2의 버그 6개를 수정하고 신규 설계 요건을 반영한 v3 구현.

## v2 버그 수정

| # | 버그 | 수정 |
|---|------|------|
| 1 | Chroma `add_documents()` `embeddings=` 누락 | `add_documents()` 시그니처에 `embeddings` 파라미터 추가, Chroma에 명시 전달 |
| 2 | RAG 검색 필터에 tenant_id 강제 주입 누락 | `_build_tenant_filters()`에서 항상 `tenant_id` 주입 |
| 3 | asyncio.to_thread + SQLAlchemy Session 공유 | `_run_pipeline_isolated()` 독립 함수로 분리, 내부에서 `SessionLocal()` 생성 |
| 4 | ChunkMetadata 누락 필드 | `tenant_id`, `org_id`, `dept_code`, `vector_db_id`, `created_at` 추가 |
| 5 | Gateway 호출 시 `tenant_id: "default"` 하드코딩 | `embed_text(text, tenant_id)`, `generate_answer(query, chunks, tenant_id)` 시그니처 추가 |
| 6 | 업로드 응답 `completed` 반환 | `asyncio.create_task()`로 파이프라인 백그라운드 실행, 즉시 `pending` 반환 |

## v1.3 신규 요건 반영

| 항목 | 구현 내용 |
|------|----------|
| X-Tenant-ID 필수화 | `_get_tenant_id()`: 누락 시 400 HTTPException |
| org_id/dept_code 격리 | `search(org_id=)` 파라미터 + `_build_where_clause()` OR 조건 |
| OR org_id IS NULL | 공유 문서는 `org_id=""` 저장, 검색 시 `org_id == "0102" OR org_id == ""` |
| ca_org_mgnt 복합 PK | `(tenant_id, org_id)` 복합 PK + ForeignKeyConstraint |
| tags Vector DB 제외 | Chroma `add_documents()` 시 tags 필드 제거 |
| company_id 전면 교체 | v3 전체 `tenant_id`로 통일, 잔존 참조 0 |
