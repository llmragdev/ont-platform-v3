## 4. Phase 3 착수 계획 (6월 시작)

### 4.1 비즈니스 ActionType 추가

**현재 문제**: ActionType이 쿼리 액션만 있고 비즈니스 액션 없음

```python
# 추가해야 할 ActionType (예시)
class ActionType(Enum):
    # 기존 (쿼리 관련)
    QUERY_ONTOLOGY = "query_ontology"
    VECTOR_SEARCH = "vector_search"
    
    # 신규 (비즈니스 액션)
    APPROVE_PROJECT = "approve_project"        # 프로젝트 승인
    REJECT_PROJECT = "reject_project"          # 프로젝트 반려
    CHANGE_STATUS = "change_status"            # 상태 변경
    REQUEST_MATERIAL = "request_material"      # 자재 요청
    SEND_NOTIFICATION = "send_notification"    # 알림 발송
```

**관련 파일**: `v3/src/backend/models/`

### 4.2 상태 전이 규칙 10개 이상

```
PROJECT 상태 전이:
  Submitted → Approved (by manager)
  Submitted → Rejected (by manager)
  Approved → InProgress (by system)
  InProgress → Completed (by system)
  Rejected → Submitted (재심 요청)
  ...
```

### 4.3 RBAC 권한 모델

| 역할 | 허용 액션 |
|------|---------|
| `admin` | 모든 액션 |
| `manager` | Approve, Reject, ChangeStatus |
| `team_lead` | RequestMaterial, SendNotification |
| `member` | 조회만 |

### 4.4 Write-back 동기화

**목표**: Foundry에서 승인 → 원천 DB(SAP/ERP) 자동 반영
- 성공률 ≥ 95%
- 실패 시 롤백 + 감사 로그
