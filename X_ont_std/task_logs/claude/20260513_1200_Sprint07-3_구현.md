### 2. WorkflowService v2.0

`src/backend/app/services/workflow.py`

- `load_config(path)` — workflow.json 로드 (캐시)
- `WorkflowService(ontology_svc, config_path=None)`
  - `queue(ctx, entity_type, doc_ids)` — 현재 role로 실행 가능한 액션이 있는 엔티티 목록
  - `execute(ctx, doc_id, entity_id, action_name)` — 상태 전이 실행
  - `available_actions(role, current_status)` — 현재 상태에서 역할이 실행 가능한 액션 목록

### 3. WorkflowGraphService v2.0

`src/backend/app/services/workflow.py` (같은 파일)

- 그래프를 테넌트별 JSON 파일로 저장: `storage/{co}/{proj}/workflow_graphs.json`
- `WorkflowGraphService(config: WorkflowGraphConfig)`
  - `list_graphs(ctx)` — 목록
  - `get_graph(ctx, graph_id)` — 단건
  - `save_graph(ctx, payload)` — 생성/수정
  - `delete_graph(ctx, graph_id)` — 삭제

### 4. API 라우터

`src/backend/app/api/workflow.py`

```
GET  /api/workflow/queue              → WorkflowService.queue()
POST /api/workflow/execute            → WorkflowService.execute()
GET  /api/workflow-graphs             → WorkflowGraphService.list_graphs()
GET  /api/workflow-graphs/{id}        → WorkflowGraphService.get_graph()
POST /api/workflow-graphs             → WorkflowGraphService.save_graph()
DELETE /api/workflow-graphs/{id}      → WorkflowGraphService.delete_graph()
```

### 5. main.py 업데이트
