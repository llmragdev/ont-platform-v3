## 🔍 기술 세부사항

### Condition 연산자 (8가지)
```python
not_null      → field_value is not None
equals        → field_value == value
gte           → field_value >= value
lte           → field_value <= value
gt            → field_value > value
lt            → field_value < value
exists        → field_value is not None (exists와 같음)
```

### Template Variable 치환 예시
```json
"property_changes": [
  { "field": "properties.deadline", "value": "{{ new_deadline }}" },
  { "field": "properties.approved_by", "value": "{{ user_id }}" },
  { "field": "properties.approved_at", "value": "{{ timestamp }}" }
]
```

실행 시:
```python
execute(params={"new_deadline": "2026-12-31"})
# → "{{ new_deadline }}" → "2026-12-31"
# → "{{ user_id }}" → "user@nipa.go.kr"
# → "{{ timestamp }}" → "2026-05-20T18:30:45.123Z"
```

### Conditional Permission 예시
```json
{
  "condition": {
    "field": "properties.budget",
    "operator": "lte",
    "value": 50000000
  },
  "allowed_roles": ["TeamLead", "FinanceManager", "Admin"]
}
```
→ 예산 ≤ 5천만원: 팀장 이상 승인 가능
