## 🔍 기술 세부사항

### Precondition 검증 연산자
```python
"not_null" → field_value is not None
"equals" → field_value == expected_value
"gte" → field_value >= expected_value
"lte" → field_value <= expected_value
"gt" → field_value > expected_value
"lt" → field_value < expected_value
"exists" → field_value is not None
```

### Conditional Permission 예
```json
{
  "condition": {
    "field": "properties.budget",
    "operator": "lte",
    "value": 50000000
  },
  "allowed_roles": ["TeamLead", "FinanceManager", "Admin"]
}
```
→ 예산 5천만원 이하: 팀장 이상 승인 가능

### Write-back 흐름 요약
```
Action 실행
  ↓
Changelog 생성 (sync_status: pending)
  ↓
WriteBackQueue 추가
  ↓
Worker (1분 주기)
  ├─ SAP API 호출
  ├─ 성공: sync_status = synced
  └─ 실패: 재시도 (최대 3회, 1시간 간격)
```
