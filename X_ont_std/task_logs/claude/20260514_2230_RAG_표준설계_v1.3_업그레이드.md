# RAG 표준설계 v1.3 업그레이드

**작업 일시**: 2026-05-14  
**작업자**: Claude  
**작업 유형**: 설계 문서 버전업

---

## 작업 배경

외부 코드 리뷰에서 v1.2의 5가지 문제점이 지적됨. 검토 후 전부 타당하다고 판단, v1.3으로 업그레이드.

## 반영 항목 (6개)

1. **X-Tenant-ID default fallback 제거** — `"default"` 반환 시 모든 누락 요청이 동일 테넌트로 수렴해 격리 모델이 깨짐. 400 오류로 즉시 차단으로 변경.

2. **팀/부서 검색 시 전사 공유 문서(`org_id IS NULL`) 포함 정책 명시**
   - 팀: `tenant_id == T AND (org_id == "0102" OR org_id IS NULL)`
   - 부서: `tenant_id == T AND (dept_code == "01" OR org_id IS NULL)`
   - 전사: `tenant_id == T` (관리자/시스템 전용)

3. **X-Org-ID 부재 처리 정책 신설** — 일반 사용자는 인증된 소속 org_id로 자동 보정, 불가 시 403. 관리자/시스템만 전사 검색 허용.

4. **`ca_org_mgnt` PK → `(tenant_id, org_id)` 복합키** — 멀티테넌트에서 `org_id` 단독 PK는 테넌트 간 충돌 위험. FK 참조 전 테이블 업데이트.

5. **`0100` 의미 명확화** — "부서 전체"가 아닌 "부서 공통 소유 문서 코드". 부서 전체 검색은 `dept_code == "01"` 사용.

6. **`tags` Vector DB metadata 제외** — ChromaDB/Qdrant는 scalar 필드만 안전. `tags`는 RDBMS/API 응답 전용으로 명시.
