### 2. embedding `tenant_id` 파라미터 누락 (버그)

`_run_pipeline_isolated` 및 `RagSearchService.search()` 가 `embed_text(text, tenant_id=tenant_id)` 로 호출하는데,
`HashEmbeddingService` / `ClaudeEmbeddingService` / `EmbeddingService` 기반 클래스에 `tenant_id` 파라미터 없음.

| 파일 | 수정 |
|------|------|
| `services/embedding/base.py` | `embed_text(text, tenant_id: str = "")` |
| `services/embedding/hash_embedding.py` | 동일 |
| `services/embedding/claude_embedding.py` | 동일 |

### 3. LLM `tenant_id` 파라미터 누락 (버그)

`RagSearchService.search()` 가 `generate_answer(query, chunks, tenant_id=tenant_id)` 로 호출하는데
`MockLlmClient` / `ClaudeLlmClient` / `LlmClientBase` 에 `tenant_id` 파라미터 없음.

| 파일 | 수정 |
|------|------|
| `services/llm/base.py` | `generate_answer(...)` / `stream_answer(...)` 에 `tenant_id: str = ""` 추가 |
| `services/llm/mock_llm.py` | 동일 |
| `services/llm/claude_llm.py` | 동일 |

### 4. `pipeline_sync_mode` 추가 (테스트 지원)

`asyncio.create_task()` 로 실행되는 파이프라인이 TestClient 환경에서 완료 전에 검색이 실행되면 벡터 없음.

| 파일 | 수정 |
|------|------|
| `core/config.py` | `pipeline_sync_mode: bool = False` 추가 |
| `services/document_service.py` | `if settings.pipeline_sync_mode: await pipeline_coro else: create_task(...)` |

### 5. `_run_pipeline_isolated` DB 오류 내성 강화

테스트 환경에서 `SessionLocal()` 이 테스트 DB가 아닌 파일 SQLite 에 연결됨.
`set_status()` 호출 실패 시 파이프라인 전체가 중단되지 않도록 try/except 처리.

### 6. `ProjectRepository.ensure_default()` tenant_id 누락 (버그)

`Project` 모델에 `tenant_id NOT NULL` 추가됐으나 `ensure_default()` 가 `tenant_id` 없이 INSERT → IntegrityError.
`tenant_id="system"` 으로 기본값 지정.

### 7. 테스트 픽스처 업그레이드

| 파일 | 수정 |
|------|------|
| `tests/conftest.py` | `TestClient(app, headers={"X-Tenant-ID": "test_tenant"})` — 전체 요청에 헤더 자동 포함 |
| `tests/conftest.py` | `settings.pipeline_sync_mode = True` monkeypatch |
| `tests/test_upload.py` | `pipeline_status == "completed"` → `"pending"` (v3 의도적 설계) |
