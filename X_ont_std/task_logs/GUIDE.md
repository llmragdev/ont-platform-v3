# AI 통합 관제 시스템 가이드 (AI Task Control System)

본 가이드는 Codex, Antigravity, Claude 세 에이전트에게 지시를 내리고 작업 이력을 관리하기 위한 공식 프로토콜입니다.

## 1. 지시서 관리 원칙
1. **중앙 관리**: 모든 지시는 `E:\ontology_edu\AI_TASK_CONTROL` 아래의 에이전트별 폴더에 파일로 남깁니다.
2. **파일명 규칙**: `YYYYMMDD_HHMM_작업명.md`
   - 예: `20260513_1120_AuthMiddleware_구현.md`
3. **상호 참조**: 한 에이전트의 작업 결과가 다른 에이전트의 입력이 될 경우, 지시서 내에 해당 파일 경로를 명시합니다.
4. **상태 질문 예외**: 사용자가 단순히 현재 상태, 다음 차례, 진행 후보를 묻는 경우는 지시서로 남기지 않습니다. 이는 의사결정 전 확인 대화로 봅니다.
5. **자율적 착수 및 기록**: AI 에이전트가 다음 작업을 제안하고 지시서(`AI_TASK_CONTROL`)를 생성한 경우, 사용자의 명시적인 거부나 수정 지시가 없는 한 즉시 작업을 시작합니다. 지시서에는 제안 내용과 예상 범위를 기록하여 사후 추적이 가능하게 합니다.
6. **기록 시작점**: 지시서에는 단순 상태 요약만 적지 말고, 최소한 다음을 포함합니다.
   - 에이전트가 제안하거나 질문한 작업
   - 사용자의 승인 또는 선택
   - 작업 범위
   - 완료 기준(DoD)
   - 참고해야 할 이전 산출물 경로

## 2. 에이전트별 R&R (Role & Responsibility)
- **Antigravity**: 플랫폼의 근본 아키텍처 설계 및 핵심 보안/인프라 레이어 구현 담당.
- **Codex**: 설계서의 빈틈을 찾고, 고도화된 기술적 대안을 제시하는 수석 아키텍트 역할.
- **Claude**: 구체적인 비즈니스 로직 구현, 단위 기능 개발 및 실전 테스트(DoD) 수행 담당.
