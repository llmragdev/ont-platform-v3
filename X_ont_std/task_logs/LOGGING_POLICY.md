# Task Logs 기록 정책

> Claude Code의 모든 작업 기록을 관리하는 정책 문서입니다.

---

## 📋 기록 대상

- **프로그램 수정/기능 추가**: 코드 변경, 버그 수정, 리팩토링
- **아키텍처/설계 변경**: 구조 변경, 패턴 도입, 설정 변경
- **문서화**: 요건 정리, 가이드 작성, API 문서
- **테스트**: 테스트 추가, 테스트 개선, 테스트 실패 기록

---

## 📝 로그 파일 형식

### 파일명
```
YYYYMMDD_HHMM_작업명.md
예) 20260519_1430_통합테스트_20대50달성.md
```

### 파일 경로
```
E:\ontology_edu\X_ont_std\task_logs\claude\
```

### 파일 구조
```markdown
# [작업 제목]

**작업 목표**: 
- 목표1
- 목표2

**작업 내용**:
[구체적인 작업 내용 및 변경사항]

---

## 변경 파일 목록
- [파일경로](링크) — 변경 사항 요약

---

## 완료 상태
- ✅ **완료** (또는)
- ⚠️ **진행중** (또는)
- ❌ **실패**

**시작 시간**: 2026-05-19 14:30  
**완료 시간**: 2026-05-19 15:45  
**소요 시간**: 1시간 15분

---

## 참고사항
[필요시 추가 메모]
```

## 🎯 기록 정책

### 작업 시작 시
1. 로그 파일 생성 (`YYYYMMDD_HHMM_작업명.md`)
2. 작업 제목, 목표, 기본 정보 입력
3. 상태: `⚠️ 진행중` 으로 표시

### 작업 완료 시
1. 변경 파일 목록 추가
2. 완료 시간 및 소요 시간 기록
3. 상태: `✅ 완료` 또는 `❌ 실패` 로 변경

### 주의사항
- **수정 내용은 git commit 메시지와 일관성** 유지
- **과도한 상세는 피하기** — 요약 수준으로
- **파일 경로는 상대 경로 사용** (링크 가능하게)
