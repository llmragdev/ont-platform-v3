## 2. 신규 공통 컴포넌트

v3.0에서 여러 화면에 공통으로 사용되는 컴포넌트를 먼저 정의한다.

### 2.1 `LlmAnswerPanel` (신규)

**파일**: `src/components/LlmAnswerPanel.tsx`

**용도**: LLM 생성 답변을 로딩 상태와 함께 표시. AIQuery, RAGQuery, HybridQuery 3개 화면에서 사용.

```
┌─────────────────────────────────────────────┐
│ AI 답변  [descriptive] [llm ✓]              │
├─────────────────────────────────────────────┤
│                                             │
│  Snowflake는 클라우드 기반 데이터 웨어하우스로  │
│  서버리스 아키텍처를 채택하여...              │
│                                             │
│  [출처: doc-001 p.3] [출처: doc-002 p.7]    │
├─────────────────────────────────────────────┤
│ 신뢰도 89%  |  응답 1.3s  |  fallback ✗    │
└─────────────────────────────────────────────┘
```

**Props**:
```typescript
interface LlmAnswerPanelProps {
  answer: string | null;
  intent: string;
  quality_metrics?: {
    llm_used: boolean;
    fallback_used: boolean;
    vector_hits: number;
    ontology_hits: number;
    latency_ms?: number;
  };
  evidence?: Array<{ citation: string }>;
  loading: boolean;
}
```

**상태별 UI**:
- `loading=true`: 점멸 스피너 + "AI가 답변을 생성하고 있습니다…" (2~5초 예상)
- `llm_used=false`: 상단에 `⚠ LLM 미연결 — 템플릿 답변` 경고 뱃지
- `fallback_used=true`: 상단에 `⚠ fallback 사용됨` 경고 뱃지

### 3.3 온톨로지 질의 (`AIQuery.tsx`)

**변경 수준**: 대폭 — 핵심 변경 화면

**현재 (v2.0)**:
```
[질문 입력창] [질의 실행]
AI 답변
  descriptive
  Found 0 document result(s).
```

**v3.0 목표**:
```
[질문 입력창] [질의 실행]

AI 답변  [descriptive] [LLM ✓]
  Snowflake는 클라우드 기반 데이터 웨어하우스로 서버리스
  아키텍처를 채택하여 스토리지와 컴퓨팅을 분리합니다.
  [출처: doc-001 p.3] [출처: doc-002 p.7]
  ─────────────────────────
  신뢰도 89% | 응답 1.3s | 문서 5건 참조

온톨로지 근거 (1건)
  [PRODUCT] Snowflake  doc-001 p.3 · 91%
    "Snowflake is a serverless ingestion service."

실행 트레이스 ▾
  planner: intent=descriptive
  vector.search: hits=5
  llm.synthesize: 1247ms
```

**레이아웃 변경**:
- 결과 영역을 3개 섹션으로 분리: `LlmAnswerPanel` / `OntologyEvidenceList` / 트레이스 (접기 가능)
- 로딩 중: 스피너 + "AI가 답변 생성 중… (최대 10초 소요)" 표시

**타입 변경** (`types/api.ts`):
```typescript
interface HybridAskResponse {
```

## 8. UX 고려 사항

### 8.1 LLM 응답 지연 (2~5초)

- 질의 버튼 클릭 즉시 버튼 비활성화 + "AI 답변 생성 중…" 스피너
- 10초 초과 시 타임아웃 토스트: "응답 시간이 초과됐습니다. 다시 시도하세요."
- LLM 응답 중 다른 탭 이동 가능 (요청 abort 안 함)

### 8.2 LLM 미연결 상태 (GEMINI_API_KEY 없음)

- 모든 질의 화면 상단에 `⚠ LLM 미연결 — 템플릿 답변 모드` 배너 표시
- 기능은 동작하되 답변 품질이 낮음을 명시

### 8.3 Provenance 없는 엔티티 (기존 v2.0 데이터)

- Provenance 필드가 없는 엔티티: "출처 정보 없음" 회색 표시
- 레이아웃 깨짐 없이 graceful degradation
