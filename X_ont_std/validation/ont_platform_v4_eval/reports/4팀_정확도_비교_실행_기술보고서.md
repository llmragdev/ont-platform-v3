## 1. 목적

기존 `3팀_정확도_비교.xlsx`의 핵심 탭인 `문항별 비교 상세` 24문항을 기준으로 `ont_platform v4`를 동일 조건에서 재평가했다.  
기존 Team0~2의 답변과 점수는 원본 엑셀에서 그대로 가져오고, `ont_platform v4` 결과는 `Team4 (ont_platform v4)`로 추가했다.

중요: 기존에 별도로 산출된 `ont_platform v4 76.30%`는 30문항 단독 평가 결과라서 최종 4팀 비교 기준으로 쓰지 않았다. 최종 비교 기준은 동일 24문항 재평가 결과인 `67.50%`이다.

## 5. 평가 입력

원본 비교 엑셀:

```text

```

평가 대상 PDF:

```text
E:\ai_lab_SIT\target_doc\*.pdf
```

PDF는 회사 프로젝트 폴더의 원본 문서를 참조한다. 비교 문항과 예상 답변은 개인연구 폴더의 `data`에 복사해 두었다.

## 6. 실행 방식

`src\build_exact_4team_workbook.py`가 전체 평가를 수행한다.

실행 흐름:

1. `data\3팀_정확도_비교.xlsx`의 `문항별 비교 상세` 탭에서 24문항과 예상 답변을 읽는다.
2. `E:\ai_lab_SIT\target_doc`의 PDF 8개를 ont_platform v4 평가 프로젝트에 업로드한다.
3. FastAPI `TestClient`로 v4 backend의 `POST /api/hybrid/ask`를 호출한다.
4. 각 문항의 Team4 답변, 검색 근거, 응답 시간, vector hits를 저장한다.
5. Gemini LLM judge로 예상 답변 대비 Team4 답변 정확도를 0~100점으로 채점한다.
6. 기존 Team0~2 결과와 Team4 결과를 합쳐 `reports\4팀_정확도_비교.xlsx`를 생성한다.

사용 엔드포인트:

```text
POST /api/documents/upload
POST /api/hybrid/ask
```

## 9. 주의사항

1. `Team4`는 `ont_platform v4`를 의미한다. 기존에 별도 Team3이 있으므로 `Team3`으로 표기하지 않는다.
2. `76.30%`는 이전 30문항 단독 평가 결과이며, 최종 4팀 비교 기준이 아니다.
3. 최종 비교는 `문항별 비교 상세`의 24문항을 기준으로 한다.
4. `3팀_정확도_비교.xlsx` 내부의 요약 탭 평균과 상세 탭 기반 평균이 약간 다르다. 최종 파일에는 이 차이를 `원본 요약 대조` 탭에 표시했다.
5. Team4 점수는 Gemini LLM judge 기반 자동 채점이다. 최종 승인 전에는 낮은 점수 문항, 특히 `STD-S-06`, `STD-A-05`, `STD-S-08`을 우선 수동 검토하는 것이 좋다.
6. 재실행 시 Gemini API 키가 필요하다. 스크립트는 `ont_platform\v3\.env`에서 `GEMINI_API_KEY` 또는 `GEMINI_API_KEY1~4`를 읽는다.
