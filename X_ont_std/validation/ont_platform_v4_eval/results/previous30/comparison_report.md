## 6. 검증상 주의점

1. 이 보고서는 **ont_platform v4 직접 평가 결과**입니다. 이전 `validation_report.md`처럼 Team0 개선 시나리오를 추정한 문서가 아닙니다.
2. v4는 `GEMINI_API_KEY`를 사용해 임베딩과 LLM 답변 생성을 수행했습니다.
3. v4의 Chroma score는 거리형 점수이므로 기존 평가 산식의 “검색 연관성”에 맞게 `1 / (1 + distance)` 형태로 정규화했습니다.
4. Team0 산출물은 `summary.txt`와 `detailed_results.json` 수치가 충돌하므로, 비교표를 두 기준으로 분리했습니다.
5. 이 결과는 자동 키워드 기반 평가입니다. 최종 배포 전에는 30개 답변에 대한 사람 검수 또는 LLM-as-judge 보조 평가를 추가하는 것이 좋습니다.
