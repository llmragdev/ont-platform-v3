# DB 초기화 및 복원 도구 매뉴얼 (reset_tool)

본 폴더는 시나리오 1(고객 문의 자동댓글) 및 시나리오 2(공장 고장 반복 대응) 통합 테스트 도중 모의 게시판 시스템의 데이터를 빠르고 안전하게 원복(Reset)하기 위한 유틸리티를 포함하고 있습니다.

---

## 📋 1. 도구 소개

`reset_boards.py` 스크립트는 시나리오 테스트 과정에서 워크플로우에 의해 자동으로 등록된 댓글 및 정비지시 데이터를 삭제하고, 이벤트 상태를 다시 'open'으로 변경하여 **시나리오 시연 및 테스트를 반복적으로 수행할 수 있게 돕는 도구**입니다.

### 🛡️ 데이터 안전 보존 원칙
본 도구는 데이터 전체를 무차별 삭제하지 않고 테스트 시 필요한 참조 데이터를 철저히 보존합니다:
* **기본 게시물 & 고장 이벤트 보존**: 최초 시드 데이터인 홍길동 고객의 문의글(`q-001`) 및 공장의 배터리 탭 용접기 고장 이벤트(`fe-001`)의 내용과 기록 자체는 **절대 삭제되지 않습니다.**
* **기본 시드 댓글 보존**: 보드 시스템 기동 시 기본 설정되는 안내용 시드 댓글(Scenario 1의 `시스템봇` 접수 댓글 및 Scenario 2의 `system-bot` 접수 알림 댓글)은 **삭제 대상에서 제외되어 영구 보존**됩니다.
* **워크플로우 결과물만 삭제**: 오직 에이전트 워크플로우에 의해 자동 추가된 외부 댓글 및 정비 지시서 데이터만 타겟팅하여 삭제합니다.

---

## 🚀 2. 사용 방법 (Run)

PowerShell 혹은 CMD 터미널을 열고 다음 명령어를 순서대로 실행합니다.

### 2.1 사전 요구사항
가상환경 활성화 및 `mock_infras/` 폴더 또는 루트 폴더에서 명령어를 실행해야 합니다.

```powershell
# 1. 가상환경 활성화
conda activate claud_be
```

### 2.2 대화형 인터랙티브 메뉴 실행 (추천)
인수(Argument) 없이 명령어를 실행하면 터미널 화면에서 번호를 선택하는 대화형 메뉴가 표시됩니다.

```powershell
# 프로젝트 루트(X_ont_std)에서 실행 시
python mock_infras/reset_tool/reset_boards.py

# 또는 reset_tool 폴더로 이동하여 실행 시
cd E:\ontology_edu\X_ont_std\mock_infras\reset_tool
python reset_boards.py
```

### 2.3 커맨드 라인 옵션 및 단축 명령

스크립트 뒤에 옵션을 붙여 특정 작업만 대화형 메뉴 없이 즉각 처리할 수 있습니다.

#### A. 시나리오 1 & 2 기본 시드 데이터 동시 원복
기본 문의글(`q-001`)과 기본 고장 이벤트(`fe-001`)에 작성된 자동 댓글과 정비지시만 조준하여 안전하게 지우고 상태를 복원합니다.
```powershell
python mock_infras/reset_tool/reset_boards.py --s1 --s2
```

#### B. 데이터베이스 완전 초기화 (전체 데이터)
두 보드 DB의 모든 생성 댓글 및 정비지시를 삭제하고 모든 고장 이벤트를 `open` 상태로 원복합니다 (기본 시드글 및 시드 댓글은 여전히 보존됩니다).
```powershell
python mock_infras/reset_tool/reset_boards.py --all
```

#### C. 상세 옵션 스펙
```text
options:
  -h, --help     도움말 및 사용 가능한 명령어 리스트 출력
  --s1           시나리오 1 기본 게시물(q-001)의 워크플로우 댓글 삭제
  --s1-all       시나리오 1의 모든 워크플로우 댓글 삭제
  --s1-id S1_ID  시나리오 1 내 특정 Post ID를 지정하여 해당 글의 댓글 삭제
  --s2           시나리오 2 기본 이벤트(fe-001)의 워크플로우 응답/정비지시 삭제 및 open 원복
  --s2-all       시나리오 2의 모든 응답/정비지시 삭제 및 모든 이벤트 open 원복
  --s2-id S2_ID  시나리오 2 내 특정 Event ID를 지정하여 초기화
  --all          두 가상 인프라 데이터베이스의 모든 워크플로우 가공 데이터 완전 초기화
```
