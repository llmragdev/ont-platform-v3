## 🎯 평가 기준

각 평가 문서는 다음 항목을 포함합니다:

- **플랫폼 개요**: 핵심 기능 및 특징
- **온톨로지 지원 수준**: 구현 난이도, 성숙도
- **AI/RAG 통합**: LLM 활용 가능성
- **운영성 (DevOps)**: 배포, 모니터링, 유지보수
- **비용 효율성**: 라이선스, 유지비용
- **권장 사항**: v3 적용 가능성

## 🔄 활용 방법

### 기술 선택 시
1. 각 플랫폼의 평가 문서 검토
2. **온톨로지 구현 난이도** 비교
3. **AI 통합 수준** 확인
4. 프로젝트 요건과 매칭

### 비교 추가 필요 시
1. **새 평가 문서 작성**: `01_새플랫폼_통합 평가.md`
2. **기준에 따라 작성** (위 평가 기준 참고)
3. 기록 유지 (날짜 포함)
