**문서 번호**: 01  
**작성자**: Antigravity  
**작성일**: 2026-06-14  
**대상 시스템**: ont_platform v5  
**목적**: 온톨로지 지식 정보 및 축적된 워크플로우 통계 데이터를 대상으로, 복잡한 SPARQL/SQL 쿼리 작성 없이 사용자의 자연어 질문을 해석하여 실시간으로 통계 데이터를 조회하고 적절한 차트(막대, 선, 파이 등)로 시각화해 주는 **대화형 AI 분석기(AIP AI Analyst)** 화면 및 기능을 설계한다.

---

## 1. 설계 배경

현재 ont_platform v5는 온톨로지 객체 간의 관계를 보여주는 **'관계 탐색'** 화면을 내장하고 있다. 하지만 이 화면은 특정 장비나 이벤트 등 **개별 객체 인스턴스의 연결 상태(맥락)를 역추적하는 탐색 도구**에 최적화되어 있다.

실무 비즈니스 분석에서는 다음과 같은 **집계 및 통계 중심의 질문**에 신속하게 답할 수 있어야 한다.
- *"공장별로 최근 3개월간 가장 많이 반복 고장이 발생한 설비 5개는 무엇인가?"*
- *"고객 문의의 분류 카테고리별 비중과 평균 AI 답변 신뢰도를 원형 차트로 그려줘."*

이를 위해 팔란티어 AIP의 핵심 비주얼 요소인 **대화형 차트 대시보드(AIP AI Analyst)**의 개념을 차용하여, 자연어 질문 ➡️ 쿼리 자동 컴파일 ➡️ 실시간 차트 시각화로 이어지는 지능형 분석 시스템을 구축하고자 한다.

### 3.1 주요 UI 컴포넌트 명세
1. **Chat Pane (좌측 대화창)**:
   - 전형적인 메신저 UI 형태로 질문을 입력하고 응답을 실시간으로 확인한다.
   - 자주 묻는 추천 질문 가이드(e.g., *"문의 카테고리 분포 확인"*, *"라인별 수리 시간 비교"*) 퀵 버튼을 하단에 제공한다.
2. **Visualization Canvas (우측 시각화 캔버스)**:
   - 좌측 대화에서 AI가 생성해 낸 차트 오브젝트(Chart Object)가 있는 경우, 여기에 큰 영역으로 단독 렌더링된다.
   - 차트 하단에는 [Raw Data 보기 (Table 전환)] 토글 스위치와 [CSV 다운로드] 버튼을 배치하여 분석 신뢰성을 제공한다.

## 4. 백엔드 API 설계 (API Spec)

자연어 요청을 전송하고, 설명 텍스트, 원시 데이터, 그리고 시각화에 필요한 차트 구성 JSON 사양(Chart Spec)을 한 번에 반환받는다.

### 4.1 엔드포인트
```http
POST /api/assistant/analyze
```

### 4.2 요청 Body (JSON)
```json
{
  "query": "세종 공장의 라인별 고장 건수를 막대 그래프로 보여줘",
  "history": [
    {
      "role": "user",
      "content": "공장 데이터 분석 시작"
    },
    {
      "role": "assistant",
      "content": "어떤 공장 데이터를 분석해 드릴까요?"
    }
  ],
  "context": {
    "company_id": "demo-co",
    "project_id": "proj-01"
  }
}
```

### 4.3 응답 Body (JSON)
```json
{
  "answer": "세종 공장의 각 라인별 고장 발생 통계입니다. 1번 라인이 10건으로 가장 높은 장애율을 보입니다.",
  "compiled_query": "SELECT ?line (COUNT(?event) as ?count) WHERE { ?event a :FaultEvent; :has_line ?line } GROUP BY ?line",
  "chart_spec": {
    "type": "bar",
    "title": "세종 공장 라인별 고장 발생 건수",
    "labels": ["1번 조립 라인", "2번 조립 라인", "3번 조립 라인"],
    "datasets": [
      {
        "label": "고장 건수",
        "data": [10, 5, 8],
        "backgroundColor": ["#0d9488", "#0284c7", "#4f46e5"]
      }
    ]
  },
  "raw_data": [
    { "line": "1번 조립 라인", "count": 10 },
    { "line": "2번 조립 라인", "count": 5 },
    { "line": "3번 조립 라인", "count": 8 }
  ]
}
```

## 5. 핵심 프론트엔드 연동 (Recharts 라이브러리 연동)

차트의 세련된 렌더링을 위해 가볍고 반응형이 우수한 `Recharts` 라이브러리를 활용한다.

### 5.1 Dynamic Chart Renderer
AI가 반환한 `chart_spec`의 `type` 필드값에 따라 동적으로 차트 컴포넌트를 스위칭한다.

```typescript
import { BarChart, Bar, LineChart, Line, PieChart, Pie, XAxis, YAxis, Tooltip, ResponsiveContainer } from 'recharts';

function DynamicChart({ spec }) {
  if (!spec) return null;
  
  const chartData = spec.labels.map((label, idx) => ({
    name: label,
    value: spec.datasets[0].data[idx]
  }));

  switch(spec.type) {
    case 'bar':
      return (
        <ResponsiveContainer width="100%" height={350}>
          <BarChart data={chartData}>
            <XAxis dataKey="name" stroke="#64748b" fontSize={12} />
            <YAxis stroke="#64748b" fontSize={12} />
            <Tooltip cursor={{ fill: 'rgba(13, 148, 136, 0.05)' }} />
            <Bar dataKey="value" fill="#0d9488" radius={[4, 4, 0, 0]} />
          </BarChart>
        </ResponsiveContainer>
      );
    case 'line':
      return (
        <ResponsiveContainer width="100%" height={350}>
          <LineChart data={chartData}>
            <XAxis dataKey="name" stroke="#64748b" fontSize={12} />
            <YAxis stroke="#64748b" fontSize={12} />
            <Tooltip />
            <Line type="monotone" dataKey="value" stroke="#0d9488" strokeWidth={3} activeDot={{ r: 6 }} />
          </LineChart>
        </ResponsiveContainer>
      );
    default:
      return <div>지원하지 않는 차트 유형입니다.</div>;
  }
}
```

## 6. 기대 효과 및 시연 시나리오

1. **SPARQL 쿼리 자동화 입증**:
   - 관리자 화면의 `RDF 워크벤치`로 직접 쿼리를 수행해 보지 않아도, 질문만으로 SPARQL을 백엔드에서 생성하고 수행하여 결과를 도출하는 혁신적인 온톨로지 접근법을 시연합니다.
2. **시연 시나리오 예시**:
   - "최근 문의 카테고리 통계 보여줘" ➡️ 원형 차트로 카테고리 비중 확인.
   - "이 중 비밀번호 문의의 주차별 추이를 보여줘" ➡️ 선형 차트로 전환하여 추이 분석.
   - "관련 온톨로지 객체 확인해줘" ➡️ 우측 차트 하단의 `관계 탐색 바로가기` 버튼을 통해 Graph Explorer로 매끄럽게 연결.
