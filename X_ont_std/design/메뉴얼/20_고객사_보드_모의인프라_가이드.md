# 20. 고객사 보드 모의 인프라 가이드

**섹션**: 모의 인프라  
**포트**: 8090 (HTTP)  
**가상환경**: `claud_be`  
**위치**: `mock_infras/s1_customer_board`  
**관련 가이드**: [01_메뉴_네비게이션_가이드.md](./01_메뉴_네비게이션_가이드.md)

---

## 📋 개요

시나리오 1(고객 문의 자동댓글 및 온톨로지 매핑)의 연동 테스트 및 외부 시스템 시연을 위한 SQLite 기반 고객사 모의 게시판 시스템 구동 안내서입니다.

> [!NOTE]
> 본 보드 시스템은 실제 엔터프라이즈 환경의 고객 센터 게시판이나 ITSM 시스템을 모사하여 작동합니다.

---

## 🚀 구동 방법

PowerShell 혹은 CMD 터미널을 열고 다음 명령어를 실행하여 서버를 기동합니다.

```powershell
# 1. 가상환경 활성화
conda activate claud_be

# 2. 디렉토리 이동
cd E:\ontology_edu\X_ont_std\mock_infras\s1_customer_board

# 3. FastAPI/Uvicorn 서버 기동
python src/main.py
```

* **URL**: [http://localhost:8090](http://localhost:8090)
* **주요 구성 요소**:

  * **시뮬레이션 설정**: 수동 댓글 등록, 웹훅 토글, 모의 이벤트 발송 기능 제공

## 🗂️ 데이터베이스 명세 (SQLite)

서버가 구동되면 `s1_customer_board.db` 파일이 루트 폴더에 자동으로 생성되며, 아래 스키마를 갖습니다.

### `posts` 테이블 (고객 문의글)
| 컬럼 | 타입 | 제약조건 | 설명 |
|------|------|----------|------|
| `id` | TEXT | PRIMARY KEY | 문의글 고유 ID (예: `q-001`) |
| `title` | TEXT | NOT NULL | 제목 |
| `content` | TEXT | NOT NULL | 본문 내용 |
| `author` | TEXT | NOT NULL | 작성자 이름 |
| `status` | TEXT | DEFAULT 'open' | 상태 (`open`, `closed`) |
| `created_at` | TEXT | | 생성 시간 |

### `comments` 테이블 (등록된 댓글)
| 컬럼 | 타입 | 제약조건 | 설명 |
|------|------|----------|------|
| `id` | TEXT | PRIMARY KEY | 댓글 고유 ID |
| `post_id` | TEXT | FOREIGN KEY | 대상 문의글 ID |
| `author` | TEXT | NOT NULL | 작성자 (`system-bot`, `user` 등) |
| `content` | TEXT | NOT NULL | 댓글 본문 |
| `created_at` | TEXT | | 등록 시간 |

---

## 🔌 주요 API 규격

| HTTP Method | Endpoint | 설명 |
|-------------|----------|------|
| `GET` | `/api/posts` | 전체 문의글 목록 조회 |
| `GET` | `/api/posts/{post_id}` | 특정 문의글 상세 조회 |
| `POST` | `/api/posts/{post_id}/comments` | 특정 문의글에 댓글 등록 |
| `GET` | `/api/posts/{post_id}/comments` | 특정 문의글의 댓글 조회 |
