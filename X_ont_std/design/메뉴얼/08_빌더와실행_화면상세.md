# 빌더와 실행 - 화면 상세 가이드

**메뉴**: 빌더와 실행  
**목적**: 워크플로우 시각적 설계 및 실행  
**현재 상태**: MVP (기본 캔버스)  
**향후 계획**: 고급 노드 타입, 조건부 분기, 병렬 처리

---

## 📐 현재 화면 구조

```
┌────────────────────────────────────────────────────────┐
│ [←] 워크플로우_alpha [저장] [실행▶] [공유] [삭제]    │ ← 헤더
├────────────────────────────────────────────────────────┤
│                                                        │
│  ┌─ 캔버스 영역 (좌측 70%) ───────────────────────┐  │
│  │                                               │  │
│  │    [START]                                   │  │
│  │       │                                      │  │
│  │       ├→ [Skill_1: ontology-write]          │  │
│  │       │       │                              │  │
│  │       │       └→ [Skill_2: rag-lookup]      │  │
│  │       │               │                      │  │
│  │       └→ [END]←───────┘                     │  │
│  │                                               │  │
│  │  [+ 노드 추가] [🔗 연결] [⚙️ 설정]          │  │
│  │                                               │  │
│  └───────────────────────────────────────────────┘  │
│  │                                                        │
│  ├─ 속성 패널 (우측 30%) ──────────────────────────┐  │
│  │ 선택: Skill_1 (ontology-write)                 │  │
│  │                                                 │  │
│  │ 📋 기본 정보                                   │  │
│  │  ID: skill_1                                  │  │
│  │  스킬: ontology-write                         │  │
│  │  버전: 1.0                                    │  │
│  │                                                 │  │
│  │ 🔗 입력 매핑                                  │  │
│  │  [탭: 입력 매핑 | 탭: 온톨로지 매핑]       │  │
│  │                                                 │  │
│  │  필드 | 값 유형 | 입력값                      │  │
│  │  entityType | literal | "Project" [검증✓]  │  │
│  │  properties | expr | {{nodes.start.output}} │  │
│  │  relations | literal | [] [검증✓]           │  │
│  │                                                 │  │
│  │  [+ 매핑 추가]                               │  │
│  │                                                 │  │
│  │ 📤 온톨로지 매핑                             │  │
│  │  [매핑 설정]                                 │  │
│  │                                                 │  │
│  │ [저장] [취소]                                │  │
│  └─────────────────────────────────────────────────┘  │
│                                                        │
├────────────────────────────────────────────────────────┤
│ 상태: 편집 중 (수정되지 않은 상태)  | [저장하기]    │
└────────────────────────────────────────────────────────┘
```

## 🎯 UI 컴포넌트 상세

### 1. 캔버스 영역

**노드 표현**:
```
┌──────────────────┐
│ [아이콘] 노드명  │ ← 타이틀
│                  │
│ 상태: ○          │ ← 실행 상태 (회색:대기, 녹색:성공, 빨강:실패)
│                  │
│ [입력 포트]│[출력 포트]
└──────────────────┘
```

**노드 타입**:
- START (초록색)
- END (빨간색)
- Skill (파란색)
- Condition (주황색, Phase 2)
- Parallel (보라색, Phase 2)

**캔버스 조작**:
- 드래그: 노드 이동
- Shift+드래그: 캔버스 이동
- 휠: 줌 인/아웃
- 더블클릭: 노드 편집

### 2. 입력 매핑 에디터

```
┌─────────────────────────────────────────┐
│ 입력 매핑 (Input Mapping)               │
├─────────────────────────────────────────┤
│                                         │
│ 필드 | 타입 | 값 | 검증 상태 | 액션   │
├─────────────────────────────────────────┤
│ entityType | string | 기본값 선택 | ✓ │
│            │        | "Project"    |   │
│            │        │              | [X]
│            │        │              │   │
│ properties │ object │ 표현식 입력  | ✓ │
│            │        │ {{nodes.s...}}  │
│            │        │              | [✎]
│            │        │              │   │
│ relations  │ array  │ 기본값 선택  | ✓ │
│            │        │ []           |   │
│            │        │              | [X]
│                                         │
│ [+ 필드 추가]                           │
│                                         │
└─────────────────────────────────────────┘
```

**자동완성**:
- `{{` 입력 시 드롭다운 표시
- `nodes.` 입력 시 이전 노드 목록
- `output.` 입력 시 해당 노드의 출력 필드

**검증**:
- ✓: 유효한 입력
- ⚠️: 경고 (타입 변환됨)
- ✗: 오류 (필수 필드 누락 등)

### 3. 온톨로지 매핑 탭

```
┌──────────────────────────┐
│ 온톨로지 매핑            │
├──────────────────────────┤
│                          │
│ 이 노드의 결과를         │
│ 온톨로지에 저장하기     │
│                          │
│ 엔티티 타입: [Project▼] │
│                          │
│ 속성 매핑:               │
│ output.entityId →        │
│   ontology.id            │
│                          │
│ output.saved →           │
│   ontology.isStored      │
│                          │
│ [+ 매핑 추가]            │
│ [저장]                   │
│                          │
└──────────────────────────┘
```

## 🚀 향후 추가 기능

### 📌 Phase 2 - 고급 노드 타입

- [ ] **Condition 노드**: IF/ELSE 분기
  ```
  status == "active"?
    ├→ [참 경로]
    └→ [거짓 경로]
  ```

- [ ] **Parallel 노드**: 병렬 실행
  ```
  [병렬 시작]
    ├→ [작업 A]
    ├→ [작업 B]
    └→ [작업 C]
  [병렬 종료 (모두 완료 대기)]
  ```

- [ ] **Loop 노드**: 반복 처리
  ```
  FOR EACH item IN items:
    └→ [작업]
  ```

### 🎯 Phase 2 - UI 개선

- [ ] **컨텍스트 메뉴**: 우클릭 → 복사, 삭제, 복제
- [ ] **Undo/Redo**: Ctrl+Z / Ctrl+Y
- [ ] **노드 검색**: Ctrl+F로 노드명 검색
- [ ] **자동 정렬**: 레이아웃 자동 정렬
- [ ] **노드 그룹화**: 여러 노드 선택 후 그룹화

### 🔧 Phase 2 - 고급 기능

- [ ] **변수 정의**: 워크플로우 전역 변수
- [ ] **에러 핸들링**: Try-Catch 노드
- [ ] **로깅**: 노드별 로그 출력 설정
- [ ] **성능 프로파일링**: 노드별 실행 시간 분석
