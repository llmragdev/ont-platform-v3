# 25. 통합 모의 인프라 실행 가이드

**섹션**: 모의 인프라  
**대상 버전**: `ont_platform v5`  
**목적**: 5개 컴포넌트 통합 시동 및 데모 시나리오 연동 기동  
**관련 가이드**: [01_메뉴_네비게이션_가이드.md](./01_메뉴_네비게이션_가이드.md), [20_고객사_보드_모의인프라_가이드.md](./20_고객사_보드_모의인프라_가이드.md) ~ [24_보드_초기화_도구_가이드.md](./24_보드_초기화_도구_가이드.md)

---

## 📋 개요

온톨로지 콘솔 및 에이전트 자동화의 통합 시연과 테스트를 위해 전체 모의 인프라 컴포넌트를 올바른 순서로 구동하고, 데모 시나리오 연동을 기동 및 검증하는 종합 안내서입니다.

## 🚀 단계별 구동 프로세스

서버 간 의존성을 고려하여 반드시 다음 순서로 각 컴포넌트를 기동해 주시기 바랍니다.

### Step 1. 모의 게시판(Boards) 구동 (포트 8090, 8091)
중계 서버(MCP)와 플랫폼이 통신할 대상 REST API 백엔드를 먼저 구동합니다.
* **PowerShell 창 1 (고객사 보드)**:
  ```powershell
  conda activate claud_be
  cd E:\ontology_edu\X_ont_std\mock_infras\s1_customer_board
  python src/main.py
  ```
* **PowerShell 창 2 (공장 보드)**:
  ```powershell
  conda activate claud_be
  cd E:\ontology_edu\X_ont_std\mock_infras\s2_factory_board
  python src/main.py
  ```

### Step 2. MCP 중계 서버(MCPs) 구동 (포트 8080, 8081)
표준 MCP 프로토콜 요청을 게시판 REST API로 변환해 주는 게이트웨이를 구동합니다.
* **PowerShell 창 3 (고객사 MCP)**:
  ```powershell
  conda activate claud_be
  cd E:\ontology_edu\X_ont_std\mock_infras\s1_customer_mcp
  python src/main.py
  ```
* **PowerShell 창 4 (공장 MCP)**:
  ```powershell
  conda activate claud_be
  cd E:\ontology_edu\X_ont_std\mock_infras\s2_factory_mcp
  python src/main.py
  ```

### Step 3. 온톨로지 콘솔 플랫폼 구동 (포트 3002, 8001)
* **PowerShell 창 5 (FastAPI 백엔드)**:
  ```powershell
  conda activate claud_be
  cd E:\ontology_edu\X_ont_std\ont_platform\v5\backend
  python -m uvicorn app.main:app --reload --port 8001
  ```
* **PowerShell 창 6 (Next.js 프론트엔드)**:
  ```powershell
  conda activate claud_fe
  cd E:\ontology_edu\X_ont_std\ont_platform\v5\frontend
  npm run dev
  ```

## 🛠️ 통합 구동 여부 검증 체크리스트

모든 서버가 켜진 후, 연동에 문제가 없는지 아래 주소들을 통해 점검합니다.

- [ ] **고객사 보드**: 브라우저에서 [http://localhost:8090](http://localhost:8090) 접속 확인
- [ ] **공장 보드**: 브라우저에서 [http://localhost:8091](http://localhost:8091) 접속 확인
- [ ] **고객사 MCP**: 브라우저에서 [http://localhost:8080/health](http://localhost:8080/health) 응답 `status: ok` 확인
- [ ] **공장 MCP**: 브라우저에서 [http://localhost:8081/health](http://localhost:8081/health) 응답 `status: ok` 확인
- [ ] **온톨로지 콘솔 FE**: 브라우저에서 [http://localhost:3002](http://localhost:3002) 대시보드 및 메뉴 표시 확인

## 🔄 반복 시뮬레이션 및 데이터 원복

시연을 마친 후 혹은 다음 시연 테스트를 준비할 때는 초기화 도구를 통해 데이터를 정비합니다.

```powershell
# 프로젝트 루트 혹은 reset_tool 디렉토리에서 실행
python mock_infras/reset_tool/reset_boards.py --all
```
위 명령어를 실행하면 게시판에 등록되었던 댓글과 정비지시서만 안전하게 삭제되며 이벤트 상태가 다시 `open`으로 초기화되어, 다음 시연을 처음부터 깨끗하게 다시 보여줄 수 있습니다.
