
### AI 질의 예시

```
자연어 입력                     → AI 생성 쿼리 → 결과

"Project-Alpha의 팀은?"       → SELECT ?team WHERE {...} → [Team-AI, Team-Finance]

"가장 많은 멤버를 가진 팀"    → SELECT ?team COUNT(?member) GROUP BY ?team → [Team-AI: 12명]

"2026년 예산 > 1M인 프로젝트" → SELECT ... FILTER (?budget > 1000000) → [Project-Alpha, ...]

"Team-AI와 관련된 모든 문서"  → SELECT ?doc WHERE {?doc relatedTo ?team} → [doc1.pdf, ...]
```

### 신뢰도 및 검증

```
신뢰도: 87%
- SPARQL 문법: ✓ 올바름
- 쿼리 논리: ✓ 의도 반영
- 결과 개수: ✓ 예상 범위

⚠️ 낮은 신뢰도 (< 70%) 경고:

   [쿼리 수정] [SPARQL 콘솔로 이동]
```

### RAG 작동 방식

```
1. 질의 임베딩
   └─ 자연어 질의 → 벡터 변환

2. 유사도 검색
   └─ 저장된 문서 청크와 비교
   └─ 상위 K개 (기본 3개) 추출

3. 컨텍스트 구성
   └─ 유사 청크 병합
   └─ 길이 제한 (기본 2000 토큰)

4. LLM 답변 생성
   └─ 프롬프트: "다음 문서 기반으로 답변..."
   └─ 답변 + 출처 인용

5. 신뢰도 계산
   ├─ 유사도 점수 (0-100)
   ├─ 문서 신뢰성 (메타데이터 기반)
   └─ 최종 신뢰도 = 가중 평균
```

### 문서 관리

**업로드**:
```
1. [문서 업로드] 또는 드래그&드롭
2. 문서 선택 (PDF, Word, Excel, Markdown, TXT)
3. 메타데이터 입력
   ├─ 제목
   ├─ 설명
   ├─ 태그
   └─ 소유자
4. [업로드] → 자동 인덱싱
```

**필터링**:
```

- 업로드자: 팀원별
- 신뢰도: 60%, 70%, 80%, 90%
- 태그: [프로젝트] [위험] [마일스톤] 등
```

### SPARQL 쿼리 종류

**SELECT** (데이터 조회):
```sparql
SELECT ?project ?budget
WHERE {
  ?project rdf:type ont:Project ;
           ont:budget ?budget ;
           ont:status "active" .
  FILTER (?budget > 1000000)
}
ORDER BY DESC(?budget)
LIMIT 10
```

**CONSTRUCT** (새 RDF 생성):
```sparql
CONSTRUCT {
  ?project ont:highBudget true
}
WHERE {
  ?project ont:budget ?b .
  FILTER (?b > 5000000)
}
```

**DESCRIBE** (엔티티 전체 설명):
```sparql
DESCRIBE ?project
WHERE {
  ?project rdf:type ont:Project ;
           rdf:label "Project-Alpha"
}
```

**ASK** (존재 여부 확인):
```sparql
ASK {
  entity:proj_001 ont:status "active"
}
```
