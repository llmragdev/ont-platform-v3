## 🎯 주요 기능

### 필터
```
사용자: alice, bob, charlie 중 선택
활동타입: entity-create, entity-update, workflow-execute 등
리소스: 엔티티, 워크플로우, 스킬 등
날짜: 지난 7일, 이달, 3개월, 커스텀
결과: 성공, 실패, 모두
```

### 로그 테이블
- 시간순 정렬
- 활동 아이콘 (✓, ✗, ⚠️)
- 클릭 시 상세 정보

### 상세 보기
- 변경 전/후 (Diff 뷰)
- IP 주소, User Agent
- [복원]: 이전 상태로 되돌리기 (ADMIN만)
