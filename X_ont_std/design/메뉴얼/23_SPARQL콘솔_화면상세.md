# SPARQL 콘솔 - 화면 상세 가이드

**메뉴**: SPARQL 콘솔  
**목적**: 전문가용 정형 쿼리 작성 및 실행

---

## 📐 화면 구조

```
┌──────────────────────────────────────────┐
│ [실행▶] [포맷: JSON▼] [저장] [이력]     │
├──────────────────────────────────────────┤
│                                          │
│ SELECT ?project ?budget                 │ ← 에디터
│ WHERE {                                 │   (구문 강조)
│   ?project rdf:type ont:Project ;      │
│            ont:budget ?budget .         │
│   FILTER (?budget > 1000000)            │
│ }                                        │
│ ORDER BY DESC(?budget)                   │
│ LIMIT 10                                 │
│                                          │
├──────────────────────────────────────────┤
│ ⚡ 성능 (245ms) | 결과: 5행             │
├──────────────────────────────────────────┤
│                                          │
│ project | budget                         │ ← 결과 테이블
│ ─────────────────────                   │
│ entity_proj_001 | 5000000               │
│ entity_proj_002 | 3000000               │
│ entity_proj_003 | 2500000               │
│ ...                                      │
│                                          │
│ [CSV] [JSON] [RDF/XML]                 │
│                                          │
└──────────────────────────────────────────┘
```

---

## 🎯 주요 기능

### 쿼리 에디터
- 구문 강조 (PREFIX, SELECT, WHERE 등)
- 자동완성 (Ctrl+Space)
- 라인 번호

### 실행
- [실행▶] 버튼
- 결과 포맷 선택 (JSON, CSV, XML, RDF)
- 성능 메트릭 표시

### 결과 시각화
- 테이블 (기본)
- JSON 뷰
- 다운로드

### 이력
- 최근 실행한 쿼리 목록
- 클릭하면 불러오기
