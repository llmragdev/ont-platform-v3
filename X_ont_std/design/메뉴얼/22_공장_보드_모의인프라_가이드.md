# 22. 공장 보드 모의 인프라 가이드

**섹션**: 모의 인프라  
**포트**: 8091 (HTTP)  
**가상환경**: `claud_be`  
**위치**: `mock_infras/s2_factory_board`  
**관련 가이드**: [01_메뉴_네비게이션_가이드.md](./01_메뉴_네비게이션_가이드.md)

---

## 📋 개요

시나리오 2(공장 고장 반복 대응 흐름)의 통합 테스트 및 시연을 위한 SQLite 기반 공장 모의 게시판 시스템 구동 안내서입니다.

> [!NOTE]
> 본 시스템은 스마트 팩토리 환경에서 설비 고장 이벤트 수집 및 설비 보전 정비지시서(Work Order) 등록 시스템을 모사합니다.

---

## 🚀 구동 방법

PowerShell 혹은 CMD 터미널을 열고 다음 명령어를 실행하여 서버를 기동합니다.

```powershell
# 1. 가상환경 활성화
conda activate claud_be

# 2. 디렉토리 이동
cd E:\ontology_edu\X_ont_std\mock_infras\s2_factory_board

# 3. FastAPI/Uvicorn 서버 기동
python src/main.py
```

### 구동 성공 로그 예시

## 🖥️ 화면 및 인터페이스 구성

서버 구동 후 웹 브라우저를 통해 모의 스마트 팩토리 제어 콘솔에 접속할 수 있습니다.

* **URL**: [http://localhost:8091](http://localhost:8091)
* **디자인 테마**: 오렌지/앰버 색상의 프리미엄 다크 인더스트리얼 테마
* **주요 구성 요소**:
  * **설비 고장 이벤트 로그**: 배터리 탭 용접기 고장 이벤트(`fe-001`) 등의 실시간 발생 내역 조회
  * **정비지시서 요약 패널**: 에이전트에 의해 자동 등록된 정비 의뢰서 및 우선순위 모니터링
  * **데모 이벤트 주입 버튼**: 클릭 한 번으로 가상의 고장 시나리오를 게시판 데이터에 동적 주입 및 웹훅 송출

## 🗂️ 데이터베이스 명세 (SQLite)

서버 구동 시 `s2_factory_board.db` 데이터베이스가 자동 빌드되며, 아래 테이블에 데이터가 누적됩니다.

### `events` 테이블 (설비 고장 이벤트)
| 컬럼 | 타입 | 제약조건 | 설명 |
|------|------|----------|------|
| `id` | TEXT | PRIMARY KEY | 고장 이벤트 ID (예: `fe-001`) |
| `equipment_id` | TEXT | NOT NULL | 설비 ID |
| `description` | TEXT | NOT NULL | 고장 상태 요약 및 설명 |
| `priority` | TEXT | | 우선순위 (`low`, `medium`, `high`, `critical`) |
| `status` | TEXT | DEFAULT 'open' | 이벤트 처리 상태 (`open`, `resolved`) |
| `created_at` | TEXT | | 발생 일시 |

### `work_orders` 테이블 (정비지시서)
| 컬럼 | 타입 | 제약조건 | 설명 |
|------|------|----------|------|
| `id` | TEXT | PRIMARY KEY | 정비지시서 고유 ID |
| `event_id` | TEXT | FOREIGN KEY | 대상 고장 이벤트 ID |
| `equipment_id` | TEXT | NOT NULL | 설비 ID |
| `instructions` | TEXT | NOT NULL | 정비 작업 지시 세부 내용 |
| `priority` | TEXT | | 정비 긴급도 |
| `created_at` | TEXT | | 등록 일시 |

---

## 🔌 주요 API 규격

| HTTP Method | Endpoint | 설명 |
|-------------|----------|------|
| `GET` | `/api/events` | 전체 고장 이벤트 리스트 조회 |
| `GET` | `/api/events/{event_id}` | 특정 고장 이벤트 정보 상세 조회 |
| `POST` | `/api/events/{event_id}/work-orders` | 정비지시서 생성 및 등록 |
| `GET` | `/api/events/{event_id}/work-orders` | 특정 고장 연계 정비지시서 조회 |
