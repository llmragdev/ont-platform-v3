# 워크플로우 홈 - 화면 상세 가이드

**메뉴**: 워크플로우 홈  
**목적**: 모든 워크플로우의 중앙 대시보드  
**현재 상태**: MVP (기본 기능)

## 🎯 UI 컴포넌트 상세

### 1. KPI Panel (주요 지표)

**카드 1: 활성 워크플로우**
```
┌─────────────────────┐
│ 활성 워크플로우     │ ← 라벨
│ 42개                │ ← 숫자 (큰 폰트)
│ ↑ 5개 (증가)       │ ← 추세
└─────────────────────┘
```
- **표시 정보**: 활성 상태의 워크플로우 총 개수
- **클릭**: → [워크플로우 필터 적용]

**카드 2: 이달 실행**
```
245회 실행 / 이달
```
- **표시 정보**: 6월 총 실행 횟수
- **추세**: 지난달 대비 +3.2%

**카드 3: 성공률**
```
94.2% 성공
47개 실패 (지난 7일)
```
- **색상**: 초록색(>90%), 주황색(80-90%), 빨강색(<80%)
- **클릭**: → [실패 항목 상세]

### 2. 성능 트렌드 차트

**차트 타입**: Line Chart (다중 시리즈)
```
Y축: 실행 횟수 (0-300)
X축: 날짜 (2026-05-15 ~ 2026-06-14)
시리즈:
  - 성공 (파란색)
  - 실패 (빨간색)
  - 실행 중 (노란색)
```

**대화형 기능**:
- 마우스 호버: 날짜별 상세 숫자 표시
- 범례 클릭: 시리즈 숨김/표시
- 드래그: 특정 기간 확대

### 3. 최근 템플릿 카드

```
┌────────────────────────┐
│  [아이콘]             │
│  템플릿 제목          │
│  짧은 설명 텍스트    │
│                        │
│  작성자: alice        │
│  수정일: 2026-06-10   │
│  사용 횟수: 15회       │
│                        │
│  [복제] [미리보기]   │
└────────────────────────┘
```

**정렬 순서**:
- 기본: 최신 수정순
- 옵션: 인기순, 사용 빈도순

### 4. 최근 실행 타임라인

```
실행 아이콘 | 시간 | 상태 | 워크플로우명 | 실행 시간 | [상세]
─────────────────────────────────────────────────────────
✓         | 10:30 | 완료 | workflow_a  | 2.5초   | [→]
✗         | 09:15 | 실패 | workflow_b  | 5.2초   | [→]
⏳        | 01:20 | 실행 | workflow_c  | (진행중)| [→]
```

**인터랙션**:
- 행 클릭: → [실행 추적 화면]
- 상태 아이콘 호버: 에러 메시지 표시
- 우측 스크롤: 더 많은 항목 로드

## 🔄 사용자 플로우

### 플로우 1: 새 워크플로우 시작
```
1. [새 워크플로우] 클릭
2. 빈 캔버스 또는 템플릿 선택
3. → 빌더와 실행 메뉴로 이동
```

### 플로우 2: 최근 실행 확인
```
1. 최근 실행 타임라인에서 항목 클릭
2. → 실행 추적 화면으로 이동
3. 노드별 상세 확인
```

### 플로우 3: 템플릿 복제
```
1. 템플릿 카드에서 [복제] 버튼
2. 새 이름 입력 팝업
3. 빌더와 실행에서 자동 오픈
```

## 📊 데이터 로딩

### 초기 로드 (First Paint)
```
1. 기본 KPI (메모리 캐시): <100ms
2. 차트 (API): 200-500ms
3. 템플릿 목록 (API): 500-800ms
4. 실행 타임라인 (API): 800-1000ms
```

**최적화**:
- KPI는 별도 빠른 엔드포인트
- 차트는 Lazy Load
- 타임라인은 가상 스크롤 (처음 20개만 렌더)
