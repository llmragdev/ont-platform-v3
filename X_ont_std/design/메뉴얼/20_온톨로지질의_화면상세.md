# 온톨로지 질의 (AI) - 화면 상세 가이드

**메뉴**: 온톨로지 질의  
**목적**: AI 기반 자연어 → SPARQL 변환

---

## 📐 화면 구조

```
질의 입력:
┌──────────────────────────────────┐
│ "6월에 시작한 활성 프로젝트?"  │
│                                 │
│ 예시: "Project-Alpha의 팀은?" │
│      "가장 많은 예산은?"       │
│                                 │
│ [질의 실행]                     │
└──────────────────────────────────┘

↓ AI 생성 SPARQL ↓

┌─ 생성된 쿼리 ──────────────────────┐
│ SELECT ?project ?status           │
│ WHERE {                           │
│   ?project rdf:type ont:Project ;│
│            ont:status "active" .  │
│   FILTER (MONTH(?startDate) = 6)│
│ }                                 │
│ ORDER BY ?startDate DESC         │
│                                  │
│ 신뢰도: 87%                       │
│ ☐ 쿼리 수정 모드                │
│                                  │
└──────────────────────────────────┘

↓ 결과 ↓

┌─ 결과 (2개 항목) ───────────────┐
│ Project | Status | Start Date  │
├──────────────────────────────────┤
│ P-Alpha │ active │ 2026-01-01 │
│ P-Beta  │ active │ 2026-02-15 │
│                                 │
│ [테이블] [그래프] [다운로드]   │
└──────────────────────────────────┘

🕐 최근 질의
  • "6월에 시작한 활성 프로젝트는?" (2m 전)
  • "Team-AI 멤버는?" (1h 전)
```

---

## 🎯 주요 기능

### AI 질의 입력
- 자연어 입력 필드
- 예시 버튼 클릭
- [질의 실행] 버튼

### SPARQL 생성
- 신뢰도 표시 (백분율)
- 쿼리 수정 모드 토글
- SPARQL 문법 하이라이트

### 결과 시각화
- 테이블 뷰
- 그래프 뷰
- CSV/JSON 다운로드
