## 🔍 관계 탐색

**목적**: 온톨로지 엔티티와 관계를 그래프로 시각화 및 탐색  
**주요 기능**:
- 인터랙티브 그래프 시각화
- 엔티티 검색 및 필터링
- 관계 패턴 분석
- 이웃 노드 확장

### 인터페이스 구성

```
┌──────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────┤
```

### 기본 작업

**엔티티 검색**:
```
1. 검색창에 엔티티명 또는 ID 입력
2. Enter 또는 [검색] 버튼
3. 결과 리스트 표시
4. 원하는 엔티티 선택 → 그래프 중앙에 표시
```

**그래프 네비게이션**:
```
마우스:
├─ 클릭: 노드 선택
├─ 더블클릭: 상세 정보 표시
├─ 우클릭: 컨텍스트 메뉴 (편집, 삭제, 분석)
├─ 드래그: 노드 이동
├─ 마우스휠: 줌 인/아웃
└─ Shift+드래그: 팬(이동)

키보드:
├─ Ctrl+F: 검색
├─ Delete: 선택 노드 삭제
├─ +: 이웃 노드 확장
└─ -: 그래프 축소
```

**이웃 노드 탐색**:
```
1. 노드 클릭으로 선택
2. [+] 또는 [Ctrl+클릭]로 이웃 확장
3. 깊이 지정 (1단계, 2단계, 3단계)
   └─ 깊이: 노드로부터 몇 칸 떨어진 노드까지 표시
4. 그래프에 새로운 노드 및 관계 추가
```

### 고급 분석

**경로 분석**:
```
1. 시작 노드 선택 → 종료 노드 선택
2. [경로 찾기]
3. 최단 경로 강조 표시
4. 경로상 모든 관계 표시
```

**통계 분석**:
```
- 노드 수, 엣지 수
- 클러스터링 계수
- 중심성 (centrality) 분석
- 관계 유형별 분포
```

**필터링**:
```
엔티티 타입: [선택/체크박스]
├─ Project ☐
├─ Team ☐
├─ Member ☐
└─ ...

관계 유형: [선택/체크박스]
├─ hasTeam ☐
├─ hasMember ☐
└─ ...

시간 범위: [날짜 선택]
```

## ⚙️ 스키마 관리

**목적**: 온톨로지의 데이터 구조 정의 (엔티티 타입, 관계 타입, 속성)  
**주요 기능**:
- 엔티티 타입 CRUD
- 관계 타입 정의
- 속성 스키마 설정
- 타입 간 제약조건 (domain, range)

### 스키마 관리 화면

```
┌──────────────────────────────────────────────────────┐
│ 스키마 관리                                           │
├──────────────────────────────────────────────────────┤
│                                                      │
│ 📑 엔티티 타입                  [새 타입]           │
│                                                      │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 타입: Project                                  │ │
│ ├─────────────────────────────────────────────────┤ │
│ │ ID: entity-type:Project                        │ │
│ │ 설명: 프로젝트 엔티티                            │ │
│ │ 부모 타입: (없음)                               │ │
│ │                                                 │ │
│ │ 속성 스키마 (5):                                │ │
│ │ ├─ name (string, 필수)                         │ │
│ │ ├─ status (enum: active/inactive/archived)    │ │
│ │ ├─ startDate (date)                           │ │
│ │ ├─ budget (number)                            │ │
│ │ └─ description (text)                         │ │
│ │                                                 │ │
│ │ [편집] [삭제] [인스턴스 보기]                   │ │
│ │                                                 │ │
│ └─────────────────────────────────────────────────┘ │
│                                                      │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 타입: Team                                     │ │
│ │ ...                                             │ │
│ └─────────────────────────────────────────────────┘ │
│                                                      │
│ 🔗 관계 타입                    [새 관계]           │
│                                                      │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 관계: hasTeam                                  │ │
│ ├─────────────────────────────────────────────────┤ │
│ │ Domain: Project                                │ │
│ │ Range: Team                                    │ │
│ │ 설명: 프로젝트가 팀을 가짐                       │ │
│ │ 역관계: belongsToProject (자동)                │ │
│ │ Cardinality: 1:N (프로젝트 1개 → 팀 다수)     │ │
│ │                                                 │ │
│ │ [편집] [삭제] [관계 보기]                       │ │
│ │                                                 │ │
│ └─────────────────────────────────────────────────┘ │
│                                                      │
│ ...                                                 │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 엔티티 타입 생성

```
1. [새 타입] 버튼
2. 기본 정보
   ├─ ID: entity-type:MyType
   ├─ 이름: 내 타입
   ├─ 설명: 타입의 목적
   └─ 부모 타입: (상속)
3. 속성 정의
   ```
   속성 이름 | 타입 | 필수 | 기본값
   ─────────────────────────────
   name    | string | O | 
   status  | enum   | X | active
   created | date   | O | 현재시간
   ```
4. [저장]
```

### 관계 타입 생성

```
1. [새 관계] 버튼
2. 관계 정보
   ├─ ID: rel:hasTeam
   ├─ 이름: hasTeam
   ├─ Domain: Project (관계 시작 타입)
   └─ Range: Team (관계 종료 타입)
3. 제약조건
   ├─ Cardinality: 1:N, M:N, 1:1 등
   └─ 특성: 이행적, 대칭적 등 (선택)
4. [저장]
```

### 속성 스키마

```
속성 정의:
├─ 이름: name
├─ 타입: string | number | date | enum | boolean
├─ 필수 여부: true | false
├─ 기본값: (선택)
├─ 정규식 (문자열만): ^[A-Za-z0-9]+$
├─ 범위 (숫자): min/max
└─ 옵션 값 (enum): ["active", "inactive", "archived"]
```

### 타입 상속

```
예시: FinancialProject < Project

FinancialProject 속성:
├─ name (상속: Project)
├─ status (상속: Project)
├─ budget (신규)
└─ fiscalYear (신규)
```

### 변경 영향도 분석

기존 인스턴스가 있을 때 스키마 변경:
```
⚠️  주의: Project 타입에 15개의 기존 인스턴스가 있습니다

변경사항:
├─ [속성 추가] category (기존 인스턴스에 영향 없음)
├─ [속성 삭제] description (15개 인스턴스 데이터 손실!)
└─ [타입 변경] budget: number → string (변환 필요)

☐ 모든 영향을 이해했으며 진행합니다
[취소] [진행]
```

## 📝 인스턴스 편집

**목적**: 스키마에 맞춰 실제 데이터(인스턴스) 생성, 수정, 삭제  
**주요 기능**:
- 인스턴스 CRUD
- 속성 입력 (타입 검증)
- 관계 설정
- 대량 작업

### 인스턴스 편집 화면

```
┌──────────────────────────────────────────────────────┐
│ 인스턴스 편집                                         │
├──────────────────────────────────────────────────────┤
│                                                      │
│ 타입 선택: [Project ▼]  [검색] [필터]  [새 인스턴스] │
│                                                      │
│ 📋 인스턴스 목록                                      │
│                                                      │
│ ID | 이름 | 상태 | 시작일 | 예산 | 작업              │
│─────────────────────────────────────────────────────  │
│ 1  │ P-01 │ active │ 2026-01-01 │ 5M │ [편집][삭제] │
│ 2  │ P-02 │ active │ 2026-02-15 │ 8M │ [편집][삭제] │
│ 3  │ P-03 │ inactive │ 2025-12-01 │ 3M │ [편집][삭제] │
│ ...                                                 │
│                                                      │
│ [이전] [1] [2] [3] [다음]                           │
│                                                      │
│ ┌──────────────────────────────────────────────────┐│
│ │ 인스턴스 상세 편집 (P-01 선택 시)                ││
│ ├──────────────────────────────────────────────────┤│
│ │ ID: entity_proj_001 (읽기 전용)                ││
│ │                                                  ││
│ │ 속성:                                            ││
│ │ ├─ [필수] name: ___________________ (Project P-01)

│ │ ├─ startDate: [2026-01-01]          │
│ │ ├─ [필수] budget: ___________________│
│ │ └─ description: ___________________|
│ │                    (여러 줄 텍스트)   │
│ │                                                  ││
│ │ 관계:                                            ││
│ │ ├─ hasTeam: [Team-01] [Team-02] [+]  │

│ │ └─ allocates: [Budget-001] [+]       │
│ │                                                  ││
│ │ [저장] [취소] [삭제] [히스토리 보기]            ││
│ │                                                  ││
│ └──────────────────────────────────────────────────┘│
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 인스턴스 생성

```
1. 타입 선택 (예: Project)
2. [새 인스턴스] 버튼
3. 속성 입력
   ├─ 필수 속성: 모두 입력
   ├─ 선택 속성: 필요시 입력
   └─ 타입별 검증 (숫자, 날짜, enum 등)
4. 관계 설정 (선택사항)
   ├─ [+] 버튼으로 관계 추가
   └─ 대상 인스턴스 선택
5. [저장]
```

### 대량 작업

**CSV Import**:
```
1. [일괄 가져오기] 버튼
2. CSV 파일 선택
   ```
   name,status,startDate,budget
   P-04,active,2026-03-01,10000000
   P-05,inactive,2026-03-15,2000000
   ```
3. 매핑 확인
   ├─ name → name
   ├─ status → status
   └─ ...
4. [가져오기]
```

**선택 삭제**:
```
1. 삭제할 인스턴스 체크박스 선택
2. [일괄 삭제] 버튼
3. 영향도 확인 (관계 정리 등)
4. [확인]
```

### 버전 관리

각 인스턴스의 수정 히스토리:
```
인스턴스: P-01

버전 | 수정일 | 수정자 | 변경사항
──────────────────────────
5 | 2026-06-14 10:30 | alice | budget: 5M → 6M
4 | 2026-06-10 14:15 | bob | status: active → inactive
3 | 2026-06-01 09:00 | alice | 생성

[버전 3으로 복원]
```

## 🎨 관계 그래프 편집

**목적**: 인스턴스 간 관계를 시각적으로 생성, 수정, 삭제  
**주요 기능**:
- 캔버스 기반 관계 편집
- 드래그&드롭 연결
- 레이아웃 자동 정렬
- 관계 속성 편집

### 인터페이스

```
┌──────────────────────────────────────────────────────┐
│ 관계 그래프 편집                                       │
├──────────────────────────────────────────────────────┤
│                                                      │
│ [저장] [취소] [자동 레이아웃] [정렬] [확대/축소]    │
│                                                      │
│ ┌────────────────────────────────────────────────┐ │
│ │                                                │ │
│ │      [Project-01]                             │ │
│ │         ↙  ↓  ↘                              │ │
│ │     [Team]  |  [Member-01]                   │ │
│ │             ↓                                 │ │
│ │         [Budget]                             │ │
│ │                                                │ │
│ │ [마우스 조작]                                 │ │
│ │ ├─ 클릭: 노드 선택                            │ │
│ │ ├─ 드래그: 노드 이동                          │ │
│ │ ├─ Shift+드래그: 연결선 그리기               │ │
│ │ ├─ 우클릭: 컨텍스트 메뉴                     │ │
│ │ └─ Del: 선택 삭제                            │ │
│ │                                                │ │
│ └────────────────────────────────────────────────┘ │
│                                                      │
│ ┌────────────────────────────────────────────────┐ │
│ │ 선택 관계 상세                                │ │
│ ├────────────────────────────────────────────────┤ │
│ │ 관계: hasTeam                                │ │
│ │ 출발: Project-01                             │ │
│ │ 도착: Team-01                                │ │
│ │                                                │ │
│ │ [편집] [삭제]                                 │ │
│ │                                                │ │
│ └────────────────────────────────────────────────┘ │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 관계 생성

```
1. 시작 노드(Project-01)에서 마우스 누르기
2. Shift+드래그하여 종료 노드(Team-01)로 끌기
3. 관계 타입 선택 팝업
   ├─ hasTeam
   ├─ hasMember
   └─ [새 관계 타입 생성...]
4. [확인]
5. 관계 선 그려짐
```

### 레이아웃 정렬

```
자동 레이아웃 알고리즘:
├─ 계층형 (Hierarchical): 방향 구조에 적합
├─ 방사형 (Radial): 중심 노드 중심
├─ 원형 (Circular): 균형 잡힌 배치
├─ 포스 기반 (Force-based): 자연스러운 분포
└─ 격자 (Grid): 규칙적 배치

[방사형 레이아웃] 선택 → 자동 정렬
```

### 외부 온톨로지 가져오기

**DBpedia 가져오기**:
```
1. [DBpedia 가져오기] 버튼

   예) "Machine Learning"
3. 도메인 선택 (예: AI)
4. [미리보기]
   ├─ 새 클래스: 6개
   ├─ 새 속성: 18개
   └─ 새 트리플: 1280개
5. [가져오기]
```

**Wikidata 가져오기**:
```
1. [Wikidata 가져오기] 버튼
2. Wikidata ID 입력 (예: Q11660)
3. 도메인 선택
4. [미리보기] → [가져오기]
```

**RDF 파일 가져오기**:
```

3. 도메인 선택
4. [미리보기] → [가져오기]
```

### URI 매핑 관계

| 관계 | 의미 | 예시 |
|------|------|------|
| **owl:sameAs** | 완전히 동일한 개념 | DBpedia Project = 내 Project |
| **skos:exactMatch** | 정확히 일치 | 정의가 정확히 같음 |
| **skos:closeMatch** | 대체로 일치 | 95% 이상 유사 |
| **skos:broader** | 상위 개념 | "Vehicle" > "Car" |
| **skos:narrower** | 하위 개념 | "Car" < "Tesla" |
| **relatedTo** | 관련 개념 | "Project" 관련 "Budget" |
