# 고객사 문의 자동댓글 시나리오 매뉴얼

**문서 번호**: 11  
**시나리오**: Scenario 1 - 고객사 문의 자동댓글  
**대상 시스템**: ont_platform, s1_customer_board, customer_mcp  
**목적**: 고객사 게시판에 접수된 문의를 워크플로우로 처리하고, 답변 댓글을 MCP 중계 서버를 통해 등록한다.

---

## 1. 시나리오 개요

고객사 문의 자동댓글 시나리오는 고객사 게시판에 새 문의가 등록되었을 때, 온톨로지 플랫폼이 문의 내용을 해석하고 답변 초안을 생성한 뒤 고객사 MCP 서버를 통해 댓글을 등록하는 흐름이다.

```text
고객사 게시판 문의 등록
  -> Webhook 또는 Batch로 ont_platform에 전달
  -> 문의 분류 및 지식 조회
  -> 답변 초안 생성
  -> customer_mcp comment.create 호출
  -> 고객사 게시판 댓글 등록
  -> 실행 이력 및 온톨로지 관계 저장
```

---

## 2. 관련 서비스

| 서비스 | 기본 포트 | 역할 |
|---|---:|---|
| ont_platform backend | 8001 | 이벤트 수신, 워크플로우 실행, 답변 생성 |
| ont_platform frontend | 3002 | 워크플로우 실행 화면 |
| customer_mcp | 8080 | 고객사 게시판 댓글 등록 중계 |
| s1_customer_board | 8090 | 고객사 모의 게시판 |

---

## 3. 실행 방식

### 3.1 Webhook 방식

Webhook 방식은 게시판에서 새 문의를 등록하는 순간 ont_platform으로 이벤트가 전달되는 방식이다.

사용 상황:

- 실시간 자동 처리 시연
- 새 문의가 들어오면 즉시 댓글이 달리는 흐름을 보여줄 때

주의 사항:

- 게시판의 Webhook 설정이 켜져 있어야 한다.
- ont_platform backend가 먼저 실행되어 있어야 한다.
- 댓글이 자동으로 달리므로 배치 테스트용 미처리 건이 남지 않을 수 있다.

### 3.2 수동 Batch 방식

Batch 방식은 게시판에 댓글이 없는 open 문의를 조회해 워크플로우가 처리하는 방식이다.

사용 상황:

- 미처리 문의를 만든 뒤 수동으로 처리하고 싶을 때
- 워크플로우 화면에서 실행 과정을 보여주고 싶을 때
- 이미 처리한 건을 재수행 테스트하고 싶을 때

권장 데모 흐름:

```text
게시판 Webhook 끄기
  -> 새 문의 등록
  -> Builder and Run에서 처리 건수 1 설정
  -> Run 실행
  -> 게시판 댓글 확인
  -> Workflow Trace와 Ontology Explorer 확인
```

---

## 4. 게시판에서 문의 만들기

1. 브라우저에서 `http://127.0.0.1:8090`을 연다.
2. Webhook 테스트가 아니라면 `실시간 Webhook 자동 트리거`를 끈다.
3. 새 문의를 작성한다.
4. 문의 목록에서 댓글이 아직 없는 상태인지 확인한다.

예시 문의:

```text
제목: 비밀번호 초기화 요청
내용: 비밀번호를 여러 번 잘못 입력해서 로그인이 잠겼습니다. 초기화 방법을 알려주세요.
```

또는 서비스 요청형 예시:

```text
제목: 주문 상태 확인 요청
내용: 주문번호 ORD-1001의 배송 상태와 취소 가능 여부를 확인하고 싶습니다.
```

---

## 5. 워크플로우 화면에서 실행

1. ont_platform 콘솔에서 `Builder and Run`으로 이동한다.
2. 고객사 자동댓글 워크플로우를 선택한다.
3. 실행 설정을 확인한다.

| 항목 | 권장값 |
|---|---|
| 실행 모드 | `post` |
| status | `open` |
| 처리 건수 | `1` |
| 이미 처리한 요청도 재수행 | 반복 데모 시 체크 |

4. `Run`을 클릭한다.
5. 우측 실행 패널에서 상태가 `completed`가 되는지 확인한다.
6. `입출력` 탭에서 각 노드의 결과를 확인한다.

---

## 6. 결과 확인

### 6.1 고객사 게시판

게시판 상세 화면에서 댓글이 등록되었는지 확인한다.

성공 예:

```text
ontology-workflow
문의 내용을 확인했습니다. 관련 정책과 주문 정보를 기준으로 안내드립니다...
```

### 6.2 Workflow Trace

확인 항목:

- 실행 ID
- 실행 상태
- 완료 단계
- 오류 여부
- 각 노드의 입력과 출력
- 외부 MCP 호출 결과

### 6.3 Ontology Explorer

확인할 관계 예:

```text
ServiceRequest -> has_reply -> AutoReply
WorkflowExecution -> generated -> AutoReply
AutoReply -> posted_as -> ExternalComment
```

## 7. 실패 시 확인 순서

| 증상 | 확인 위치 | 조치 |
|---|---|---|
| 댓글이 안 달림 | customer_mcp 실행 여부 | 8080 포트 또는 mock infra 실행 확인 |
| 워크플로우가 계속 running | Workflow Trace | 마지막 실행 노드와 오류 메시지 확인 |
| Webhook 실패 | s1_customer_board 로그 | ont_platform 8001 기동 여부 확인 |
| 이미 처리되어 새 댓글이 없음 | 실행 옵션 | 재수행 옵션 체크 |
| PowerShell curl 오류 | 명령 문법 | PowerShell에서는 `Invoke-RestMethod` 또는 `curl.exe` 사용 |
