# 24. 보드 초기화 도구 가이드

**섹션**: 모의 인프라  
**스크립트**: `reset_boards.py`  
**가상환경**: `claud_be`  
**위치**: `mock_infras/reset_tool`  
**관련 가이드**: [20_고객사_보드_모의인프라_가이드.md](./20_고객사_보드_모의인프라_가이드.md), [22_공장_보드_모의인프라_가이드.md](./22_공장_보드_모의인프라_가이드.md)

---

## 📋 개요

시나리오 테스트 과정에서 워크플로우 실행 및 시뮬레이션을 통해 자동 등록된 모의 인프라의 가공 데이터를 정리하고 데이터베이스 상태를 복원(Reset)하는 유틸리티 도구입니다.

---

## 🛡️ 데이터 안전 보존 원칙

본 도구는 무차별적인 데이터 삭제 방식을 지양하고, 시스템 기동에 필수적인 핵심 시드 데이터는 유지하는 안전 격리 설계를 따릅니다.

* **기본 게시물 및 이벤트 보존**: 홍길동 고객의 문의글(`q-001`)과 배터리 탭 용접기 고장 이벤트(`fe-001`) 데이터 본체는 절대 삭제되지 않습니다.
* **기본 시드 댓글 보존**: 보드 서비스 기동 시 기본 설정되는 안내용 봇 댓글(`시스템봇` 댓글 및 `system-bot` 알림 댓글)은 보존됩니다.
* **에이전트 결과물만 타겟팅**: 워크플로우 런타임 중에 생성된 자동 댓글과 정비지시서(Work Order) 데이터만 특정하여 삭제 및 복원합니다.

---

## 🚀 사용 방법

PowerShell 혹은 CMD 터미널을 열고 가상환경을 활성화한 후 스크립트를 기동합니다.

```powershell
# 1. 가상환경 활성화
conda activate claud_be

# 2. 대화형 인터랙티브 메뉴 실행 (추천)
python mock_infras/reset_tool/reset_boards.py
```

### 🖥️ 인터랙티브 메뉴 화면 예시
```text
========================================
   모의 인프라 DB 초기화 및 복원 도구
========================================
1. 시나리오 1 기본 문의(q-001) 댓글 초기화
2. 시나리오 1 전체 댓글 초기화 (시드글 보존)
3. 시나리오 2 기본 고장(fe-001) 응답 및 정비지시 초기화
4. 시나리오 2 전체 고장 응답 및 정비지시 초기화
5. [전체 초기화] 두 인프라 DB의 모든 자동 가공 데이터 초기화
0. 종료
----------------------------------------
원하는 작업 번호를 선택하세요: 
```

## 🛠️ 커맨드 라인 단축 명령어 (CLI Options)

대화형 메뉴를 거치지 않고 특정 초기화 작업을 자동 배치 처리하도록 옵션을 조합할 수 있습니다.

### A. 시나리오 1 & 2 기본 시드 데이터 동시 초기화
```powershell
python mock_infras/reset_tool/reset_boards.py --s1 --s2
```

### B. 데이터베이스 완전 초기화 (모든 데이터 대상)
```powershell
python mock_infras/reset_tool/reset_boards.py --all
```

### C. 상세 CLI 옵션 스펙
| 옵션 | 단축 옵션 | 설명 |
|------|-----------|------|
| `--help` | `-h` | 도움말 및 사용 가능한 명령어 옵션 출력 |
| `--s1` | | 시나리오 1 기본 게시물(`q-001`)의 워크플로우 생성 댓글 삭제 |
| `--s1-all` | | 시나리오 1 데이터베이스 전체의 자동 등록 댓글 삭제 |
| `--s1-id {ID}`| | 특정 Post ID를 인수로 지정하여 해당 게시글의 댓글만 삭제 |
| `--s2` | | 시나리오 2 기본 이벤트(`fe-001`) 관련 정비지시 삭제 및 `open` 상태 원복 |
| `--s2-all` | | 시나리오 2 전체 이벤트 관련 정비지시 삭제 및 전체 상태 `open` 원복 |
| `--all` | | 두 가상 인프라 데이터베이스의 모든 자동 가공 데이터 완전 초기화 |
