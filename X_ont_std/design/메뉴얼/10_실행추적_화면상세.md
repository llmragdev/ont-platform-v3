# 실행 추적 - 화면 상세 가이드

**메뉴**: 실행 추적  
**목적**: 워크플로우 실행 결과 상세 분석

---

## 📐 화면 구조

```
실행 선택 | 상태 | 시작시간 | 진행도
┌──────────────────────────────────┐
│ 노드1   ✓ (500ms)               │
│  Input: {...}                   │
│  Output: {...}                  │
│                                  │
│ 노드2   ✓ (1200ms)              │
│  Input: {...}                   │
│  Output: {...}                  │
│  온톨로지 저장: entity_001 ✓    │
│                                  │
│ 노드3   ✗ (실패)                │
│  Error: timeout                 │
│  재시도: [버튼]                │
│                                  │
└──────────────────────────────────┘
```

---

## 🎯 주요 기능

### 타임라인 뷰
- 각 노드의 실행 시간 시각화
- 진행도 바 표시
- 에러 노드 강조

### 데이터 비교
- Input (원본) vs Rendered Input (표현식 평가 후) 비교
- Output 상세 JSON 표시
- 타입 검증 결과

### 온톨로지 통합
- 어느 노드가 온톨로지에 저장했는지 표시
- 저장된 엔티티 ID 클릭 → 관계 탐색으로 이동

---
