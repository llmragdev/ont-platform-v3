# 인스턴스 편집 - 화면 상세 가이드

**메뉴**: 인스턴스 편집  
**목적**: 실제 데이터 CRUD

---

## 📐 화면 구조

```
타입: [Project▼] [검색] [필터] [새 인스턴스]
┌──────────────────────────────────────┐
│ ID | 이름 | 상태 | 예산 | 작업      │
├──────────────────────────────────────┤
│ 001│ P-1 │ 활성│ 5M │ [편집][삭제]│
│ 002│ P-2 │ 활성│ 8M │ [편집][삭제]│
│ 003│ P-3 │ 비활성│ 3M │ [편집][삭제]│
│ ...                                  │
└──────────────────────────────────────┘
[이전] [1] [2] [다음]

┌─ 상세 편집 (행 선택 시) ─────────────┐
│ ID: entity_proj_001                 │
│                                    │
│ 속성:                              │
│  name: _________________ (Project P-1)
│  status: [active▼]                 │
│  startDate: [2026-01-01]          │
│  budget: _________________ (숫자)   │
│                                    │
│ 관계:                              │
│  hasTeam: [Team-01] [Team-02] [+] │
│                                    │
│ [저장] [취소] [삭제] [히스토리]   │
└────────────────────────────────────┘
```

---

## 🎯 주요 기능

### 테이블 뷰
- 페이지네이션 (기본 20개)
- 정렬 (클릭 헤더)
- 필터 (타입, 날짜 범위)

### 대량 작업
```
[CSV 다운로드]
[CSV 업로드]
  │
  ├→ 파일 선택
  ├→ 열 매핑 확인
  └→ 가져오기 진행

[선택 항목 삭제]
```

### 속성 편집
- 타입별 입력 필드 (텍스트, 숫자, 날짜, enum)
- 필수 필드 표시
- 유효성 검증 실시간
