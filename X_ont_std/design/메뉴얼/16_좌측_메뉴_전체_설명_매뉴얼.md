# 좌측 메뉴 전체 설명 매뉴얼

**문서 번호**: 16  
**대상 화면**: Ontology Console v5 좌측 사이드바  
**기준 파일**: `ont_platform/v5/frontend/src/components/Sidebar.tsx`  
**목적**: 좌측 메뉴에 표시되는 모든 메뉴의 역할, 사용 시점, 관련 화면, 시나리오 연결 관계를 빠짐없이 설명한다.

---

## 1. 좌측 메뉴 전체 구조

현재 좌측 메뉴는 4개 그룹, 총 20개 메뉴로 구성된다.

| 그룹 | 메뉴 수 | 목적 |
|---|---:|---|
| 워크플로우 | 7 | 업무 흐름 템플릿, 실행, 추적, 스킬, 실패 큐 관리 |
| 온톨로지 | 5 | 객체, 관계, 스키마, 인스턴스, RDF 연결 관리 |
| 질의와 분석 | 6 | AI 질의, RAG 질의, 통합 분석, SPARQL 조회 |
| 운영과 검증 | 2 | 감사 로그와 통합 테스트 |

전체 메뉴는 다음 순서로 표시된다.

```text
워크플로우
  - 워크플로우 홈
  - 템플릿 갤러리
  - 빌더와 실행
  - 스킬 관리
  - 실행 추적
  - 승인 워크플로우
  - Writeback DLQ

온톨로지
  - 관계 탐색
  - 스키마 관리
  - 인스턴스 편집
  - 관계 그래프 편집
  - RDF 워크벤치

질의와 분석
  - 대시보드
  - 객체 탐색
  - 온톨로지 질의
  - 통합 질의
  - 문서 RAG 질의
  - SPARQL 콘솔

운영과 검증
  - 감사 로그
  - 통합 테스트
```

## 2. 좌측 상단 사용자 영역

좌측 메뉴 상단에는 현재 사용자와 실행 컨텍스트가 표시된다.

| 항목 | 설명 |
|---|---|
| 현재 사용자 | 데모 또는 권한 테스트에 사용할 사용자 프리셋 |
| 역할 | 사용자에게 부여된 역할 |
| company_id | 테넌트 또는 고객사 단위 |
| project_id | 프로젝트 또는 업무 공간 단위 |

이 영역은 단순 표시가 아니라 멀티테넌트, 프로젝트 분리, 권한 테스트와 연결된다.

데모 설명 문장:

```text
좌측 상단의 사용자, 회사, 프로젝트는 이 플랫폼이 한 고객사 전용 화면이 아니라
회사와 프로젝트 단위로 워크플로우와 온톨로지 데이터를 분리할 수 있음을 보여줍니다.
```

## 3. 워크플로우 그룹

워크플로우 그룹은 업무 자동화의 중심 메뉴이다.  
템플릿을 선택하고, 워크플로우를 복제하고, 실행하고, 결과를 추적하는 흐름을 담당한다.

### 3.1 워크플로우 홈

| 항목 | 내용 |
|---|---|
| 메뉴명 | 워크플로우 홈 |
| 화면 제목 | 워크플로우 홈 |
| 설명 | 템플릿과 최근 실행 현황 |
| 주요 사용자 | 운영자, 시연자, 업무 담당자 |

주요 기능:

- 최근 사용한 워크플로우 확인
- 최근 실행 결과 확인
- 템플릿 또는 빌더 화면으로 빠르게 이동
- 현재 프로젝트의 업무 자동화 현황 파악

사용 시점:

- 데모를 시작할 때
- 어떤 워크플로우가 준비되어 있는지 확인할 때
- 최근 실행 성공/실패를 빠르게 볼 때

### 3.2 템플릿 갤러리

| 항목 | 내용 |
|---|---|
| 메뉴명 | 템플릿 갤러리 |
| 화면 제목 | 템플릿 갤러리 |
| 설명 | 복제해서 시작하는 업무 흐름 |
| 주요 사용자 | 업무 설계자, 컨설턴트, 운영자 |

주요 기능:

- 사전 정의된 워크플로우 템플릿 조회
- 고객사 문의 자동댓글 템플릿 복제
- 공장 자동화 정비지시 템플릿 복제
- 템플릿을 프로젝트 워크플로우로 변환

사용 시점:

- 새 업무 자동화 흐름을 만들 때
- 기존 시나리오를 복제해 테스트용 워크플로우를 만들 때
- 회사별/프로젝트별 워크플로우를 분리하고 싶을 때

### 3.3 빌더와 실행

| 항목 | 내용 |
|---|---|

| 주요 사용자 | 업무 설계자, 개발자, 시연자 |

주요 기능:

- 워크플로우 블록 배치
- 블록 간 연결선 생성
- 선택한 블록 또는 연결선 삭제
- 워크플로우 저장, 복제, 삭제
- 실행 모드, 상태, 처리 건수 설정
- 워크플로우 즉시 실행
- 실행 중인 블록 상태 확인
- 우측 패널에서 실행 현황, 선택 항목, 입출력, 온톨로지, 이력 확인

사용 시점:

- 워크플로우를 직접 수정할 때
- 공장 자동화 또는 고객사 자동댓글 시나리오를 실행할 때
- 특정 블록의 입력/출력을 확인할 때
- 워크플로우와 온톨로지 매핑을 같이 보여줄 때

데모 핵심:

```text
이 화면은 단순한 그림판이 아니라,
업무 흐름을 편집하고 바로 실행하며
각 단계의 결과와 온톨로지 연결까지 확인하는 핵심 화면입니다.
```

| 주요 사용자 | 승인자, 운영자, 업무 담당자 |

주요 기능:

- 승인 대기 상태 확인

사용 시점:

- 자동화 결과를 사람이 승인해야 하는 업무에 사용할 때
- AI가 만든 조치가 바로 실행되면 안 되는 업무에 사용할 때

- 운영 환경에서는 중요 조치에 대해 승인 워크플로우를 사이에 둘 수 있다.

## 4. 온톨로지 그룹

온톨로지 그룹은 업무 데이터를 객체와 관계로 관리하는 영역이다.  
워크플로우가 실행한 결과가 실제로 어떤 업무 의미로 남았는지 확인한다.

### 4.1 관계 탐색

| 항목 | 내용 |
|---|---|
| 메뉴명 | 관계 탐색 |
| 화면 제목 | 관계 탐색 |
| 설명 | 객체와 관계를 그래프로 조회 |
| 주요 사용자 | 업무 분석가, 시연자, 데이터 설계자 |

주요 기능:

- 온톨로지 객체를 관계 그래프로 조회
- ServiceRequest, AutoReply, FaultEvent, Equipment 등 연결 확인
- 객체 선택 시 상세 속성 확인
- 실행 결과가 업무 관계로 남았는지 확인

사용 시점:

- 워크플로우 실행 후 온톨로지 저장 결과를 보여줄 때
- 반복 고장, 정비지시, 댓글 등록 관계를 시각적으로 설명할 때

### 4.2 스키마 관리

- 업무 도메인별 온톨로지 구조 관리

사용 시점:

- 새로운 업무 도메인을 추가할 때
- 공장, 설비, 정비지시 같은 객체 타입을 정의할 때
- 고객사별 온톨로지 템플릿을 구성할 때

## 7. 업무별 추천 메뉴 경로

### 7.1 고객사 문의 자동댓글 시연

```text
템플릿 갤러리
  -> 빌더와 실행
  -> 실행 추적
  -> 관계 탐색
  -> 감사 로그
```

### 7.2 공장 자동화 정비지시 시연

```text
빌더와 실행
  -> 실행 추적
  -> 관계 탐색
  -> 객체 탐색
  -> 통합 질의
```

### 7.3 온톨로지 구조 설명

```text
스키마 관리
  -> 인스턴스 편집
  -> 관계 그래프 편집
  -> 관계 탐색
```

### 7.4 RAG와 온톨로지 차이 설명

```text
문서 RAG 질의
  -> 온톨로지 질의
  -> 통합 질의
```

### 7.5 운영 장애 확인

```text
실행 추적
  -> Writeback DLQ
  -> 감사 로그
  -> 통합 테스트
```

## 8. 데모 중 메뉴 설명 순서

시연 시간이 짧으면 모든 메뉴를 순서대로 누르지 말고 다음 흐름으로 설명한다.

```text
1. 워크플로우 그룹
   - 업무를 만들고 실행하는 곳

2. 온톨로지 그룹
   - 실행 결과가 어떤 객체와 관계로 남았는지 보는 곳

3. 질의와 분석 그룹
   - 저장된 업무 맥락과 문서를 질문하는 곳

4. 운영과 검증 그룹
   - 누가 무엇을 실행했고 실패한 것은 없는지 확인하는 곳
```

한 문장 설명:

```text
좌측 메뉴는 업무 자동화 실행, 업무 관계 저장, AI/RAG 분석, 운영 검증의 네 영역으로 나뉘어 있습니다.
```

## 10. 향후 메뉴 개선 제안

현재 메뉴 구조는 기능별로 잘 분리되어 있지만, 납품용 제품 관점에서는 다음 개선을 고려할 수 있다.

| 개선 방향 | 설명 |
|---|---|
| 역할 기반 메뉴 표시 | 일반 사용자, 업무 설계자, 관리자별 메뉴 노출 분리 |
| 시나리오 중심 바로가기 | 고객사 자동댓글, 공장 정비지시 같은 업무별 진입점 제공 |
| 운영 메뉴 하위 통합 | 감사 로그, DLQ, 통합 테스트를 운영 콘솔로 묶기 |
| 온톨로지 관리 단계 구분 | 스키마 설계, 데이터 편집, 관계 조회를 더 명확히 구분 |
| 데모 모드 제공 | 시연용으로 핵심 메뉴만 보이게 하는 모드 |
