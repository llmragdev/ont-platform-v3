### 활동 타입

**온톨로지 활동**:
```
- ontology-entity-create: 엔티티 생성
- ontology-entity-update: 엔티티 수정
- ontology-entity-delete: 엔티티 삭제
- ontology-relation-create: 관계 생성
- ontology-relation-delete: 관계 삭제
- ontology-schema-update: 스키마 변경
```

**워크플로우 활동**:
```
- workflow-create: 워크플로우 생성
- workflow-execute: 워크플로우 실행
- workflow-update: 워크플로우 편집
- workflow-delete: 워크플로우 삭제
- workflow-publish: 템플릿 발행
```

**쿼리 활동**:
```
- query-ontology: 온톨로지 질의
- query-sparql: SPARQL 실행
- query-rag: RAG 검색
- query-hybrid: 통합 질의
```

**기타**:
```
- skill-execute: 스킬 실행
- import-ontology: 온톨로지 import
- mapping-create: URI 매핑 생성
- dlq-retry: DLQ 항목 재시도
```

### 필터링 및 검색

**고급 검색 문법**:
```
사용자: "alice@company.com"
활동: ontology-entity-update OR workflow-execute
리소스: entity_proj_* (와일드카드)
날짜: 2026-06-01..2026-06-14
결과: success OR failure
IP: 192.168.*.*
```

**사전 정의 필터**:
```
- "내 활동": 현재 사용자의 모든 활동
- "최근 실패": 지난 24시간 실패 항목
- "삭제 작업": 모든 delete 작업
- "외부 API": DLQ, 스킬 실행, import
- "위험한 변경": 스키마 변경, 대량 삭제
```

### 감사 알림

```
감사 조건 설정:

☐ 스키마 변경 발생 시 알림
☐ 삭제 작업 발생 시 알림
☐ 실패율 > 10% 초과시 알림
☐ 특정 사용자의 활동 → alice@company.com
☐ 특정 리소스 변경 → entity_proj_* 또는 workflow_alpha
☐ 외부 시스템 오류 (DLQ) → 지속 2회 이상

[알림 설정] → 이메일, Slack 선택
```

### 버전 복원

삭제된 엔티티 또는 수정된 데이터 복원:

```
1. 감사 로그에서 "ontology-entity-delete" 검색
2. 삭제 기록 선택

⚠️ 주의: 복원 후에도 감사 로그에 기록됨
```

### 테스트 케이스 작성

**새 테스트 생성**:
```
1. [새 테스트] 버튼
2. 테스트 타입 선택
   ├─ Workflow 실행
   ├─ 쿼리 정확도
   ├─ 스킬 호출
   ├─ RAG 검색
   └─ 통합 (여러 모듈)
3. 테스트 상세 정보
   ├─ 이름: "workflow_alpha 정상 실행"
   ├─ 설명: 기본 입력으로 정상 완료 확인
   ├─ 우선순위: 높음
   └─ 태그: [regression] [smoke]
4. 입력 데이터 설정
5. 예상 결과 정의
   ├─ 상태: "완료"
   ├─ 응답 시간: < 3초
   ├─ 신뢰도: > 90%
   └─ 출력: {entityId: "...", saved: true}
6. [저장]
```

### 배치 실행

```
테스트 선택:
☐ [Smoke 테스트] (빠른 검증용, 10개)
☐ [회귀 테스트] (모든 변경 테스트, 48개)
☐ [성능 테스트] (로드 테스트, 20개)

└─ 평행 실행: 4개 동시 실행
```

### 테스트 결과 분석

**품질 지표**:
```
통과율 (Pass Rate):
├─ 95% 이상: ✓ 양호 (배포 가능)
├─ 90-95%: ⚠️ 주의 (수정 필요)
├─ 80-90%: ⚠️ 경고 (회귀 가능성)
└─ < 80%: ✗ 나쁨 (배포 중단)

성능 지표:
├─ 응답 시간 < 기준: ✓
├─ 응답 시간 > 기준: ⚠️
└─ 응답 시간 > 기준 2배: ✗

정확도:
├─ 쿼리 일치도 > 95%: ✓
├─ 신뢰도 > 90%: ✓
└─ 신뢰도 < 80%: ⚠️
```

**트렌드 분석**:
```
최근 10회 실행:
├─ 통과율 추세: 95% → 96% → 98% (개선)
├─ 응답 시간: 2.8초 → 2.5초 → 2.3초 (개선)
├─ 오류 분포: Skill > Query > Workflow
└─ 회귀 위험: 낮음 (오류율 감소 중)
```

```
└─ 필수 테스트: 18개 선택됨

실행:

결과:
✓ 18개 모두 통과
└─ 안전하게 병합 가능
```

## 🎓 운영 모범 사례

**감사 로그**:
- 일일 검토: 실패율 및 오류 패턴 파악
- 주간 요약: 위험 작업 및 사용자 활동
- 월간 보고: 품질 지표 및 개선 제안

**통합 테스트**:
- 배포 전: 회귀 테스트 필수 실행
- 성능 저하: 즉시 조사 및 최적화
- 실패 패턴: 원인 분석 및 예방 조치

**모니터링**:
- 응답 시간 > 기준 2배: 자동 알림
- 실패율 > 10%: 즉시 대응
- 신뢰도 < 80%: 사용자 경고
