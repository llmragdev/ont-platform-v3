# 온톨로지 콘솔 v5 - 메뉴 네비게이션 가이드

**플랫폼**: Workflow Workbench  
**버전**: v5 (FastAPI + Next.js)  
**최종 업데이트**: 2026-06-14

---

## 📋 메뉴 구조 개요

온톨로지 콘솔은 4개의 메뉴 그룹으로 구성되어 있습니다:

| 그룹 | 메뉴 수 | 목적 | 주요 기능 |
|------|--------|------|---------|
| **워크플로우** | 7개 | 업무 흐름 설계 및 실행 | 템플릿, 빌더, 스킬, 실행 추적 |
| **온톨로지** | 5개 | 데이터 그래프 관리 | 스키마, 인스턴스, RDF 연결 |
| **질의와 분석** | 6개 | 데이터 조회 및 분석 | AI, RAG, SPARQL 쿼리 |
| **운영과 검증** | 2개 | 모니터링 및 품질 관리 | 감사 로그, 테스트 |

## 🎯 메뉴별 네비게이션 경로

### 📌 일반적인 사용 흐름

**시나리오 1: 새로운 워크플로우 생성**
```
워크플로우 홈 → 템플릿 갤러리 → 빌더와 실행 → 스킬 관리 → 실행 추적
```

**시나리오 2: 온톨로지 스키마 정의**
```
온톨로지 → 스키마 관리 → 인스턴스 편집 → 관계 그래프 편집
```

**시나리오 3: 외부 데이터 연결**
```
온톨로지 → RDF 워크벤치 → 스키마 관리 → 인스턴스 편집
```

**시나리오 4: 데이터 분석**
```
대시보드 → (온톨로지 질의 | 통합 질의 | RAG 질의) → 감사 로그
```

## 📂 좌측 메뉴 전체 상세 안내

온톨로지 콘솔 v5의 좌측 사이드바에 제공되는 모든 메뉴 항목(총 20개)의 목적, 핵심 기능, 화면 레이아웃 구성, 그리고 향후 고도화할 보완 기능 명세입니다.

### 🔄 1. 워크플로우 그룹 (7개 메뉴)
* **1.1 워크플로우 홈 (Workflow Home)**
  * **목적**: 프로젝트 내 모든 워크플로우 상태를 종합 관제하는 중앙 대시보드입니다.
  * **핵심 기능**: 활성 워크플로우 수, 최근 성공률, 이달 누적 실행 수 등 KPI 표시. 최근 저장된 템플릿과 실행 중/완료된 최근 인스턴스 모니터링.
  * **화면 구성**:
    * **상단 요약 카드**: 총 실행 횟수, 활성 수, 에러율 지표 카드.
    * **중앙 최근 템플릿 영역**: 카드 그리드 형태로 제공되는 주요 템플릿 목록과 우측의 템플릿 복제 바로가기 버튼.
    * **하단 실시간 실행 큐**: 현재 런타임이 돌고 있는 인스턴스의 ID, 상태 칩, 소요 시간 요약 테이블.
  * **향후 추가 필요 기능**:
    * 워크플로우별 실행량 증감 추세를 가시화하는 실시간 라인 차트 대시보드 위젯 추가.
    * 자주 쓰는 특정 워크플로우 인스턴스를 최상단에 고정하는 즐겨찾기(Pin) 기능.
* **1.2 템플릿 갤러리 (Template Gallery)**
  * **목적**: 사전 제작된 업종별/기능별 표준 워크플로우 모듈을 탐색하고 복제합니다.
  * **핵심 기능**: 승인, 데이터 통합, ETL 등 분류 필터. 클릭 시 노드 구조와 입출력 스키마를 확인하고 '복제'하여 즉시 활용 가능.
  * **화면 구성**:
    * **상단 카테고리 탭**: '전체', '승인', '데이터 통합', '알림/통지' 탭 버튼 그룹.
    * **중앙 템플릿 뷰**: 카드별 템플릿 제목, 기능 요약, 포함된 스킬의 수 및 평점 노출.
    * **상세 팝업 모달**: 클릭 시 그래프 노드들의 구조를 썸네일 형태로 미리 보고 스펙을 검사하는 창.
  * **향후 추가 필요 기능**:
    * 개별 사용자가 커스텀하게 만든 워크플로우를 조직 내 갤러리에 템플릿 패키지로 직접 발행(Publish)하는 기능.
    * 외부 마켓플레이스 및 타 시스템의 템플릿 파일을 수동 가져오기(Import File)하는 기능.
* **1.3 빌더와 실행 (Builder & Run)**
  * **목적**: 캔버스 상에서 노드를 조립하고 외부 API(스킬)를 바인딩하여 실행하는 핵심 빌더입니다.
  * **핵심 기능**: 노드 드래그 앤 드롭 연결. 스킬 노드 선택 시 `InputMappingEditor` 표시 및 `{{nodes.x.output.y}}` 자동완성/정규식 유효성 실시간 검증.
  * **화면 구성**:
    * **좌측 노드 팔레트**: 드래그 앤 드롭 가능한 노드(START, END, SKILL, CONDITION) 요소.
    * **중앙 드로잉 캔버스**: React Flow 기반 격자형 그래프 캔버스와 컨트롤 패널(배율, 미니맵).
    * **우측 상세 편집바**: 선택된 노드의 ID, 매핑 폼(Input Mapping) 및 이전 노드 출력 바인딩 도구.
    * **하단 콘솔 탭**: SSE 실행 스트리밍 데이터 로그 수신 창 및 실행 결과 JSON 뷰어.
  * **향후 추가 필요 기능**:
    * 노드 배치가 자동 정렬되는 그리드 가이드 스냅 기능.
    * 복수 개의 노드와 에지를 한 번에 묶어 이동, 복사, 삭제 처리하는 그룹화 도구.
    * 실시간 공동 편집 도구(동시 협업자 커서 위치 및 실시간 변경사항 표시).
* **1.4 스킬 관리 (Skill Catalog)**
  * **목적**: 워크플로우 노드에서 실행할 기능 단위(내장/외부 API)를 중앙 통제합니다.
  * **핵심 기능**: Built-in 스킬 7종 및 커스텀 스킬 목록 관리. 입력/출력 JSON Schema 정의. 커스텀 스킬의 HTTP/MCP 연동 주소 및 자격증명 매핑.
  * **화면 구성**:
    * **상단 스킬 수치 요약**: 총 스킬 수, 내장형 개수, 커스텀 개수, 검증 완료 스킬 지표.
    * **검색 및 카테고리 필터**: 검색 입력 필드 및 Built-in/Custom 필터 탭.
    * **스킬 카드 그리드**: 스킬별 스펙 설명, 입출력 스키마의 속성 목록 요약 칩, 편집/삭제 트리거 버튼.
  * **향후 추가 필요 기능**:
    * **커스텀 스킬 생성/편집/삭제 모달 연동**: 현재 UI에 포함되어 있으나 동작 바인딩이 누락된 `CustomSkillModal`과 생성 버튼을 완전 매핑.
    * **드래그 앤 드롭 비주얼 스키마 에디터**: 텍스트 JSON 대신 화면에서 마우스 클릭으로 속성을 추가하고 타입을 지정하여 스키마를 구성하는 도구.
* **1.5 실행 추적 (Execution Trace)**
  * **목적**: 실행이 완료되거나 진행 중인 워크플로우 인스턴스의 하부 노드별 실행 과정을 상세 추적합니다.
  * **핵심 기능**: 간트 차트형 실행 타임라인. 개별 노드 클릭 시 Input, Rendered Input(표현식 평가 후 값), Output 데이터 비교 분석 및 에러 로그 확인.
  * **화면 구성**:
    * **좌측 실행 이력 목록**: 실행 성공/실패 여부를 색상(초록/빨강)으로 도식화한 인스턴스 목록.
    * **중앙 실행 타임라인**: 노드 간 병렬/직렬 가동 소요 시간을 바 차트(Gantt)로 형상화한 영역.
    * **우측 상세 뷰어**: 선택 노드의 Input, Rendered Input, Output 값을 보여주는 탭 전환식 JSON 에디터.
  * **향후 추가 필요 기능**:
    * 에러 코드 발생 시 백엔드 스택 트레이스를 파싱하여 문제 해결 방안을 즉시 추천해 주는 AI 오류 자동 진단 어시스턴트.
    * 실행이 도중에 중단되었을 때 처음부터 다시 실행하지 않고, 실패한 해당 노드부터 이어서 가동(Resume)시키는 기능.
* **1.6 승인 워크플로우 (Approval Workflow)**
  * **목적**: 담당자 승인이 수반되는 업무 단계의 상태 전이를 관리합니다.
  * **핵심 기능**: 대기, 승인, 반려 등의 전이 규칙 정의. 사용자 역할별 접근 권한 및 추가 정보 요청 알림 기능.
  * **화면 구성**:
    * **상단 내 승인 대기 함**: 내가 결재해야 할 건들의 리스트와 결재 기한.
    * **중앙 요청 상세 정보**: 요청에 이르게 된 이전 워크플로우 노드 실행 결과와 매개 파라미터 요약.
    * **하단 결재 조치 영역**: [승인], [반려], [보완 요청] 등의 처리 액션 버튼과 사유 텍스트 영역.
  * **향후 추가 필요 기능**:
    * 복수의 인원이 순차적으로 승인하는 직렬/병렬 결재 라인 설정 기능.
    * 지정 기한 내에 미승인 상태가 유지될 시 차상위 결재권자에게 자동으로 위임되는 에스컬레이션 정책.
* **1.7 Writeback DLQ (Dead Letter Queue)**
  * **목적**: 외부 ERP, SAP 또는 알림 시스템으로의 저장(Writeback) 실패 이력을 추적하고 복구합니다.
  * **핵심 기능**: 원인 분석 뷰. 지수 백오프 기반 재시도, 수동 Payload 수정 후 재시도(Retry with Edit) 및 무시 옵션 제공.
  * **화면 구성**:
    * **상단 에러 상태 탭**: Pending, Retrying, Failed, Resolved 등 실패 상태 탭.
    * **중앙 에러 내역 리스트**: 실패 원인(HTTP 500, 타임아웃 등), 최종 시도 시각, 대상 Endpoint.
    * **우측 복구 조치 영역**: [수정 후 재시도] 클릭 시 열리는 JSON Payload 임시 에디터 및 즉시 재시도 버튼.
  * **향후 추가 필요 기능**:
    * 연동 대상 서버의 공통 에러 유형별 자동 보정 규칙(Auto-recovery Rule) 스크립트 작성 및 주입 기능.
    * 여러 개의 실패 건을 체크박스로 다중 선택하여 일괄 재시도(Bulk Retry)하는 기능.

### 🗂️ 2. 온톨로지 그룹 (5개 메뉴)
* **2.1 관계 탐색 (Relation Explorer)**
  * **목적**: 온톨로지 데이터베이스의 엔티티와 관계들을 그래프 망으로 시각화하여 조회합니다.
  * **핵심 기능**: 네트워크 토폴로지 렌더링. 타입별 노드 색상 매핑. 노드 선택 시 상세 속성(Properties) 및 Provenance(출처 문서) 패널 표시.
  * **화면 구성**:
    * **중앙 토폴로지 그래프**: 노드와 관계 에지(Edge)가 거미줄 형태로 배치된 시각화 뷰.
    * **우측 정보 패널**: 노드나 에지 선택 시 속성 목록, Provenance 출처 문서 탭 제공.
    * **상단 줌/레이아웃 제어**: 그래프 확대/축소, 강제 유향(Force-directed) 레이아웃 정렬 옵션바.
  * **향후 추가 필요 기능**:
    * 관계의 단계 수(N-Depth)를 실시간 조절하여 주변 노드를 확장 탐색하는 깊이 슬라이더바.
    * 두 노드를 선택 시 가장 짧게 연결된 관계 에지 체인을 찾아 빨간색으로 시각화하는 최단 경로 탐색 도구.
* **2.2 스키마 관리 (Schema Manager)**
  * **목적**: 데이터 모델의 뼈대가 되는 엔티티 타입과 관계 타입을 작성하고 정의합니다.
  * **핵심 기능**: 엔티티 타입 및 속성 포맷(텍스트, 숫자 등) 추가. 엔티티 간 연결 제약인 관계 방향(from-to) 설정 및 변경 영향도 분석.
  * **화면 구성**:
    * **좌측 스키마 목록**: 엔티티 유형 리스트와 관계 유형 리스트를 구분하여 제공.
    * **중앙 스키마 명세 테이블**: 선택한 타입의 속성(자료형, 필수값 유무)을 추가/수정하는 편집 테이블.
    * **우측 메타 그래프**: 전체 모델의 상속 관계 및 도식도를 축소판 그래프로 보여주는 뷰.
  * **향후 추가 필요 기능**:
    * 스키마 변경 시, 이미 적재되어 있는 기존 인스턴스 데이터에 미칠 포맷 손상 경보를 측정해 주는 변경 시뮬레이션(Impact Scanner).
    * 스키마를 XML, JSON-LD, OWL 규격으로 일괄 내보내기/가져오기 하는 메타데이터 이관 기능.
* **2.3 인스턴스 편집 (Instance Editor)**
  * **목적**: 정의된 스키마를 바탕으로 실제 데이터를 생성, 수정, 삭제하는 스프레드시트형 도구입니다.
  * **핵심 기능**: 속성 편집 입력 폼. 대량 엔티티 처리를 위한 Excel/CSV 파일 다운로드/업로드(Bulk Import).
  * **화면 구성**:
    * **상단 조작 바**: 신규 인스턴스 생성 버튼, Excel/CSV 다운로드 및 업로드 드롭존.
    * **중앙 데이터 그리드**: 엑셀 형식의 데이터 행 목록. 다중 선택 및 셀 값 더블클릭 수정 지원.
    * **우측 단건 상세 폼**: 행 선택 시 속성 값을 명확히 채우도록 설계된 텍스트 필드 양식.
  * **향후 추가 필요 기능**:
    * 엑셀/CSV 업로드 시 파일 컬럼명과 온톨로지 속성명이 다를 때, AI가 두 필드의 의미적 유사도를 판단해 매핑해주는 AI 자동 컬럼 매퍼(AI Auto-mapper).
    * 다중 선택한 대량 인스턴스 행의 특정 필드 값을 단번에 덮어씌우는 일괄 편집(Bulk Fill) 유틸리티.
* **2.4 관계 그래프 편집 (Graph Layout Editor)**
  * **목적**: 인스턴스 데이터를 캔버스 상에서 직접 배치하고 연결선을 그려 관계를 정의하는 편집기입니다.
  * **핵심 기능**: 시각적 노드 생성 및 드래그. 마우스 드로우를 통한 관계(에지) 생성 및 RDF 그래프 저장소 실시간 동화.
  * **화면 구성**:
    * **중앙 캔버스**: 인스턴스 카드가 배치되는 격자 무늬 저작 도화지.
    * **좌측 인스턴스 검색기**: 캔버스 위에 노드로 드래그 앤 드롭해 올릴 수 있는 인스턴스 목록.
    * **에지 연결 도구**: 마우스 드로우를 통해 노드 사이를 드래그하여 연결 선을 생성하는 상단 트리거바.
  * **향후 추가 필요 기능**:
    * 스키마에서 정의되지 않은 관계 방향이나 타입을 연결하려 할 때 화면에서 붉은색 경고로 차단하는 스키마 적합성 실시간 검증 레이어.
    * 꼬여 있는 복잡한 에지 선을 보기 좋게 일률 재배치해 주는 레이아웃 알고리즘 셀렉터.
* **2.5 RDF 워크벤치 (RDF Workbench)**
  * **목적**: 외부 시맨틱 웹(Wikidata, DBpedia 등 LOD) 또는 RDF 파일의 관계 데이터를 가져옵니다.
  * **핵심 기능**: 외부 URI 대상 `DESCRIBE` 조회 및 가져오기 규칙 매핑. 로컬 온톨로지 스키마 변환 및 인입 기능.
  * **화면 구성**:
    * **LOD 연동 검색바**: DBpedia 등 외부 엔드포인트 선택창 및 검색할 위키 데이터 엔티티 주소 입력란.
    * **스키마 매핑 맵**: 외부 트리플 키 ➔ 로컬 온톨로지 속성 및 인스턴스 변환 정의 테이블.
    * **결과 로그 영역**: 가져온 데이터 행 수 및 진행 상황 표시창.
  * **향후 추가 필요 기능**:
    * 외부 LOD 데이터 적재 작업을 주기적으로 가동할 수 있도록 크론식(Cron Expression)을 지원하는 가져오기 자동 스케줄러.
    * 외부 지식 연동 중 단절이 발생하면 캐시된 이전 버전의 온톨로지로 자동 롤백하는 장애 내성 트랜잭션 도구.

### 🔍 3. 질의와 분석 그룹 (6개 메뉴)
* **3.1 대시보드 (Dashboard)**
  * **목적**: 온톨로지 데이터 사용 추이 및 사용자 액션 큐를 대시보드 형태로 제공합니다.
  * **핵심 기능**: 시스템 사용 통계(누적 질의, 성공률). 사용자가 수동 개입해야 하는 '작업 큐(Workflow Queue)' 목록 바로가기.
  * **화면 구성**:
    * **상단 KPI 위젯**: 질의 횟수 추이 그래프, RAG 적중 성공률 미터, 평균 레이턴시 차트.
    * **중앙 사용량 차트**: 자연어 질의, SPARQL 질의, 하이브리드 질의 등 유형별 사용량을 비교한 파이 차트.
    * **하단 일감 큐**: 승인 요청, DLQ 에러 등 사용자가 오늘 조치해야 할 주요 작업 항목 요약 표.
  * **향후 추가 필요 기능**:
    * 개별 부서나 사용자 기호에 맞춰 대시보드 내 위젯을 자유롭게 변경하고 배치하는 Drag-and-drop 대시보드 커스터마이저.
    * 월간 지표 요약 보고서를 생성하여 PDF 파일로 자동 메일 발송해 주는 기능.
* **3.2 객체 탐색 (Entity Explorer)**
  * **목적**: 인덱스 검색을 통해 온톨로지 내 모든 엔티티 데이터를 간편하게 검색합니다.
  * **핵심 기능**: 키워드 통합 검색. 엔티티 유형 및 활성화 상태 필터링. 상세 페이지 바로가기.
  * **화면 구성**:
    * **상단 통합 검색란**: 자동완성과 오타 교정을 지원하는 입력창.
    * **좌측 Facet 필터 사이드바**: 생성 일자 범위, 특정 속성 수치 구간(예: budget > 3M) 필터링 조건 설정창.
    * **중앙 매칭 결과**: 조건에 부합하는 인스턴스 목록 카드 그리드와 매칭 스코어 표시.
  * **향후 추가 필요 기능**:
    * 최근 검색어 자동 저장 및 자주 찾는 중요 객체를 화면 최상단에 핀으로 고정해 조회하는 개인화 북마크.
* **3.3 온톨로지 질의 (AI Query)**
  * **목적**: 자연어 질문을 AI가 SPARQL 쿼리로 기계 변환하여 데이터를 탐색하는 대화형 엔진입니다.
  * **핵심 기능**: 자연어 입력 ➔ SPARQL 자동 생성 및 실행 ➔ 정제된 자연어 요약 답변 및 그래프 쿼리 이력 조회.
  * **화면 구성**:
    * **중앙 채팅 영역**: 자연어 질문 입력 폼 및 LLM이 답변하는 대화형 채팅 피드 패널.
    * **우측 기술 상세 탭**: LLM이 자동 번역한 원본 SPARQL 쿼리문, 실제 SPARQL 실행 결과 JSON 표 및 온톨로지 메타 컨텍스트 뷰.
  * **향후 추가 필요 기능**:
    * 도출된 AI 답변의 사실 부합도(Factuality Score)를 점수로 계산하여 띄워주는 정확도 검증 지표 컴포넌트.
    * SPARQL 쿼리가 구문 오류로 실패할 경우, LLM이 자동으로 오류 코드를 분석해 쿼리를 고쳐서 재실행하는 Self-healing 쿼리 런타임.
* **3.4 통합 질의 (Hybrid Query)**
  * **목적**: 온톨로지 데이터와 RAG의 비정형 문서를 복합 결합하여 사실에 입각한 지식을 도출합니다.
  * **핵심 기능**: 구조화된 SPARQL 조회 결과와 벡터 문서 검색 결과를 동시에 컨텍스트로 LLM에 입력하여 신뢰도 극대화.
  * **화면 구성**:
    * **중앙 대화창**: 자연어 형태의 복합 질문 창.
    * **우측 출처 근거 판넬**: 지식 융합에 사용된 RAG 문서 청크 내용(유사도 점수 포함) 및 매핑된 온톨로지 엔티티 속성 요약.
  * **향후 추가 필요 기능**:
    * 비정형 문서의 내용과 정형 온톨로지 데이터 간 모순이 발견되면 화면 상단에 붉은색 오류 경고를 노출하는 시맨틱 모순 감지 엔진.
    * 쿼리당 발생하는 실시간 LLM 토큰 수와 요금을 측정하여 알려주는 비용 통계 보드.
* **3.5 문서 RAG 질의 (Document RAG)**
  * **목적**: 플랫폼 내 업로드된 매뉴얼, 기안서 등의 원문 문서에 근거한 검색 질의를 수행합니다.
  * **핵심 기능**: PDF/Docs 임베딩 처리. 질문과 유사도가 높은 청크 검색 및 출처 하이라이팅 답변 제공.
  * **화면 구성**:
    * **좌측 문서 업로드 함**: 시연용 PDF/Docs 파일 드롭 업로드 및 변환 성공 여부 상태 표시창.
    * **중앙 질의 답변 피드**: 문서 기반 검색 질문 및 인용답변 윈도우.
    * **우측 PDF 뷰어**: 인용된 답변의 실제 출처 문단을 PDF 페이지 내에서 노란색/빨간색 마크업 박스로 보여주는 원문 뷰어.
  * **향후 추가 필요 기능**:
    * 문서 내부의 이미지(도면, 차트)나 테이블을 고성능으로 분석하여 인용하는 멀티모달(Multimodal) RAG 리더 탑재.
* **3.6 SPARQL 콘솔 (SPARQL Console)**
  * **목적**: 시맨틱 웹 표준 SPARQL 문법으로 정밀하고 복잡한 구조 질의를 수행하는 고급 콘솔입니다.
  * **핵심 기능**: 구문 하이라이트 에디터. 쿼리 최적화를 위한 실행 계획(Explain) 설명. 표 및 그래프 데이터 시각화.
  * **화면 구성**:
    * **상단 쿼리 편집창**: 줄 번호 및 구문 자동 강조 기능이 내장된 SPARQL 에디터.
    * **하단 결과 보기 영역**: 데이터 테이블 뷰 탭 및 트리플 형태를 관계 노드 다이어그램으로 시각화한 그래프 뷰 탭.
    * **우측 실행 리포트**: 쿼리 소요 시간(ms), 스캔 범위, 오류 로그 표시창.
  * **향후 추가 필요 기능**:
    * 자주 사용하는 복잡한 SPARQL 쿼리를 템플릿 라이브러리로 저장해 두고 언제든 불러오는 쿼리 즐겨찾기 보관함.
    * 대량 쿼리 결과에 대해 Limit & Offset을 에디터 수준에서 자동으로 분할 처리해 주는 자동 페이징 기능.

### 🛡️ 4. 운영과 검증 그룹 (2개 메뉴)
* **4.1 감사 로그 (Audit Log)**
  * **목적**: 플랫폼 내의 데이터 파손 방지 및 통제를 위해 작업 기록을 감사(Audit)합니다.
  * **핵심 기능**: 사용자ID, IP, 변경사항(Diff) 수집. 특정 시점의 데이터로 즉시 롤백하는 '복원(Restore)' 기능.
  * **화면 구성**:
    * **중앙 이벤트 로그 격자**: 발생 시각, 사용자, 액션 유형, 리소스 ID, IP 주소 목록 테이블.
    * **하단 변경 내역 비교 뷰**: 행 선택 시 속성 값의 수정 사항을 빨간색(기존)과 초록색(변경)으로 정밀 대조하는 Diff 패널.
    * **버전 롤백 제어**: 클릭 시 감사 시점의 원본 값으로 원격 복구하는 [복원 (Restore)] 버튼.
  * **향후 추가 필요 기능**:
    * 특정 시간 내 대량의 리소스를 임의 삭제하려 하거나 허가되지 않은 스키마 편집을 가할 시 즉각 관리자에게 경보를 띄우는 이상 징후 자동 알림 엔진.
* **4.2 통합 테스트 (Integration Test)**
  * **목적**: 에이전트 자동화 시나리오 및 LLM 쿼리 신뢰도를 자동 평가합니다.
  * **핵심 기능**: 정답 셋(Ground Truth)과 비교하는 자동 배치 평가. 통과율(Pass Rate) 트렌드 분석 및 성능 벤치마크 추적.
  * **화면 구성**:
    * **상단 통계 위젯**: 총 테스트 케이스 수, 성공률, 통과율 변동성 선형 그래프.
    * **중앙 테스트 결과 리스트**: 예상 결과와 실제 LLM 결과를 대조하여 Pass/Fail 칩으로 표시한 격자 테이블.
    * **하단 예외 덤프 분석기**: 실패 건 선택 시, API 타임아웃 오류 메시지 및 예외 추적 디버그 로그 표시창.
  * **향후 추가 필요 기능**:
    * Git 커밋 또는 배포가 일어날 때 자동으로 런타임 테스트가 가동되는 CI/CD 연동 Webhook 모듈.
    * 테스트 실패 시, 원인이 되는 백엔드 소스 로그를 역추적해 해결 팁을 제공하는 AI 디버그 도우미.

## 🔗 메뉴 간 데이터 흐름

### 워크플로우 → 온톨로지
- **빌더와 실행**에서 workflow node를 생성할 때 온톨로지의 스키마 정보 참조
- **온톨로지 매핑** 탭에서 workflow output을 온톨로지 entity로 저장
- **실행 추적**에서 온톨로지에 저장된 결과 조회

### 온톨로지 → 질의와 분석
- **스키마 관리**에서 정의한 엔티티/관계가 질의의 기반 제공
- **관계 탐색**의 그래프가 SPARQL 쿼리 작성에 활용
- **인스턴스 편집**의 데이터가 AI 질의의 근거 제공

### 질의와 분석 → 운영과 검증
- **온톨로지 질의** 결과가 **감사 로그**에 기록
- **통합 테스트**에서 질의 정확도/성능 검증

## 🎓 학습 경로

### 초급 (기본 이해)
1. 워크플로우 홈 - 플랫폼 소개 및 최근 활동 확인
2. 대시보드 - 주요 지표 및 작업 큐 이해
3. 객체 탐색 - 온톨로지 데이터 구조 파악

### 중급 (실제 사용)
1. 스키마 관리 - 데이터 모델 정의
2. 인스턴스 편집 - 실제 데이터 입력
3. 빌더와 실행 - 간단한 워크플로우 생성
4. 온톨로지 질의 - AI 기반 데이터 조회

### 고급 (전문가 수준)
1. 관계 그래프 편집 - 복잡한 데이터 관계 설계
2. SPARQL 콘솔 - 정형 그래프 쿼리 작성
3. 통합 질의 - 온톨로지 + RAG 결합 분석
4. RDF 워크벤치 - 외부 온톨로지 (DBpedia, Wikidata) 연결

## ⚠️ 주의사항

| 메뉴 | 주의사항 |
|------|---------|
| 빌더와 실행 | 저장 전에 스킬 설정 검증 필수 |

| 감사 로그 | 민감 데이터 필터링 옵션 확인 |
