## 2. 정책 QA 결과

### 2.1 GENERAL_ONLY confidence 정책

이전 우려:

```text
GENERAL_ONLY인데 confidence_score=0.85이면 사용자가 문서 직접 근거가 충분하다고 오해할 수 있다.
```

현재 코드:

```text
NO_ANSWER    -> confidence_score = 0.0
GENERAL_ONLY -> confidence_score = 0.55
PARTIAL      -> confidence_score = 0.75
NORMAL       -> confidence_score = 0.95
```

검증:

```text
DB schema / expert_mode:
  answer_status=GENERAL_ONLY
  confidence_score=0.55
```

판정:

```text
GENERAL_ONLY + 0.85 과신 리스크: 해소
```

### 2.2 Snowflake false positive 방어

검증:

```text
Snowflake / document_only:
  answer_status=NO_ANSWER
  confidence_score=0.0
  rag=5
  filtered=5
```

판정:

```text
Snowflake false positive 방어: GO
```
