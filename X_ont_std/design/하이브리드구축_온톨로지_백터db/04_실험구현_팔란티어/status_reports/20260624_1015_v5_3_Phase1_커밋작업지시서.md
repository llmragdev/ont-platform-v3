## 1. 역할 분담

### Claude Code PM

역할: 커밋 실행 담당

책임:

1. `git add` 대상 목록을 먼저 제시한다.
2. ANTI 검토를 받은 뒤 선별 add를 수행한다.
3. 커밋 메시지를 작성하고 커밋을 수행한다.
4. 커밋 해시와 포함 파일 목록을 최종 보고한다.

### Antigravity

역할: 커밋 전 정책/범위 QA

책임:

1. Claude가 제시한 `git add` 목록을 검토한다.
2. 정책상 포함되면 안 되는 파일이 있는지 확인한다.
3. 검색 히스토리 기능이 “구현”으로 과장 표현되지 않았는지 확인한다.
4. Word 증거 파일, 임시 스크립트, 대량 untracked 산출물이 포함되면 `WAIT` 판정한다.

### Codex

역할: 기술 근거 및 커밋 후보 제공

책임:

1. v5.3 backend/frontend/test/docs 후보를 제공한다.
2. 회귀 테스트와 수동 smoke 증거를 근거로 GO/WAIT를 분리한다.
3. 커밋 후 필요 시 후속 구현 항목을 정리한다.

## 6. ANTI 검토 기준

ANTI는 Claude의 add 목록을 보고 아래 기준으로 판정한다.

GO 조건:

- Commit A 포함 후보만 들어 있음
- Word evidence `.doc` 파일 없음
- `phase0_report_script.py` 없음
- 대량 산출물 없음
- 검색 히스토리 기능이 구현 완료로 과장되지 않음

WAIT 조건:

- Downloads의 Word evidence가 포함됨
- env 실행 안정화 파일이 Commit A에 섞임
- 무관한 대량 untracked가 포함됨
- commit message가 `GO/NO_GO` 등 실제 status와 다른 용어를 사용함
