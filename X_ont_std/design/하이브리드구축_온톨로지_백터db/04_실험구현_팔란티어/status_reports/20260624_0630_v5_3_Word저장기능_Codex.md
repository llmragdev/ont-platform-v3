# v5.3 QA 결과 Word 저장 기능 구현

- 작성자: Codex
- 기준 시각: 2026-06-24 06:30 KST
- 대상: `ont_platform/v5/frontend`
- 판정: 기능 구현 완료 / 브라우저 클릭 저장 확인은 사용자 수동 확인 필요

## 1. 배경

UI smoke와 성능 평가 과정에서 매번 화면을 직접 캡처하고 정리하는 비용이 높았다. 평가 질문별 결과를 이미지 포함 Word 파일로 저장할 수 있도록 최소 기능을 추가했다.

## 2. 구현 내용

### 추가 의존성

- `html2canvas`

변경 파일:

- `ont_platform/v5/frontend/package.json`
- `ont_platform/v5/frontend/package-lock.json`

### UI 변경

변경 파일:

- `ont_platform/v5/frontend/src/components/query/AnswerDisplay.tsx`

답변 생성이 완료되면 답변 영역 상단에 `Word 저장` 버튼이 표시된다.

저장 파일 형식:

- 확장자: `.doc`
- 내용: Word 호환 HTML
- 포함 항목:
  - 생성 시각
  - 질문
  - 답변 모드
  - v5.3 판정
  - gate decision
  - confidence
  - coverage level
  - 답변 본문
  - 제한사항
  - 저장 시점의 답변/근거 패널 캡처 이미지

## 3. 검증

수행:

```powershell
npx tsc --noEmit
```

결과:

- 전체 타입 검사는 기존 unrelated 오류로 실패.
- 이번 변경 파일인 `AnswerDisplay.tsx` 또는 `html2canvas` import 관련 신규 오류는 출력되지 않음.

수행:

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:3001/hybrid-query
```

결과:

- HTTP 200
- `Module not found`, `Failed to compile`, `Build Error`, `Runtime Error` 마커 없음.

## 4. 사용 방법

1. 질의를 실행한다.
2. 답변 생성이 끝날 때까지 기다린다.
3. 답변 영역 상단의 `Word 저장` 버튼을 클릭한다.
4. 다운로드된 `.doc` 파일을 Word에서 연다.

## 5. 한계 및 후속 개선

- 현재는 진짜 OOXML `.docx`가 아니라 Word 호환 HTML `.doc`이다.
- 데모와 평가 기록 용도로는 충분하지만, 장기적으로는 `docx` 패키지 기반의 정식 `.docx` export로 전환할 수 있다.
- 전체 페이지가 아니라 답변/근거 패널 중심으로 캡처한다.
