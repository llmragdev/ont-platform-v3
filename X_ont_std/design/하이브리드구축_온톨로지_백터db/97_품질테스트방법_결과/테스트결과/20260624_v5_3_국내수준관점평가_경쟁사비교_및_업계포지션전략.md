# v5.3 국내 수준 관점 평가, 경쟁사 비교 및 업계 포지션 전략

- 작성일: 2026-06-24
- 작성자: Codex
- 대상: `ont_platform/v5` Hybrid Query Engine v5.3
- 문서 성격: 국내 시장 관점의 전략 평가
- 중요 전제: 본 문서의 경쟁사 수준과 예상 순위는 공개 자료와 현재 v5.3 테스트 결과를 바탕으로 한 **가정 기반 평가**이다. 실제 시장 순위, 매출, 고객 수, 성능 benchmark를 확정하는 문서가 아니다.

## 1. 평가 결론

개인 연구/PoC 결과물 기준으로 v5.3 Phase 1은 상당히 우수하다. 특히 단순 RAG가 아니라 **벡터 검색 + 온톨로지 그래프 + answerability gate + confidence policy + Word evidence 저장**까지 연결했다는 점에서 국내 단순 RAG QA봇 대비 차별성이 크다.

다만 국내 엔터프라이즈 AI 시장 전체에서 “최상위 확정”이라고 표현하기에는 아직 이르다. 현재 적절한 표현은 다음과 같다.

```text
국내 단순 RAG QA봇 대비: 상위권 후보
국내 온톨로지 결합 QA 데모 기준: 강한 경쟁력 있음
제한 고객 PoC 기준: 조건부 GO
국내 엔터프라이즈 상용 제품 최상위 확정: 아직 NO
```

## 2. 현재 v5.3의 긍정적 측면

### 2.1 단순 RAG를 넘어선 답변 가능성 판단

일반 RAG QA봇은 검색 결과가 있으면 답변을 생성하는 경우가 많다. v5.3은 검색 결과가 있어도 문서/온톨로지 근거가 충분하지 않으면 `NO_ANSWER / 0%`로 차단한다.

검증된 결과:

- Snowflake 질문: `NO_ANSWER / blocked / 0%`
- Kubernetes 질문: `NO_ANSWER / blocked / 0%`
- Azure AI Search 질문: `NO_ANSWER / blocked / 0%`

이는 “답변 생성 능력”보다 “답변해도 되는지 판단하는 능력”을 제품의 핵심 가치로 둔 구조다.

### 2.2 상태와 신뢰도 정책의 명시화

현재 상태 체계:

| 상태 | 신뢰도 | 의미 |
|---|---:|---|
| `NO_ANSWER` | `0%` | 답변 차단 |
| `GENERAL_ONLY` | `55%` | 일반 설명, 문서 근거 부족 |
| `PARTIAL` | `75%` | 제한적 근거 답변 |
| 정상 근거 충분 | `95%` | 근거 기반 답변 |

이 정책은 사용자가 “AI가 말했으니 맞겠지”라고 오해하는 위험을 줄인다.

### 2.3 온톨로지 그래프 결합

v5.3은 RAG source와 ontology source를 별도로 보여주고, ontology graph까지 시각화한다. 이는 설명가능성 측면에서 단순 vector search 기반 챗봇보다 강하다.

### 2.4 실무형 Word evidence 저장

사용자는 8개 테스트 결과를 Word evidence로 저장했고, 내부 HTML 메타에서 다음 항목을 확인했다.

- 질문
- v5.3 판정
- 신뢰도
- 화면 캡처 이미지

국내 실무 환경에서는 “답변을 받는 것”만큼 “보고서/검토 증거를 남기는 것”이 중요하다. 이 기능은 실제 PoC 설득력에 도움이 된다.

### 2.5 개인 연구 성과로서의 가치

개인 연구로 다음 요소를 통합했다는 점은 강점이다.

- RAG
- ontology graph
- answerability gate
- confidence policy
- source filtering
- UI badge
- Word evidence export
- 수동 smoke evidence
- 설계/테스트 보고서 체계화

이는 일반적인 개인 RAG 프로젝트보다 성숙도가 높다.

## 3. 현재 v5.3의 부정적 측면 및 한계

### 3.1 테스트 규모 부족

현재 근거:

- backend 기본 4문항
- backend 확장 12문항
- UI 수동 Word evidence 8건

이는 기능 검증에는 충분하지만, 제품 품질 보증에는 부족하다.

필요:

- 최소 100문항
- 권장 300문항 이상
- 도메인별 false positive/false negative 평가

### 3.2 자동화 부족

Cypress spec은 있으나 실제 실행은 환경 이슈로 WAIT/SKIP 상태다.

필요:

- Cypress 또는 Playwright 자동화 복구
- CI/CD에서 회귀 테스트 자동 실행
- UI screenshot 또는 DOM assertion 기반 검증

### 3.3 상용 제품 기능 부족

아직 부족한 기능:

- 전문가 의견 등록 UI/API
- 검색 히스토리 snapshot 복원 구현
- ontology graph snapshot 복원 구현
- 정식 `.docx`/PDF export
- 인증/인가
- 멀티테넌트
- 운영 모니터링
- 고객별 데이터 격리

### 3.4 Word export의 형식 한계

현재는 정식 `.docx`가 아니라 Word 호환 HTML `.doc`이다. Phase 1 데모에는 충분하지만 엔터프라이즈 보고서 자동화 기능으로 내세우려면 정식 `.docx` 또는 PDF export가 필요하다.

### 3.5 글로벌/대기업 운영 검증 부족

아직 확인되지 않은 항목:

- 동시 사용자 부하
- LLM quota/rate limit 대응
- 장애 복구
- latency SLA
- 보안 감사
- 데이터 거버넌스와 감사 로그

## 4. 국내 예상 경쟁사별 수준 평가

아래 평가는 공개 자료를 참고한 **가정 기반 전략 평가**이다.

### 4.1 솔트룩스

공개 자료 기준:

- 솔트룩스는 기업용 AI 검색, 생성형 AI 챗봇, AI agent 솔루션을 제공한다고 소개한다.
- 루시아 A.RAG는 GS인증 1등급을 획득했다는 공개 보도가 있다.
- 공개 자료에는 벡터 기반 의미 검색, 대화 맥락 반영, 한·영 쿼리 확장, AI 리랭킹, 온톨로지 기반 지식 관리 플랫폼 연동 등이 언급된다.

예상 수준:

| 항목 | 예상 수준 |
|---|---|
| 제품화 | 높음 |
| 공공/기업 레퍼런스 | 높음 |
| RAG/AI 검색 기능 | 높음 |
| 인증/상용 안정성 | 높음 |
| ontology 연동 | 높음 |
| answerability gate 세밀도 | 공개 자료만으로는 확인 필요 |

v5.3 대비:

- 솔트룩스는 상용 제품화, 인증, 영업/레퍼런스 측면에서 훨씬 앞설 가능성이 높다.
- v5.3은 특정 화면에서 `NO_ANSWER/PARTIAL/GENERAL_ONLY`와 confidence를 명시적으로 보여주는 실험적 UX에서 차별화 가능성이 있다.

전략:

- 솔트룩스와 정면 경쟁하기보다 “도메인 특화 answerability gate + ontology graph 설명성 + 평가 evidence 자동화”를 차별점으로 가져가야 한다.

### 4.2 엔코아

공개 자료 기준:

- 엔코아는 AI Ready Data, 데이터 거버넌스, 데이터 표준화, 메타데이터 관리, AI 기반 자동화에 강점을 가진 회사로 소개된다.
- META# AI 관련 공개 자료에는 RAG 기반 지식 수집, 업무문서/베이스사전/DB카탈로그 정보를 활용한 데이터 표준화 자동화 흐름이 언급된다.

예상 수준:

| 항목 | 예상 수준 |
|---|---|
| 데이터 거버넌스 | 매우 높음 |
| 메타데이터/표준화 | 매우 높음 |
| 컨설팅/대기업 프로젝트 | 높음 |
| RAG 기반 업무 자동화 | 중상~상 |
| ontology QA 제품화 | 확인 필요 |

v5.3 대비:

- 엔코아는 데이터 표준화, 메타데이터, 기업 데이터 거버넌스에서 강한 기반을 갖고 있을 가능성이 높다.
- v5.3은 QA 화면에서 gate, source filtering, ontology graph를 사용자가 직접 확인하는 UX가 강점이다.

전략:

- 엔코아와 결합하면 v5.3은 “데이터 거버넌스/표준화 결과를 질의응답으로 검증하고 설명하는 프론트/게이트 레이어”가 될 수 있다.

### 4.3 디노티시아

공개 자료 기준:

- 디노티시아는 AI와 데이터 시스템 융합, RAG 솔루션, 장기기억 AI, 벡터 데이터베이스/벡터 연산 가속기, Seahorse 등의 키워드가 공개 자료에서 확인된다.
- 벡터 DB 및 RAG 통합, 공공/민간 실전형 AI 솔루션 보급 관련 보도가 있다.

예상 수준:

| 항목 | 예상 수준 |
|---|---|
| 벡터 DB/인프라 기술 | 높음 |
| RAG 검색 인프라 | 높음 |
| 장기기억 AI/개인화 | 중상~상 |
| 엔터프라이즈 UI/업무 UX | 확인 필요 |
| ontology 기반 gate | 확인 필요 |

v5.3 대비:

- 디노티시아는 벡터 DB/검색 인프라와 성능 최적화 측면에서 강할 가능성이 있다.
- v5.3은 인프라 자체보다는 answerability policy, ontology graph UX, evidence 저장에서 차별화된다.

전략:

- 디노티시아와 결합하면 v5.3은 고성능 검색/장기기억 인프라 위에 올라가는 “신뢰성 게이트 + 도메인 설명 UI” 역할을 할 수 있다.

### 4.4 기타 국내 경쟁군

가정 기반 경쟁군:

- 대기업 SI/클라우드 계열 AI 검색 솔루션
- 네이버/카카오/KT/LG 계열 생성형 AI 플랫폼
- AI 검색/RAG 스타트업
- 공공 SI 기반 문서 QA 솔루션
- GraphRAG/Knowledge Graph 전문 기업

예상:

- 대기업 계열은 운영/보안/영업/인프라가 강하다.
- 스타트업은 UX와 빠른 기능 출시가 강하다.
- SI 계열은 고객 맞춤 구축이 강하지만 제품 공통화가 약할 수 있다.
- v5.3은 “작지만 gate와 ontology UX가 뚜렷한 PoC” 포지션이다.

## 5. 국내 경쟁사 대비 v5.3 예상 위치

### 5.1 현재 Phase 1 기준

가정:

- v5.3은 개인 연구/PoC 결과물이다.
- 대규모 고객 운영, 인증, 보안, 성능 테스트는 아직 없다.
- 평가셋은 8~16문항 수준이다.

예상 위치:

| 구분 | 예상 순위권 |
|---|---|
| 단순 RAG 데모 대비 | 상위 20~30% 후보 |
| ontology 결합 QA 데모 대비 | 상위 10~20% 후보 |
| 엔터프라이즈 상용 제품 전체 대비 | 중위권 이하~중위권 후보 |
| 개인 연구 프로젝트 대비 | 상위권 |

해석:

- 기능 아이디어와 gate UX는 강하다.
- 제품 완성도, 운영, 보안, 레퍼런스는 아직 약하다.

## 6. 엔코아, 솔트룩스, 디노티시아 합류 시 포지션 전망

이 절은 “각 회사와 협업 또는 합류가 이루어진다”는 가정 기반 시나리오다.

### 6.1 엔코아 합류 시

가정:

- 엔코아가 데이터 표준화, 메타데이터, 데이터 거버넌스 레이어를 제공한다.
- v5.3이 QA/gate/explanation UI를 담당한다.

예상 시너지:

- DB 스키마, 표준 용어, 메타데이터 기반 QA 품질 상승
- AI Ready Data와 answerability gate 결합
- 데이터 표준화 프로젝트의 검증/설명 인터페이스 확보

예상 업계 포지션:

```text
데이터 거버넌스 기반 QA/설명형 AI 영역에서 국내 상위권 후보
```

예상 순위:

- 데이터 표준화/거버넌스 결합 QA: 상위 10~20% 후보
- 범용 AI 검색 제품: 중상위권 후보

전략:

- “데이터 거버넌스 결과를 검증 가능한 QA로 연결”하는 메시지 사용
- DB schema to ontology, standard term QA, lineage QA에 집중

### 6.2 솔트룩스 합류 시

가정:

- 솔트룩스가 상용 AI 검색/RAG 플랫폼, LLM, 공공/기업 레퍼런스, 인증 기반을 제공한다.
- v5.3이 answerability gate와 ontology evidence UX를 보강한다.

예상 시너지:

- 기존 AI 검색 제품에 강한 근거 차단/신뢰도 정책 추가
- 공공/기업 고객 대상 “안전한 RAG” 메시지 강화
- GS인증/상용 레퍼런스와 v5.3 gate UX 결합

예상 업계 포지션:

```text
공공/기업용 신뢰형 AI 검색 영역에서 국내 최상위권 후보
```

예상 순위:

- 공공/기업 AI 검색: 상위 5~10% 후보
- ontology 기반 안전 RAG: 상위권 후보

전략:

- “답하지 말아야 할 질문을 차단하는 RAG”를 핵심 차별점으로 제시
- LLM guardrail이 아니라 retrieval/ontology 기반 answerability gate임을 강조

### 6.3 디노티시아 합류 시

가정:

- 디노티시아가 벡터 DB, RAG 인프라, 장기기억 AI/검색 성능 최적화를 제공한다.
- v5.3이 domain gate, ontology graph, evidence UI를 담당한다.

예상 시너지:

- 검색 성능과 응답 속도 개선
- 대규모 vector retrieval 기반 위에 answerability gate 적용
- 장기기억/개인화 검색 결과의 안전성 제어

예상 업계 포지션:

```text
고성능 RAG 인프라 + 신뢰성 gate 결합 영역에서 국내 상위권 후보
```

예상 순위:

- 고성능 RAG/Vector DB 기반 QA: 상위 10~20% 후보
- 특화 하드웨어/검색 인프라 결합 서비스: 차별화 가능

전략:

- “빠른 검색”만이 아니라 “빠르고 안전한 답변 가능성 판단”으로 포지셔닝
- 대규모 문서/장기기억 기반 QA에서 false positive 차단을 강조

### 6.4 세 회사 모두 합류 시

가정:

- 엔코아: 데이터 거버넌스/표준화/메타데이터
- 솔트룩스: 상용 AI 검색/LLM/레퍼런스/인증
- 디노티시아: 벡터 DB/RAG 인프라/장기기억
- v5.3: answerability gate/ontology graph UX/evidence export

예상 통합 포지션:

```text
데이터 거버넌스 + RAG 검색 + 온톨로지 + 신뢰성 게이트 + 증거 보고를 결합한 국내 최상위권 엔터프라이즈 AI QA 플랫폼 후보
```

예상 순위:

| 영역 | 예상 순위 |
|---|---|
| 국내 단순 RAG QA | 최상위권 가능 |
| 국내 도메인 특화 GraphRAG/온톨로지 QA | 최상위권 후보 |
| 공공/금융/제조 PoC | 매우 경쟁력 있음 |
| 글로벌 엔터프라이즈 GA | 추가 검증 필요 |

단, 이 경우에도 글로벌 수준을 말하려면 보안, 운영, 다국어, 성능, 평가 자동화가 필요하다.

## 7. 전략 제안

### 7.1 제품 포지셔닝

권장 메시지:

```text
답변을 잘 만드는 RAG가 아니라, 답변해도 되는지 판단하는 신뢰형 RAG
```

보조 메시지:

```text
문서 근거, 온톨로지 근거, 전문가 의견을 분리해 검증하는 엔터프라이즈 QA
```

피해야 할 메시지:

```text
국내 최상위 확정
글로벌 수준 완성
모든 도메인에서 환각 방지
```

### 7.2 초기 타깃

추천 타깃:

1. 데이터 표준화/거버넌스 QA
2. 국방/공공 온톨로지 QA
3. 제조 설비/품질 문서 QA
4. 금융 내부 규정 QA
5. 대규모 PDF/DB schema 혼합 QA

이유:

- 문서 근거와 용어/관계 구조가 중요하다.
- 잘못 답하면 위험이 크다.
- `NO_ANSWER` 차단 가치가 크다.

### 7.3 단기 개발 전략

Phase 1.5:

- 검색 히스토리 snapshot 복원
- ontology graph snapshot 복원
- 정식 `.docx` export
- Cypress/Playwright 자동화 복구

Phase 2:

- 전문가 의견 등록 UI/API
- 100~300문항 평가셋
- RAG/LLM 자동 평가
- 도메인별 false positive/false negative 측정

Phase 3:

- 보안/권한/멀티테넌트
- 운영 모니터링
- 부하 테스트
- 고객 PoC 패키지

### 7.4 제안서/데모 전략

데모 구성:

1. 통과해야 하는 내부 도메인 질문
2. 차단해야 하는 외부 도메인 질문
3. 같은 질문을 전문가 모드/문서 제한 모드에서 비교
4. ontology graph 근거 설명
5. Word evidence 저장
6. 히스토리 snapshot 복원

핵심 설득 포인트:

- “잘 답하는 것”보다 “잘못 답하지 않는 것”
- 문서 근거와 일반 설명을 분리
- 테스트 evidence를 남김
- 고객 감사/품질검증 프로세스에 연결 가능

## 8. 예상 아웃풋 수준

### 현재 Phase 1

예상 아웃풋:

- 내부 데모 가능
- Word evidence 기반 품질 검토 가능
- 제한 고객 PoC 소개 가능
- 개인 연구 성과로 강함

한계:

- 고객 운영 투입은 이르다.

### Phase 1.5 완료 후

예상 아웃풋:

- 데모 완성도 크게 향상
- 반복 검색 UX 개선
- 보고서 자동화 설득력 강화
- 고객 PoC 자료 패키지화 가능

한계:

- 보안/운영 검증은 아직 부족하다.

### Phase 2 완료 후

예상 아웃풋:

- 전문가 지식 기반 QA로 확장
- 평가셋 기반 품질 수치 제시 가능
- 도메인별 고객 PoC 가능성 상승

한계:

- 대규모 운영 검증 필요.

### Phase 3 완료 후

예상 아웃풋:

- 국내 특화 엔터프라이즈 QA beta 후보
- 공공/제조/금융 PoC 경쟁 가능
- 파트너사 협업 시 국내 상위권 제품 후보

한계:

- 글로벌 GA는 별도 장기 로드맵 필요.

## 9. 최종 판단

현재 v5.3 Phase 1은 개인 연구/PoC 기준으로 매우 좋은 성과다. 국내 단순 RAG QA봇과 비교하면 상위권 후보로 볼 수 있다. 특히 answerability gate와 ontology graph를 UI에서 함께 보여주고, Word evidence까지 남기는 흐름은 실무 설득력이 있다.

하지만 국내 엔터프라이즈 AI 시장에서 최상위 제품이라고 확정하려면 대규모 평가, 자동화, 보안, 운영, 고객 검증이 필요하다.

가정 기반 최종 포지션:

```text
현재 단독 v5.3: 국내 단순 RAG 대비 상위권 후보
Phase 1.5 완료: 국내 PoC/데모 상위권 후보
Phase 2 완료: 국내 도메인 특화 QA 상위권 후보
엔코아/솔트룩스/디노티시아 협업 시: 국내 최상위권 후보 가능
글로벌 GA: 별도 장기 검증 필요
```
