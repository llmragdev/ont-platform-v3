## 🎯 **평가 문항 1: 온톨로지 역할**

### **질문**
```
"온톨로지 기반 질의응답에서 온톨로지는 어떤 역할을 하는가?"
```

### **예상 답변**

```
온톨로지는 특정 영역(도메인)의 개념을 분류하고 개념 간의 관계를 
명시적으로 모델링하여 컴퓨터가 처리 가능한 지식 구조를 제공한다.

핵심 역할:
1. 다출처 데이터의 의미적 통합
2. 구조화된 데이터 표현 (Class/Property/Instance)
3. 의미 기반 검색 및 추론
4. 시스템 간 상호운용성 확보
```

### **v5 현재 답변 (Phase 1 후)**

```
온톨로지는 질의응답에서 단순 키워드 매칭 수준을 넘어, 
도메인의 개념을 문제하고 개념 사이의 관계를 모델링하는 
기초 지식 구조입니다. 문서와 데이터에 플러진 의미를 통합해 
컴퓨터가 처리할 수 있는 기계 판독 가능한 지식으로 바꾸며, 
Class/Property/Instance 같은 구조로 대상과 속성, 사례를 
명확히 표현합니다. 도한 온톨로지는 서로 다른 문서, 데이터베이스, 
시스템 사이의 의미를 맞추는 상호운용성의 기초이 되어, 질의응답에 
있어서 온톨로지의 역할은 단순 키워드만을 바탕으로 관계를 모델링하는 
기초 지식 구조를 사용하도록 함으로써 질의응답이 더 원란된 근거를 
제공할 수 있다...
```

### **평가 분석**

#### **강점 (득점 요인)**

```

   1. 개념 분류: "개념을 문제하고" ✅
   2. 관계 모델링: "관계를 모델링" ✅
   3. 구조화: "Class/Property/Instance" ✅
   4. 의미적 통합: "의미를 통합" ✅
   5. 상호운용성: "상호운용성의 기초" ✅
   
✅ 질의응답 맥락: "질의응답에서 역할" 명시 ✅
✅ 용어 정확성: 기술 용어 정확함
```

```
   - "원란된" → 의미 불명확
```
