## 1. 핵심 결론

Phase 2의 질의응답 평가는 단순히 "답변을 생성했는가"가 아니라, **검색 근거가 질문 주제와 실제로 관련 있는가**를 먼저 판정해야 한다.

특히 Snowflake 질문처럼 현재 문서 저장소에 해당 주제 근거가 없을 가능성이 높은 경우, 시스템이 무관한 RAG 조각을 억지로 붙여 정상 답변처럼 보이게 하면 평가 신뢰도가 무너진다.

따라서 최종 설계는 다음 2단계 원칙을 따른다.

1. 먼저 문서 근거의 관련성을 판정한다.
2. 이후 사용자가 선택한 모드와 옵션에 따라 "관련 없음", "부분 설명", "일반/전문가 설명"을 분리해서 제공한다.

## 2. 반영된 PM 의견

PM 의견의 핵심은 다음과 같다.

| 구분 | 설계 반영 |
|---|---|
| 모드 기반 제어 | 라디오 버튼으로 3개 기본 정책 제공 |
| 세부 옵션 제어 | 체크박스로 독립 옵션 제공 |
| 안전한 기본값 | 전문가모드에만 일반 설명 기본 허용 |
| 평가 투명성 | 관련 없음과 설명 가능 영역을 명확히 분리 |
| 작업 분담 | Codex, Antigravity, Claude Code 역할 분리 |

이 설계는 "문서만 보고 답하라"는 평가 상황과 "전문가 관점으로 보완 설명하라"는 서비스 상황을 한 화면에서 선택 가능하게 만든다.

## 3. 최종 UX 정책

### 3.1 모드 기반 선택

사용자는 라디오 버튼으로 기본 응답 정책을 선택한다.

| 모드 | 목적 | 기본 정책 |
|---|---|---|
| 문서만 (엄격) | 평가/검증용 | 문서 근거 없으면 관련 없음 |
| 한계 포함 (부분) | 운영/진단용 | 문서에 있는 부분만 답하고 없는 부분 명시 |
| 전문가 (유연) | 설명/컨설팅용 | 문서 근거와 일반 설명을 분리해 제공 |

### 3.2 체크박스 옵션

모드와 별도로 다음 옵션을 제공한다.

| 옵션 | 권장 기본값 | 의미 |
|---|---:|---|
| 무관한 검색 결과 숨기기 | ON | 질문 주제와 맞지 않는 RAG/온톨로지 근거를 화면에서 제외 |
| 부분 답변 허용 | 모드별 | 문서에 일부만 있으면 그 범위 안에서만 답변 |
| 출처 분리 | ON | 문서 근거와 일반 설명을 UI/문장 구조에서 분리 |
| 일반 설명 허용 | 전문가만 ON | 문서에 없더라도 일반 지식 또는 전문가 관점 설명 허용 |

---

## 4. 모드별 기본값

| 모드 | 무관 결과 숨기기 | 부분 답변 허용 | 출처 분리 | 일반 설명 허용 |
|---|---:|---:|---:|---:|
| 문서만 (엄격) | ON | OFF | ON | OFF |
| 한계 포함 (부분) | ON | ON | ON | OFF |
| 전문가 (유연) | ON | ON | ON | ON |

이 기본값은 평가 안정성을 우선한다. 사용자가 의도적으로 체크박스를 바꾸면 기본 정책을 세밀하게 조정할 수 있다.

## 5. 응답 판정 정책

### 5.1 문서에 전혀 없는 질문

예: Snowflake 질문인데 검색 근거에 Snowflake 관련 내용이 없음.

| 모드 | 기대 응답 |
|---|---|
| 문서만 | "현재 업로드/검색된 문서에서 Snowflake 관련 근거를 찾지 못했습니다." |
| 한계 포함 | "문서 근거상 Snowflake 관련 내용은 확인되지 않습니다. 따라서 문서 기반 답변은 제한됩니다." |
| 전문가 | "문서 근거는 없습니다. 다만 일반적인 엔터프라이즈 RAG 관점에서는..." |

### 5.2 문서에 일부만 있는 질문

예: 질문은 "응답 시간과 운영 제약"을 묻지만 문서에는 응답 시간만 있음.

| 모드 | 기대 응답 |
|---|---|
| 문서만 | 응답 시간 근거만 답변, 운영 제약은 근거 없음 명시 |
| 한계 포함 | 응답 시간은 설명하고 운영 제약은 문서 부재로 제한 |
| 전문가 | 문서 근거와 일반 운영 관점 설명을 분리 |

### 5.3 문서에 충분히 있는 질문

기존 RAG 답변처럼 문서명, 페이지, 점수, 핵심 근거를 함께 제시한다.

## 6. 구현 계획

### 6.1 Codex 작업: 백엔드 정책 분기

대상 파일:

`E:\ontology_edu\X_ont_std\ont_platform\v5\backend\app\api\adaptive_query.py`

작업 내용:

1. SSE 엔드포인트에 옵션 파라미터 추가
   - `hide_irrelevant: bool`
   - `allow_partial: bool`
   - `separate_sources: bool`
   - `allow_general: bool`

2. 옵션 미전달 시 모드별 기본값 적용
   - `document_only`
   - `document_with_limits`
   - `expert_mode`

3. 검색 결과 관련성 게이트 추가
   - 질문 핵심 토픽 추출
   - RAG snippet/title/page metadata 검사
   - Ontology entity/relation 검사
   - 토픽 불일치 시 근거 제외

4. Snowflake 등 특정 도메인 질문의 무관 근거 차단
   - 질문에 `snowflake`, `스노우플레이크`, `warehouse`, `cortex` 등이 포함되면 관련 근거에도 최소 1개 이상 포함되어야 함
   - 없으면 RAG/ontology 결과를 숨기고 "관련 근거 없음" 판정

5. 신뢰도/레벨 산정 보정
   - 관련 근거 없음: 신뢰도 낮음, 예: 30~45%
   - 부분 근거: 중간, 예: 50~70%
   - 충분 근거: 기존 90%대 가능

6. 응답 문구 분리
   - 문서 근거 판단
   - 문서 기반 답변
   - 일반/전문가 설명

검증 기준:

- Snowflake 질문에서 무관한 온톨로지/NLP 문서가 RAG 5개로 표시되지 않아야 한다.
- 문서만 모드에서는 관련 근거가 없으면 답변이 "관련 없음"으로 종료되어야 한다.
- 전문가 모드에서는 일반 설명이 가능하되, 문서 근거가 없다는 사실을 먼저 밝혀야 한다.

### 6.2 Antigravity 작업: UI 옵션 구현

대상 영역:

`frontend` 질의 UI 컴포넌트

작업 내용:

1. 기존 select 또는 mode UI를 라디오 기반 3개 모드로 정리
   - 문서만 (엄격)
   - 한계 포함 (부분)
   - 전문가 (유연)

2. 체크박스 4개 추가
   - 무관한 검색 결과 숨기기
   - 부분 답변 허용
   - 출처 분리
   - 일반 설명 허용

3. 모드 변경 시 기본 체크 상태 자동 반영

4. 사용자가 체크박스를 수동 변경하면 해당 값을 SSE query parameter로 전달

검증 기준:

- 모드 변경 시 체크박스 기본값이 예상대로 바뀌어야 한다.
- 사용자가 체크박스를 직접 바꾸면 API 요청에 반영되어야 한다.
- 기존 RAG/Ontology/Expert 탭 렌더링이 깨지지 않아야 한다.

### 6.3 Claude Code 작업: 평가 실행

작업 내용:

1. 24문항 평가를 모드별로 실행
   - 문서만
   - 한계 포함
   - 전문가

2. 결과를 비교
   - 관련 없음 정확도
   - 부분 답변 정확도
   - 일반 설명 분리 여부
   - 무관 출처 노출 여부

3. 최종 평가 보고서 작성

검증 기준:

- Snowflake처럼 문서 근거가 없는 질문은 문서만 모드에서 0점 또는 관련 없음으로 판정되어야 한다.
- 전문가 모드는 문서 근거 없음과 일반 설명을 분리하면 부분 점수를 받을 수 있다.
- 무관 출처가 표시되면 실패로 기록한다.

## 7. 기대 점수 변화

같은 질문이라도 모드에 따라 정답 기준이 달라진다.

예시 질문:

`Snowflake 기반 QA 테스트에서 응답 시간과 운영 제약을 함께 봐야 하는 이유는 무엇인가?`

현재 문제:

- 검색 근거에는 Snowflake 내용이 없음
- 하지만 무관한 온톨로지/NLP 문서를 근거로 정상 답변처럼 출력됨
- 신뢰도 92%가 표시되어 평가자에게 잘못된 확신을 줌

개선 후 기대:

| 모드 | 기대 판정 | 예상 점수 의미 |
|---|---|---|
| 문서만 | 관련 없음 | 0점이지만 정직한 실패 |
| 한계 포함 | 문서 근거 없음 + 범위 제한 | 30점 수준 |
| 전문가 | 문서 근거 없음 + 일반 설명 분리 | 60점 수준 |

핵심은 모든 모드에서 무관한 출처를 정답 근거처럼 보여주지 않는 것이다.
