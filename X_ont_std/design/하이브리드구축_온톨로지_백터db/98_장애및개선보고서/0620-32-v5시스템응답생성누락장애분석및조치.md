**문제 2: 출처만 나열하고 답변 없음**

```python
def synthesize_answer(rag_results):
    """
    RAG 결과가 있을 때 답변 합성
    문제: 실제 설명을 생성하지 않고 출처만 나열
    """
    answer = "주요 근거는 "
    for chunk in rag_results:
        answer += f"{chunk['source']} p.{chunk['page_number']}, "
    answer += "입니다."
    
    # 실제 질문에 대한 설명은 없음!
    return answer
```


## 부록: 코드 변경 비교

### Before (문제)
```python
class AdaptiveQueryAPI:
    def _build_no_evidence_answer(self, mode):
        # ❌ 질문과 무관한 고정 문장
        return "응답 시간은 사용자 경험과 SLA를..."
    
    async def answer_query(self, query, mode):
        rag_results = self.search(query)
        
        if not rag_results:
            # ❌ 근거 없어도 일반 설명 강제
            return self._build_no_evidence_answer(mode)
        
        # ❌ 근거 파일명만 나열
        answer = "주요 근거는 "
        for r in rag_results:
            answer += f"{r['file']} p.{r['page']}, "
        return answer
```

### After (수정)
```python
async def generate_stream(...):
    if not has_rag_evidence:
        # ✅ 명확한 근거 없음 표현

    else:
        # ✅ RAG 청크에서 핵심 문장 추출

    # ✅ 출처는 별도 events 이벤트로 전송 (RAG 탭용)
```
