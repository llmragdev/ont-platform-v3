## ⚡ 1주일 스프린트 계획

### Day 1-2 (화, 수)
**병렬 작업 구성**:

#### Claude (백엔드)
```
□ CSV 데이터 로더 스킬
  └─ 파일 파싱 → 테이블 객체 변환
  
□ 기본 데이터 변환 스킬들
  ├─ 필터링 (WHERE)
  ├─ 그룹화 (GROUP BY)
  └─ 정렬 (ORDER BY)
  
□ 통계 분석 스킬
  ├─ COUNT, SUM, AVG, MIN, MAX
  └─ 기본 통계량 (표준편차, 중앙값)

예상: 2일 (이미 많은 기반이 있음)
```

#### Codex (프론트엔드)
```
□ 데이터 업로드 UI
  └─ 드래그&드롭 파일 선택
  
□ 데이터 테이블 뷰
  └─ 페이지네이션, 정렬, 필터
  
□ 간단한 차트
  ├─ 막대 그래프
  ├─ 선 그래프
  └─ 원형 그래프

예상: 2일 (React 컴포넌트 조합)
```

#### Antigravity (성능)
```
□ 데이터 로딩 최적화
  └─ 청크 로딩, 가상 스크롤
  
□ 캐싱 전략
  └─ 쿼리 결과 메모리 캐시
  
□ 초기 설정
  └─ 벤치마크, 모니터링

예상: 2일 (병목 분석 및 최적화)
```
