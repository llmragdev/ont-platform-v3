## 🎯 핵심 기능

### 1️⃣ **자연어 → 코드 변환**
```
사용자: "지난 3개월 매출이 100만 이상인 고객들의 이름과 매출을 보여줘"
       ↓
AI 분석:
  - 온톨로지 스키마 이해 (Customer, Sales 엔티티)
  - 시간 조건 (3개월), 금액 조건 (100만)
  - 출력 형식 (고객명, 매출)
       ↓
자동 생성:
  - SQL: SELECT customer_name, SUM(sales) FROM sales WHERE date >= CURRENT_DATE - 90 DAYS AND sales >= 1000000 GROUP BY customer_name
  - 또는 Python: pandas DataFrame으로 필터링 후 시각화
  - 또는 SPARQL: ontology 쿼리로 온톨로지 검색
       ↓
자동 실행 & 결과 반환
```

### 2️⃣ **데이터 분석 자동화**
```
사용자: "고객 세그먼트 분석 해줘"
       ↓
AI 에이전트:
  - 데이터 탐색 (어떤 컬럼이 있는가)
  - 군집화 추천 (K-Means 추천)
  - 모델 학습 & 실행
  - 결과 시각화
  - 인사이트 생성 (이 3개 세그먼트는...)
       ↓
대시보드 + 분석 리포트 자동 생성
```

### 3️⃣ **워크플로우 자동 생성**
```
사용자: "매일 밤 11시에 매출 데이터를 새로 고치고 분석 보고서를 이메일로 보내줘"
       ↓
AI 에이전트:
  - 워크플로우 자동 설계
    ├─ Step 1: 데이터 새로고침
    ├─ Step 2: 분석 실행
    └─ Step 3: 이메일 발송
  - 스케줄 자동 설정 (cron: 0 23 * * *)
  - 감시 규칙 생성
       ↓
워크플로우 저장 & 실행
```

## 🔄 6개 핵심 에이전트

### 1. **Intent Detector** (의도 파악)
```
입력: "지난 3개월 매출이 100만 이상인 고객들 보여줘"

분석:
  - Intent: SELECT (데이터 조회)
  - Entity: Customer, Sales
  - Filter: date >= 3개월, sales >= 100만
  - Output: 고객명, 매출

출력: IntentSchema {
  type: "SELECT",
  entities: ["Customer", "Sales"],
  filters: [...],
  output_fields: [...],
  confidence: 0.95
}
```

### 2. **Schema Analyzer** (스키마 이해)
```
온톨로지 스키마 확인:

Customer 엔티티:
  - customer_id (ID)
  - customer_name (string)
  - segment (enum: VIP, Premium, Standard)
  - join_date (date)

Sales 엔티티:
  - sale_id (ID)
  - customer_id (FK)
  - amount (number)
  - sale_date (date)

관계:
  - Customer --hasMany--> Sales

출력: SchemaMap {
  entities: [...],
  relationships: [...],
  indexes: [...],
  computed_fields: [...]
}
```

### 3. **Code Generator** (코드 생성)
```
생성 옵션:

A. SQL (가장 빠름):
SELECT customer_name, SUM(amount) as total_sales
FROM customers c
JOIN sales s ON c.customer_id = s.customer_id
WHERE s.sale_date >= CURRENT_DATE - 90
  AND s.amount >= 1000000
GROUP BY customer_name
ORDER BY total_sales DESC;

B. SPARQL (온톨로지):
SELECT ?customer ?name ?totalSales
WHERE {
  ?sale ont:hasCustomer ?customer ;
         ont:amount ?amount ;
         ont:date ?date .
  ?customer ont:name ?name .
  FILTER (?date >= NOW() - P3M && ?amount >= 1000000)
}
GROUP BY ?customer ?name
AGGREGATE(SUM(?amount) as ?totalSales)

C. Python (유연함):
import pandas as pd
df = load_data('sales')
df = df[df['sale_date'] >= (today - timedelta(days=90))]
df = df[df['amount'] >= 1000000]
result = df.groupby('customer_name')['amount'].sum()
```

### 4. **Validator** (검증)
```
생성된 코드 검증:

□ 문법 검사 (SQL/Python syntax)
□ 스키마 일치성 (컬럼이 실제로 있는가)
□ 성능 분석 (쿼리가 효율적인가)
□ 보안 검사 (SQL injection 방지)
□ 논리 검증 (의도와 일치하는가)

결과:
  - Valid: ✅
  - Performance Score: 4.5/5
  - Security: ✅
  - Estimated Time: 250ms
```

### 5. **Executor** (실행)
```
생성된 코드 실행:

1. 샌드박스 환경에서 실행
2. 권한 검증 (사용자가 이 데이터에 접근할 수 있는가)
3. 타임아웃 설정 (30초)
4. 리소스 모니터링
5. 결과 캐싱

실행 결과:
  - Rows: 42
  - Execution Time: 245ms
  - Memory Used: 12MB
  - Status: SUCCESS
```

### 6. **Explainer** (설명)
```
결과 분석 & 설명:

- 요약: "42명의 고객이 지난 3개월 동안 100만 이상 매출 발생"
- Top 3: 
  1. 삼성 (5,000만)
  2. LG (4,500만)
  3. SK (3,200만)
- 인사이트:
  - 상위 3개 고객이 전체의 35% 차지
  - 매월 증가 추세 (+15%)
  - 신규 고객 중 60%가 이미 100만 달성

다음 제안:
  - "이 고객들의 구매 패턴 분석해볼까요?"
  - "다음 달 매출 예측해볼까요?"
  - "고객 세그먼트별 분석해볼까요?"
```

## 💾 구현 범위

### Phase 1 (2-3주): MVP
```
✅ Intent Detection (단순)
✅ Schema Analysis (온톨로지 기반)
✅ SQL/SPARQL Generator (기본)
✅ Validator (기본 검사)
✅ Executor (샌드박스 실행)
✅ Simple Explainer

= "조회" 기능만 지원 (SELECT)
```

### Phase 2 (3-4주): 확장
```
+ 복잡한 Intent Detection
+ Python Code Generator
+ 자동 시각화 생성
+ 고급 Explainer (인사이트)
+ 대화형 개선 ("이걸 더 자세히 보여줘")

= "조회 + 분석" 지원 (SELECT + ANALYZE)
```

### Phase 3 (2-3주): 자동화
```
+ Workflow Auto-Generator
+ Schedule 자동 설정
+ API 호출 자동화
+ 이메일/알림 자동화
+ 모니터링 규칙 자동 생성

= "조회 + 분석 + 자동화" (SELECT + ANALYZE + AUTOMATE)

### Phase 4 (3-4주): ML/고급
```
+ ML 모델 추천
