## 관리 원칙

- 현재 구현 판단은 `status_reports/MASTER_ROADMAP.md`에서 관리한다.
- 상세 설계는 `design` 하위에 둔다.
- 검증 결과는 `validation` 하위에 둔다.
- 완료/참조 문서는 `archive`로 이동한다.
- 고객명이나 특정 사례명은 메인 문서 제목에서 사용하지 않고, 필요한 경우 참조 문서 안에서만 출처로 남긴다.
