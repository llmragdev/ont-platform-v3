## 핵심 개념

### 2단계 평가의 목표

- **Step 1 (핵심, 70점)**: "기본적으로 맞는가?"
  - STD-S 질문: "관련 없음"을 명시했는가?
  - 일반 질문: 정답이 맞는가?

- **Step 2 (부가, 30점)**: "추가 설명이 정확하고 신뢰할 수 있는가?"
  - STD-S 질문: "관련 없음" 외에 어떻게 설명했는가?
  - 일반 질문: 정답을 얼마나 명확하게 제시했는가?

### 기본 원칙

```
최종 점수 = Step 1 점수 + Step 2 점수 (최대 100점)
```

---

## Step 1: 핵심 정확도 (70점)

### STD-S 질문 (STD-S-01, STD-S-02, ...)

**핵심 질문**: "관련 없음" 또는 "명시되지 않음"을 명시했는가?

| 답변 포함 내용 | 점수 | 설명 |
|---|---|---|
| "관련 없음" **또는** "명시되지 않음" 명시 | **70점** | ✅ 정확 |
| 명시하지 않음 | **30점** | ❌ 누락 |

**구체적인 표현 예시** (70점 인정):
- "논문에 명시되지 않았습니다"
- "관련 내용이 없습니다"
- "이 주제에 대해 다루어지지 않았습니다"
- "확인할 수 없습니다"

**표현 예시** (30점 - 명시 누락):
- 바로 일반 설명만 함: "A/B 테스팅은..." (관련 없음 언급 없음)
- "제가 알기로는..." (기존 지식으로만 답변)

---

### 일반 질문 (STD-O-01, STD-A-01, ...)

**핵심 질문**: 정답이 맞는가?

| 답변 | 점수 | 설명 |
|---|---|---|
| 정답 | **70점** | ✅ 맞음 |
| 오답 | **30점** | ❌ 틀림 |

---

## Step 2: 부가 설명 (30점)

### STD-S 질문에서 부가 설명 평가

Step 1에서 "관련 없음"을 명시한 경우에만 적용합니다.

#### 부가 점수 배분표

| 설명 수준 | 점수 | 조건 | 예시 |
|---|---|---|---|
| 정확한 설명 + 출처명시 | **30점** | "관련 없음" + 일반 원칙 설명 + [출처: 논문명] | "관련 없음. 일반적으로 A/B 테스팅은... [출처: 실험설계이론]" |
| 일반원칙 설명 + 출처미명시 | **25점** | "관련 없음" + 일반 설명 하지만 출처 없음 | "관련 없음. 일반적으로 A/B 테스팅은..." |
| 부정확한 설명 포함 | **20점** | "관련 없음" 했지만 추가 설명에 오류 있음 | "관련 없음. 하지만 [틀린 내용]" |
| 미언급 | **10점** | "관련 없음"만 했고 추가 설명 없음 | "관련 없음." (마침표) |
| 부가 설명 없음 | **0점** | "관련 없음" 명시 자체가 없음 | - |

**주의**: Step 1에서 이미 30점을 받은 경우 (관련 없음 미명시), Step 2에서 추가 점수 없음 (총 30점)

---

### 일반 질문에서 부가 설명 평가

일반 질문은 부가 설명을 길게 평가하지 않습니다. (간단함)

| 답변 | 점수 |
|---|---|
| 정답 (어떻게 설명하든) | **30점** |
| 오답 | **0점** |

## 최종 점수 계산

### 공식

```
최종 점수 = Step 1 점수 + Step 2 점수

Step 1: 70 점 또는 30 점
Step 2: 30 점, 25 점, 20 점, 10 점, 또는 0 점

결과: 최대 100 점 (70 + 30)
```

### 가능한 점수

| Step 1 | Step 2 | 최종 |
|---|---|---|
| 70 | 30 | **100** ✅ |
| 70 | 25 | **95** ✅ |
| 70 | 20 | **90** ✅ |
| 70 | 10 | **80** ✅ |
| 70 | 0 | **70** ✅ |
| 30 | 0 | **30** ❌ |

## 실제 예시

### 예시 1: STD-S-04 (Snowflake 반복 개선)

**기준 답변**: "관련 논문에 명시되지 않음. 일반적인 A/B 테스팅 원칙 적용."

#### 응답 A: "관련 없음 + 정확한 설명 + 출처명시"

```
"논문에는 Snowflake 기반 RAG 반복 개선이 명시되지 않습니다.
 일반적으로 A/B 테스팅은 두 버전을 비교하여...
 [출처: 실험설계이론]"
```

**Step 1**: 70점 (관련 없음 명시 O)
**Step 2**: 30점 (정확한 설명 + 출처명시)
**최종**: 100점 🟢

---

#### 응답 B: "관련 없음 + 일반 설명 (출처 없음)"

```
"논문에 명시되지 않았습니다.
 일반적으로 A/B 테스팅은..."
```

**Step 1**: 70점 (관련 없음 명시 O)
**Step 2**: 25점 (일반 원칙 설명하지만 출처 없음)
**최종**: 95점 🟡

---

#### 응답 C: "관련 없음만 (추가 설명 없음)"

```
"관련 논문에 명시되지 않았습니다."
```

**Step 1**: 70점 (관련 없음 명시 O)
**Step 2**: 10점 (추가 설명 없음)
**최종**: 80점 🟡

---

#### 응답 D: "관련 없음 미언급 (일반 설명만)"

```
"A/B 테스팅은 두 버전을 비교하여..."
(관련 없음 언급 없음)
```

**Step 1**: 30점 (관련 없음 미언급)
**Step 2**: 0점 (Step 1 실패)
**최종**: 30점 🔴

---

### 예시 2: STD-O-01 (일반 온톨로지 질문)

**기준 답변**: "온톨로지는 지식을 구조화된 형태로 표현..."

#### 응답 A: 정답

"온톨로지는 개념, 관계, 속성을 체계적으로..."

**최종**: 100점 🟢

#### 응답 B: 오답

```
"온톨로지는..."
(잘못된 내용)
```

**Step 1**: 30점 (오답)
**Step 2**: 0점 (Step 1 실패)
**최종**: 30점 🔴

## 실수하기 쉬운 부분

### ❌ 자주 하는 실수

#### 1. "관련 없음" 표현 다양성 인정 안 함

```
❌ 틀림: "논문에 나와있지 않아" → 30점으로 판정
✅ 맞음: "논문에 명시되지 않았습니다" → 70점
```

**해결**: 다음 표현들은 모두 "관련 없음"으로 인정
- "명시되지 않음"
- "확인할 수 없음"
- "다루어지지 않음"
- "기술되지 않음"

---

#### 2. 출처명시 기준 엄격하게

```
❌ 너무 엄격: 정확한 논문명 아니면 인정 안 함
✅ 맞음: [출처: 실험설계이론], [논문참고], [일반원리] 모두 인정
```

**해결**: 중괄호 [ ] 또는 "출처:" 표현 있으면 OK

---

#### 3. "관련 없음" + "부정확한 설명" 점수 처리

```
❌ 틀림: 
  Step 1: 70점
  Step 2: 0점 (부정확이라고 완전 탈락)
  최종: 70점

✅ 맞음:
  Step 1: 70점
  Step 2: 20점 (부정확하지만 일부 인정)
  최종: 90점
```

**해결**: "부정확"은 탈락 아니라 20점 부여

---

#### 4. 일반 질문에서 부가 설명 과평가

```
❌ 틀림:
  정답이지만 설명 부실 → 70점 + 10점 = 80점?
  
✅ 맞음:
  정답이면 → 70점 + 30점 = 100점
  (설명 길이는 평가 대상 아님)
```

**해결**: 일반 질문은 "정답/오답"만 판정. 설명은 부가 점수에 영향 X

---

### ✅ 체크리스트

평가할 때마다 확인하세요:

#### STD-S 질문용

- [ ] "관련 없음" 또는 유사 표현 있는가?
  - 있음 → 70점
  - 없음 → 30점

- [ ] Step 1 = 70점인 경우, 부가 설명 수준?
  - 정확 + 출처명시 → 30점
  - 일반원칙 + 출처미명시 → 25점
  - 부정확 포함 → 20점
  - 설명 없음 → 10점

#### 일반 질문용

- [ ] 정답인가?
  - 정답 → 70점 + 30점 = 100점
  - 오답 → 30점 + 0점 = 30점

## 빠른 참조표

### STD-S 질문 점수 결정 플로우

```
질문을 읽는다
    ↓
"관련 없음" 명시되어 있는가?
    ├─ Yes → Step 1 = 70점
    │         부가 설명 수준은?
    │         ├─ 정확+출처명시 → Step 2 = 30점 → 최종 100점 🟢
    │         ├─ 일반원칙+출처미명시 → Step 2 = 25점 → 최종 95점 🟡
    │         ├─ 부정확포함 → Step 2 = 20점 → 최종 90점 🟡
    │         └─ 설명없음 → Step 2 = 10점 → 최종 80점 🟡
    │
    └─ No → Step 1 = 30점, Step 2 = 0점 → 최종 30점 🔴
```

### 일반 질문 점수 결정 플로우

```
질문을 읽는다
    ↓
답변이 정답인가?
    ├─ Yes → 100점 🟢
    └─ No → 30점 🔴
```
