# Snowflake 관련 STD-S 답변 평가 기준

**적용 대상**: STD-S-04, STD-S-05, STD-S-06, STD-S-07, STD-S-08  
**기준**: 4팀_정확도_비교_STD-S정답수정_추가평가.xlsx 의 수정된 답변

---

## 핵심 기준

### ⚠️ 주의사항

현재 확보된 논문에는 **Snowflake 기반 RAG 시스템의 반복적 개선 프로세스가 명시되지 않았으나**,  
A/B 테스팅과 실험 설계의 일반 원칙에 기반해 설명합니다.

---

## 평가 방식

### 1️⃣ "관련 없음"만 답변한 경우

```
예: "논문에 명시되지 않았습니다."
```

**점수**: 100점 ✅

---

### 2️⃣ "관련 없음" + 일반 원칙 설명 (맥락/내용 정확)

```
예: "논문에는 명시되지 않았습니다. 

    일반적으로 A/B 테스팅은 두 버전을 비교하여...
    실험 설계 원칙에 따라..."
```

**조건**:
- "관련 없음/명시안됨" 명시 ✓
- 설명 내용이 맥락상 정확 ✓
- 틀린 얘기 없음 ✓

**점수**: 100점 ✅ (유지)

---

### 3️⃣ "관련 없음" + 다른 얘기 (오류/부정확)

```
예: "논문에는 명시되지 않았습니다.

    하지만 [틀린 내용]..."
```

**점수**: 감점 (80-90점)

---

### 4️⃣ "관련 없음" 언급 없음

```
예: "A/B 테스팅은... [관련 없음 언급 X]"
```

**점수**: 큰 감점 (30-50점)

---

## 요약

| 답변 형태 | 점수 | 조건 |
|---|---|---|
| "관련 없음"만 | 100점 | - |
| "관련 없음" + 정확한 설명 | 100점 | 맥락/내용 정확, 출처/원칙 명시 |
| "관련 없음" + 부정확한 설명 | 80-90점 | 기본은 맞지만 설명에 오류 |
| "관련 없음" 미언급 | 30-50점 | 큰 감점 |
