# 12. 파일럿 상업화 가격 전략

> 기준일: 2026-05-14  
> 대상: ont_platform v3.0 현재 상태  
> 시나리오: ① 강의 오픈 / ② 파일럿 솔루션 판매 + 기술이전

---

## 현재 시스템 자산 평가

| 구성요소 | 완성도 | 상업적 가치 |
|---|---|---|
| FastAPI 백엔드 (온톨로지 + RAG + 하이브리드 파이프라인) | 80% | 핵심 IP |
| Next.js 프론트엔드 (13개 뷰, 완성형 UI) | 85% | 즉시 데모 가능 |
| Gemini LLM 연동 (분류 + 합성) | 75% | 교체 가능 구조 |
| 멀티테넌트 아키텍처 | 70% | 확장성 증명 |
| 도메인 온톨로지 + 데이터셋 (AI바우처) | 60% | 방법론 증명 |
| 자동화 통합 테스트 시스템 | 60% | QA 방법론 포함 |
| 요구사항 문서 일체 (req_doc_hub) | 90% | 기술이전 패키지 가치 ↑ |

**현재 한계 (파일럿 판매 시 고지 필요):**
- 통합 테스트 통과율 개선 중 (0% → 목표 80%+)
- 운영 환경 배포/보안 하드닝 미완
- 단일 도메인 특화 (AI바우처) → 도입 시 커스터마이징 필요

## 시나리오 1: 강의 오픈 (교육 콘텐츠)

### 커버 기술 스택 (국내 희소 조합)
- 온톨로지 모델링 + 지식그래프 설계
- RAG / 벡터 서치 아키텍처
- LLM 연동 (의도 분류 + 합성 파이프라인)
- FastAPI + Next.js 풀스택
- 멀티테넌트 엔터프라이즈 설계

### 형태별 가격

| 강의 형태 | 예상 가격 | 비고 |
|---|---|---|
| 온라인 강의 (개인) | ₩300K ~ ₩600K/인 | 패스트캠퍼스 AI 강의 기준 |
| 기업 출강 워크숍 (1일) | ₩5M ~ ₩10M/회 | 실습 포함 |
| 커리큘럼 패키지 (학원/기관 납품) | ₩20M ~ ₩50M | 소스코드 + 강의자료 일체 |
| 대학원/연구소 산학 강의 | ₩15M ~ ₩30M/학기 | 실습 플랫폼 포함 |

### 연간 수익 시뮬레이션

| 채널 | 규모 | 예상 수익 |
|---|---|---|
| 온라인 수강생 200명 × ₩400K | — | ₩80M/년 |
| 기업 출강 월 2회 × ₩7M × 12 | — | ₩168M/년 |

## 시나리오 2: 파일럿 솔루션 판매 + 기술이전

### 원가접근법 (개발비 산정)

```
시니어 개발자 2명 × 5개월
  = ₩12M/월 × 2명 × 5개월 = ₩120M
기획/설계/문서 1인 × 3개월 = ₩30M
                          소계: ₩150M

방법론·IP 프리미엄 40%        = ₩60M
────────────────────────────────────
원가 기반 적정가: ₩180M ~ ₩250M
```

### 시장접근법 (유사 제품 비교)

| 유사 제품 | 시장가 |
|---|---|
| 국내 지식관리 시스템 (KMS) SaaS | ₩3M ~ ₩10M/월 |
| 공공기관 AI 분석 플랫폼 | ₩50M ~ ₩300M/프로젝트 |
| AI 바우처 공급기업 솔루션 평균 | ₩50M ~ ₩130M (최대 지원액) |
| 엔터프라이즈 온톨로지 툴 (Stardog 등) | $50K ~ $200K/년 |

### 타겟별 제안가

| 타겟 | 파일럿 판매가 | 기술이전 추가금 |
|---|---|---|
| 스타트업 / AI 전문기업 | ₩30M ~ ₩60M | +₩10M ~ ₩20M (소스코드 라이선스) |
| 중견기업 (사내 도입) | ₩80M ~ ₩150M | +₩30M ~ ₩50M |
| 공공기관 / 정부 조달 | ₩100M ~ ₩300M | 별도 유지보수 계약 |
| AI 바우처 공급기업 등록 후 수요기업 판매 | ₩50M ~ ₩130M | 수요기업이 국비로 구매 가능 |

### 기술이전 패키지 구성 제안

```
기본 라이선스 (소스코드 + 문서)        ₩50M
├── 소스코드 전체 (백엔드 + 프론트엔드)
├── 아키텍처 / 요구사항 문서 일체
└── 온톨로지 설계 방법론

구축 지원 (도메인 커스터마이징)         ₩30M ~ ₩80M
├── 도입 도메인 온톨로지 설계 (3개월)
├── 배포 환경 세팅 (클라우드 / 온프레미스)
└── 담당자 교육 (2일)

연간 유지보수                          ₩15M ~ ₩30M/년
```

**총 첫 계약 예상가: ₩80M ~ ₩180M**

## 권고 전략 로드맵

```
1단계 (즉시): AI 바우처 공급기업 등록
  → 수요기업이 최대 ₩130M 국비로 구매 가능
  → 공급기업 투자 없이 첫 레퍼런스 확보

2단계 (레퍼런스 확보 후): 직접 판매
  → ₩80M ~ ₩150M 구간 목표
  → 기술이전 계약 병행

3단계 (병행): 강의 채널 개설
  → 기업 교육으로 연 ₩100M ~ ₩200M 추가
  → 고객 파이프라인 역할도 겸함
```
