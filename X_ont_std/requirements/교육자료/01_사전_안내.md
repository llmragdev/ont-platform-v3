# 01. 사전 안내 — 환경 셋업

> 실습 시작 30분 전까지 이 문서대로 환경을 준비하세요.

## 1. 필수 도구

| 도구 | 버전 | 확인 명령 |
| --- | --- | --- |
| conda (Anaconda/Miniconda) | 22+ | `conda --version` |
| Git | 2.30+ | `git --version` |
| 텍스트 에디터 | VS Code 권장 | — |
| 브라우저 | Chromium 계열 권장 | — |

> **conda가 없다면**: Miniconda 설치 ([docs.anaconda.com/miniconda](https://docs.anaconda.com/miniconda/)).

`PROGRESS.md`, `README.md`, `CHANGELOG.md`, `NEXT_STEPS.md`, `backend/`, `frontend/`가 보이면 OK.

## 3. 백엔드 환경 (conda `claud_be`)

```powershell
cd e:\ontology_edu\claud_통합\backend
conda env create -f environment.yml          # 약 3~5분
conda activate claud_be
```

## 4. Gemini API 키 연결 (필수)

**옵션 A — 강사 공유 .env**:
```powershell
$env:DOTENV_PATH = "F:\ai_std_dev\.env"      # 강사 안내 경로
```

**옵션 B — 직접 발급**:
1. [ai.google.dev](https://ai.google.dev/) 접속 → "Get API Key" → 키 발급
2. `backend/.env` 파일 만들고 다음 한 줄:
   ```
   GEMINI_API_KEY=AIza...your-key
   ```

> **키 없이도 진행 가능합니다**. 키가 없으면 룰베이스 폴백 답변이 자동으로 사용되며, `/api/health.llm.provider`가 `rule-based`로 표시됩니다.

## 5. 백엔드 동작 확인

```powershell
$env:PYTHONIOENCODING="utf-8"
pytest                                       # 17 passed in ~2s
python -m eval.scenarios --json              # 5/5 PASS
python evaluate.py --json                    # 10/10 PASS, mean p@3=1.0
```

서버 띄워보기:
```powershell
python -m uvicorn app.main:app --reload --port 8000
```
다른 터미널에서:
```powershell
# PowerShell 네이티브 (권장)
Invoke-RestMethod http://localhost:8000/api/health
# 또는 진짜 curl
curl.exe http://localhost:8000/api/health
# → status:ok, llm_provider:gemini 또는 rule-based
```

> ⚠ PowerShell의 `curl`은 `Invoke-WebRequest` 별칭이라 `-X`, `-d` 같은 진짜 curl 플래그를 못 받습니다.
> Bash/WSL/macOS에서는 그대로 `curl ...`을 쓰세요.

## 6. 프론트엔드 환경 (conda `claud_fe`)

```powershell
cd e:\ontology_edu\claud_통합\frontend
conda env create -f environment.yml          # nodejs 20 설치, 약 1~2분
conda activate claud_fe

copy .env.local.example .env.local

npm install --ignore-scripts                 # ~30초, 386 packages
npm run build                                # ~10초
npm run dev                                  # http://localhost:3000
```

브라우저에서 `http://localhost:3000` 접속 → 대시보드 표시되면 OK.

## 7. 흔히 막히는 지점

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| `pytest`에서 `ImportError` | `backend/` 밖에서 실행 | `cd backend` 먼저 |
| `npm install` 첫 시도가 unrs-resolver 오류 | postinstall에 node PATH 누락 | `--ignore-scripts` 플래그 사용 |
| `npm run build`에서 `'node'`를 찾을 수 없음 | conda env의 node가 PATH에 없음 | `conda activate claud_fe` 다시 확인 |
| `/api/health.llm.provider`가 `rule-based`인데 키는 있음 | dotenv가 키를 못 읽음 | `$env:DOTENV_PATH` 경로 재확인, 파일이 UTF-8인지 확인 |
| Playwright 첫 실행 실패 | Chromium 바이너리 없음 | `npx playwright install chromium` 1회 실행 |
| 한글 폴더(`claud_통합`)에서 npm 캐시 오류 | 일부 도구가 비ASCII 경로 문제 | 임시로 `claud_unified`로 리네임 |
