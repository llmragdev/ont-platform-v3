# 온톨로지 AI 업무 콘솔 — 교육 커리큘럼 오버뷰

> 본 교육은 `claud_통합/` 통합 샘플을 가지고 4시간 안에 "온톨로지 + RAG + 워크플로우 + 거버넌스"의 전체 흐름을 체험하는 것이 목표입니다.

## 1. 학습 목표

| # | 학습 목표 | 도달 기준 |
| --- | --- | --- |
| 1 | 객체-관계 기반 온톨로지 모델을 코드로 구성한다 | `OntologyRegistry` 등록·`get_order_context` 호출 가능 |
| 2 | BM25 검색과 RAG 프롬프트 구성을 이해한다 | 질문 → 객체 추출 → 검색 → 프롬프트 → LLM 8단계 trace 설명 가능 |
| 3 | 역할 기반 접근 통제(RBAC)와 속성 마스킹을 적용한다 | analyst/finance/viewer 4가지 역할 결과 차이를 화면에서 확인 |
| 4 | 워크플로우 상태 전이와 액션 권한을 결합한다 | 7가지 전이 다이어그램을 보고 ApproveOrder가 막히는 사유를 진단 |
| 5 | RAG/Policy 자동 평가로 회귀를 감지한다 | `pytest` + `evaluate.py` + `playwright test` 3종 명령으로 합격 확인 |

## 4. 평가 방법

- **자동 평가**: `python evaluate.py --json` 결과 JSON을 제출 (pass_rate, mean_precision_at_3)
- **심화 과제**: `03_심화_과제.md` 중 최소 1개 PR 형태로 제출 (테스트 포함)
- **회고**: 학습 목표 5개에 대한 자가 평가 (1~5점)
