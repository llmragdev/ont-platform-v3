# 화면 기획

## 1. 메뉴

```text
대시보드
온톨로지 관리
객체 탐색
관계 탐색
AI 질의
워크플로우 그래프
문서 검색
감사 로그
설정
```

## 2. 온톨로지 관리

탭:

```text
개요
객체 타입
관계 타입
객체 데이터
관계 데이터
액션 타입
권한
검증
```

### 개요

- 객체 타입 수
- 관계 타입 수
- 액션 타입 수
- 객체 인스턴스 수
- 관계 인스턴스 수
- 온톨로지 그래프

### 객체 타입

- 타입 목록
- 속성 목록
- 필수/검색/민감 속성 표시
- 새 타입 추가는 Phase 2부터

### 관계 타입

- source/target 타입 표시
- cardinality 표시
- 관계 속성 표시

### 관계 데이터

- 관계 타입별 인스턴스 목록
- source/target 객체 링크
- 관계 추가 폼

## 3. 객체 탐색

- 객체 타입 선택
- 객체 목록
- 객체 상세
- incoming 관계
- outgoing 관계
- 관련 문서
- 가능한 액션

## 4. AI 질의

- 질문 입력
- 감지된 객체
- 관계 기반 컨텍스트
- 검색 근거
- 답변
- 가능한 액션
- trace

## 5. 워크플로우 그래프

`claud_통합`의 React Flow 화면을 참조한다.

차이:
- 노드 팔레트는 하드코딩 목록이 아니라 Action Type에서 생성한다.
- `ApproveOrder`, `RiskAssess` 같은 도메인 노드는 온톨로지 액션 정의에서 나온다.
