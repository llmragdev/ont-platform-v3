## 2. 지금 반영할 내용

### 2.1 Plan Validator

반영 위치:

- `FINAL_DESIGN.md`
- `06_ACCEPTANCE_TEST_PLAN.md`

반영 내용:

```text
QueryPlanner
  -> PlanValidator
  -> OntologyQueryEngine / SearchService
  -> HybridAnswerService
```

검증 규칙:

- `entity_type`은 현재 schema에 존재해야 한다.
- `property`는 해당 entity type에 존재해야 한다.
- `op`는 허용 연산자만 가능하다.
- `AGGREGATE` 대상 field는 number 타입이어야 한다.
- `relation_path`는 relationship schema로 검증한다.
- `doc_ids`는 현재 TenantContext에서 접근 가능한 문서만 허용한다.
- Plan에는 client supplied company/project를 넣지 않는다.

테스트 추가:

- 존재하지 않는 property가 plan에 있으면 422 또는 fallback
- 권한 없는 doc_id가 plan에 있으면 제외 또는 403
- number가 아닌 field에 sum 요청 시 validation error
- LLM이 잘못된 action을 만들면 실행 전 차단

### 2.2 Reasoning Trace Graph

반영 위치:

- `FINAL_DESIGN.md`
- `03_FINAL_API_SPEC.md`
- `07_UX_AND_OPERATIONS.md`

반영 내용:

`POST /api/v1/hybrid/ask` 응답에 다음 필드를 추가한다.

```json
{
  "reasoning_trace_graph": {
    "nodes": [
      {
        "id": "q1",
        "type": "question",
        "label": "사용자 질문"
      }
    ],
    "edges": [
      {
        "source": "q1",
        "target": "plan1",
        "label": "planned_as"
      }
    ]
  }
}
```

필수 node type:

- `question`
- `query_plan`
- `ontology_entity`
- `ontology_relationship`
- `document_chunk`
- `structured_result`
- `answer`
- `warning`

필수 edge label:

- `planned_as`
- `matched`
- `traversed`
- `grounded_by`
- `supports`
- `contradicts`
- `filtered_out`

### 2.3 AI 품질 모니터링

반영 위치:

- `04_FINAL_DATA_SCHEMA.md`
- `07_UX_AND_OPERATIONS.md`

반영 내용:

`audit_log.jsonl` 또는 hybrid query event에 다음 필드를 추가한다.

```json
{
  "quality": {
    "prompt_tokens": 1200,
    "completion_tokens": 350,
    "total_tokens": 1550,
    "estimated_cost": 0.0012,
    "llm_model": "gemini-2.5-flash",
    "planner_fallback_used": false,
    "plan_validation_error_count": 0,
    "llm_self_confidence": 0.78,
    "grounding_score": 0.92,
    "plan_validity_score": 1.0,
    "evidence_count": 5,
    "latency_ms": 1830
  }
}
```

운영 대시보드 지표:

- 테넌트별 token 사용량
- 테넌트별 estimated cost
- planner fallback 비율
- 평균 grounding score
- plan validation 실패율
- 평균 latency

### 2.4 절제된 프리미엄 UX

반영 위치:

- `07_UX_AND_OPERATIONS.md`

반영 내용:

- 다크 모드는 선택 지원한다.
- 디자인 토큰을 정의한다.
- 마이크로 인터랙션은 로딩, 저장 완료, 권한 차단, trace graph 전개에 제한 적용한다.
- 글래스모피즘은 핵심 업무 화면에 적용하지 않는다.
- 핵심 화면은 대비, 정보 밀도, 표/그래프 가독성을 우선한다.
