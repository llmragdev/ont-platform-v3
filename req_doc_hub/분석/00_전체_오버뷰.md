# 온톨로지 AI 교육 및 구현 프로젝트 전체 오버뷰

## 1. 프로젝트 개요

본 프로젝트는 기업의 방대한 데이터를 현실 세계의 업무 맥락(객체, 관계, 액션)으로 재구성하는 **팔란티어 온톨로지(Palantir Ontology)** 개념을 학습하고, 이를 **Snowflake** 데이터 플랫폼과 **RAG(Retrieval-Augmented Generation)** 기술에 결합하여 실제 업무용 AI 시스템을 구축하는 것을 목표로 합니다.

단순히 질문에 답하는 챗봇을 넘어, 데이터를 기반으로 의사결정을 내리고 직접 **액션(Action)**을 실행할 수 있는 '실행형 AI'의 구조를 설계하고 구현합니다.

---

## 2. 핵심 아키텍처 패러다임

### A. 데이터에서 객체로 (Data to Object)
전통적인 테이블 중심의 데이터 구조를 비즈니스 사용자가 이해할 수 있는 **객체(Object)** 모델로 변환합니다.
- **객체**: 고객, 주문, 장비 등 업무의 핵심 단위
- **속성**: 객체가 가진 정보 (이름, 상태, 금액 등)
- **관계**: 객체 간의 연결 (고객-주문, 장비-공장 등)

### B. 온톨로지-RAG 융합 (Ontology-RAG Fusion)
구조화된 온톨로지 정보와 비구조화된 문서 정보를 결합하여 답변의 정확성과 신뢰성을 높입니다.
1. 질문에서 객체 식별
2. 온톨로지에서 관계 및 상태 검증
3. BM25/Vector 검색으로 관련 문서 추출
4. 컨텍스트 결합 후 LLM 답변 생성

## 4. 주요 기술 스택

- **Storage**: Snowflake (Data Warehouse)
- **Backend**: Python (FastAPI / Pydantic)
- **AI/Search**: BM25, RAG, LLM (OpenAI/Vertex AI)
- **Frontend**: Next.js (React), Tailwind CSS
- **Governance**: Policy-based Access Control (PBAC)

---

## 5. 프로젝트의 가치

본 프로젝트를 통해 구현되는 시스템은 다음의 가치를 제공합니다.
1. **신뢰성**: 데이터 객체 정보를 통해 LLM의 할루시네이션(환각) 방지
2. **실행성**: 분석 결과에서 즉시 업무 액션(승인, 반려 등)으로 연결
3. **보안성**: 엔터프라이즈 수준의 세밀한 데이터 접근 제어
4. **가독성**: 복잡한 데이터 스키마를 비즈니스 언어로 사용자에게 전달
