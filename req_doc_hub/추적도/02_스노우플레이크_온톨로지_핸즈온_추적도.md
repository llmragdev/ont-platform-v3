## 3. 구현 추적

### 3.1 원천 데이터

`src_codex`:
- `src_codex/backend/data.py`
- `RAW_CUSTOMERS`
- `RAW_PRODUCTS`
- `RAW_ORDERS`
- `RAW_ORDER_ITEMS`
- `DOCUMENTS`

- `src_anti/backend/data.py`
- `Repository.reset()`

- 목 데이터 기반 대체 구현은 두 소스 모두 부분 구현

## 4. 요약

`02` 문서의 Snowflake 자체 구현은 두 소스 모두 없습니다. 다만 Snowflake에서 만들려던 객체 뷰, 관계 뷰, 계산 속성, 업무 조회 개념은 `src_codex`가 온톨로지 서비스로 더 잘 대체 구현하고 있습니다.
