## 4. 요약

`02` 문서의 Snowflake 핸즈온은 `src_sql`에 직접 구현되어 있습니다. `src_sql`은 원천 테이블, 객체 뷰, 관계 뷰, 계산 속성, 액션 요청, 업무용 조회 큐를 담당합니다. `src_codex`는 같은 개념을 Python 온톨로지 서비스와 워크플로우 서비스로 대체 구현하고 있으며, `src_anti`는 화면 데모에 필요한 목 데이터와 간단한 조회/상태 변경 로직 중심의 부분 구현입니다.
