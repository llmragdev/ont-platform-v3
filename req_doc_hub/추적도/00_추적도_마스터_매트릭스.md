## 2. 프로그램 누락 및 보완 로드맵

### 🔴 우선순위 1: SQL 프로그램 구축 (Requirement 02)
- **목적**: 스노우플레이크 데이터웨어하우스 상에서의 온톨로지 모델링(Table, View, Procedure)을 코드로 증명
- **위치**: `src_sql/` 폴더 신설
- **주요 내용**: DDL, DML, Ontology View, Workflow Procedure 스크립트

### 🔴 우선순위 2: Next.js 프론트엔드 구축 (Requirement 07)
- **목적**: Vanilla JS를 넘어선 최신 웹 프레임워크 기반의 온톨로지 업무 화면 구현
- **위치**: `src_nextjs/` 폴더 신설
- **주요 내용**: React 기반 컴포넌트 구조, TypeScript 적용, API Route 연동

### 🟡 우선순위 3: RAG 고도화 및 LLM 연동 (Requirement 05, 10)
- **목적**: Mock 답변을 넘어선 실제 LLM API 연동 및 BM25 알고리즘 정밀화
- **위치**: 각 소스의 `rag.py`, `search.py`
- **주요 내용**: OpenAI/Vertex AI SDK 연동, 하이브리드 검색 도입
